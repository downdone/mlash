# 当前 UI / UX 契约

产品取舍是“简约而不简单”：首屏只放当前对象、真实状态和高频下一步；高级能力从对象附近展开。去掉同义入口和长期说明时，草稿、失败、回读、恢复与键盘路径必须保留。主操作行一行只承担一个用户任务，同组行高和对齐稳定；对象的进度与结果就近呈现，不在控制区重复。内核启停等实现状态由应用维护，只有影响用户决策或需要处理的异常才占据可见界面；可观察详情保留在状态栏和诊断入口。Daymark 的安全导航、固定对象身份、就近菜单和滚动书签是交互方法，Mlash 的运行配置/代理接管仍按各自写入契约处理。逐页审视和未完成项见 [U22 重审](design/u22-daymark-page-reaudit.md)。

U22 修订：一级导航保留未提交的工作区、网络设置和规则草稿，返回所属分区恢复位置与输入；只有写事务进行中才阻止切页并恢复侧栏。配置详情跨分区返回保持对象、详情滚动及列表位置，同一行的重复激活不重建详情。配置列表普通单击打开详情，Ctrl/Shift 点击只调整批量选择；右键菜单固定打开时的配置 ID 并把单对象选择归到被点行。配置页以“导入…”行选择三种来源，顶栏 `+` 只在首页提供快捷添加。节点卡片和行列表的 Enter、书签、进入子组均读取各自可见视图的当前项；切换呈现同步选中，手动组选路共用写入守卫。节点收藏只对实际成员出现。规则页“前往订阅”始终回来源配置。设置搜索结果使用锚定菜单，不能把提交中或有脏草稿的设置任务藏在不可见的目录项之后。逐页操作审计见 [U22](design/u22-page-operation-flows.md)，实际验证范围见[验证报告](verification-report.md)。

U22 第四片：配置名称行内编辑有未保存输入时，尝试切换到另一配置会留在原配置、恢复原行高亮并聚焦输入；明确保存或取消后才切换。设置目录保留分组、行尾值和就近菜单，搜索框常驻目录与任务的顶部，Ctrl+F 聚焦输入；选中结果才定位目录项或打开所属任务。网络设置有未应用修改时，跨任务的搜索定位被拒绝并在状态栏提示先应用或放弃；搜索本身不重排正在编辑的工作区。跨一级分区的草稿保留语义不变。

U22 第五片：首页当前节点名称仅展示，不作为隐藏的点击入口；「连通性测试」按钮测试当前浏览的策略组全部可测成员，显示已测/总数并可停止。测速只读，期间仍可手动切换当前节点；内核或配置改变时取消。网站测速的节点下拉只切换结果视图，至多暂存八个其他节点的内存结果；显式清空、目标定义改变或配置写入清除暂存，结果详情始终标明测试节点。从连接详情定位策略组后返回连接页，恢复原筛选与列表位置，不自动重开详情。

当前层级按 [U14 全页设计](design/u14-shadowrocket-all-pages.md) / [ADR 0054](adr/0054-shadowrocket-all-pages-refinement.md) 精修：四分区保留，普通信息用连续分组行，内容正文在 Windows 以 10pt 为默认起点，节点卡 44 DIP、网站结果卡最小 92 DIP；文字放大与字体实际指标仍可扩高。托盘仅展示当前/常用组与每组少量当前/收藏/前列成员，完整节点选择回主窗口；展开自动测速最多取 16 个节点，显式整组重测仍有原 500 节点上限与取消语义。

U15/U22 修订：首页与配置的顶栏只有一个“添加配置”入口；文件导入留在配置页。配置详情按使用、配置内容、来源与维护分组；任务从对应行就近展开检查器，不再叠加外层任务页签。返回收起检查器并复用原详情与滚动位置，返回列表沿用原列表滚动。设置目录行悬停全高且不显示鼠标焦点环。外部代理待确认接管通过确认操作与全局状态说明，不占用首页技术状态次行；其他真实错误和只读保护仍持续提示。节点列表圆角由抗锯齿绘制而非二值 viewport 蒙版。

U12 / ADR 0052 的任务契约继续有效：高级编辑在正文工作区完成；内核一次到达完整编辑，备份创建/恢复/自动/WebDAV 同级；配置内容在固定对象内切换，来源与维护合并。工作区保留同级草稿，重复入口复用，取消/切对象放弃需确认，隐藏提交继续回读但不抢回页面。普通帮助在原位置展开，失败在任务内显示。首页按三行控制与连续节点列表组织，搜索默认收起；危险和权限操作确认保留。


本文维护当前交互，历史方案见 [归档导航](archive/README.md)。修改界面前遵守 [先审视、先设计、后修改](engineering.md)；技术调度、容量和事务由 [架构](architecture.md) 与 [功能模块契约](development/feature-contracts.md) 维护。

## 整体原则

系统基础沿用 [U11](design/u11-ui-system.md) 和 [ADR 0051](adr/0051-prototype-ui-task-hierarchy.md) 的四分区、配置对象详情、宽窄自适应 Inspector、固定状态栏和四列连接默认视图。入口 6 进入设置目录，显式设置分类为任务深链；编辑任务的位置与返回方式由 U12 规定。

U10 已接受的紧凑原生实现以 [施工设计](design/u10-implementation.md) 和 [ADR 0050](adr/0050-shadowrocket-compact-widgets.md) 为准：固定居中顶栏、四分区、连续分组行；运行反馈在固定状态栏和首页展示，侧栏不重复。节点来源下拉只浏览，显式“使用此配置”才激活。行尾延迟是独立测速目标，不能触发节点选择。以下历史布局细节与该决策冲突时，以此决策为准。

界面围绕“理解状态 → 使用订阅 → 选择节点 → 必要时调整 → 观察与诊断”组织。一级导航为首页、配置、数据、设置；首页合并状态和节点，配置列表进入对象详情及规则，数据提供流量/连接/测试/日志四页签，设置默认目录并深入编辑任务。ViewIds 将历史八页入口适配到五个主视图和数据页签；导航同时同步侧栏。首页节点名称单击使用，延迟点击独立测速，信息按钮打开详情；选择浏览组不应用订阅。

显示与写入分开：浏览、搜索、排序和详情不改变运行状态；使用、应用、保存、确认选择和首页节点单击才调用 Controller 写命令。操作忙碌优先限制重复写入，保持可行的浏览与取消。内核当前成员、下载候选、运行版本和上次良好版本分别表达。

状态只呈现实际观测。未知显示“—”或原因，不以 0、旧成功值或选中的浏览对象填充。模式、内核就绪、系统代理归属、TUN 状态和节点健康互不代替。结果保留失败/取消/未完成边界。

默认内容围绕对象、状态和动作组织；同一信息不在标题、正文和页脚重复。自解释控件不附教学段落，正常无修改时保持安静。实现细节进入提示或可用键盘打开的说明；失败、草稿/待应用、来源覆盖差异、密码不可找回及权限后果仍直接显示。信息减噪的逐页取舍见 [U02 审视](ui-apple-review.md#u02-信息减噪与任务重审)。

## 视觉与排版

当前密度由 [U13](design/u13-compact-density.md) / [ADR 0053](adr/0053-compact-density.md) 修订；U11 的 52 DIP 节点行等较宽松尺寸不再作为当前要求。

借鉴用户提供的 macOS 系统设置及 Shadowrocket 的少量一级入口、分组列表和直接动作，采用 Apple HIG 启发的桌面布局：连续侧栏、克制的蓝色主动作、浅层分组和清晰文字层级，保留 Windows/macOS 原生窗口装饰与输入习惯。UiTheme 是颜色、字号和间距的唯一实现来源，各页不复制调色板。逐项设计与取舍见 [U01 审视](ui-apple-review.md)，单列与平台字体决策见 [ADR 0042](adr/0042-grouped-settings-and-platform-typography.md)。

| 角色 | 当前基线 |
|---|---|
| 字体 | 内置 Noto Sans SC 可变字体，缺字回退平台字体；当前字号与缩放规则见 U13/U14，代码使用平台等宽字体。 |
| 颜色 | window/sidebar/surface、ink/secondary、brand/selection/focus、success/warning/error 等语义角色 |
| 尺寸 | 集中 UiTheme，紧凑基准与真实双行指标扩展见 U13；图标图形与命中区分别定义。 |
| 窗口 | 默认 1040×720，最小 840×560 DIP；不足时换行/滚动，不能裁字或放大主窗掩盖冲突。 |
| 外观 | system/light/dark；文字比例 90/100/110/120%；系统高对比优先 |

浅色语义层级以近白窗口、纯白内容面、轻灰侧栏和轻灰控件为序；深色保持独立的深灰窗口/内容面层级，增强对比另有专用取值。选中使用浅蓝面，各页及菜单从同一 `UiTheme` 取色，不持有自己的调色板。U25 设计与实际验证边界见[配色审视](design/u25-brighter-macos-semantic-palette.md)。

U26 起主操作按钮使用品牌蓝的紧凑圆角矩形；胶囊开关启用时为绿色轨道、关闭时为灰色轨道。普通按钮、危险动作、禁用状态和增强对比模式遵循各自语义；见[按钮与开关设计](design/u26-theme-buttons-green-switches.md)。

全局交互遵守“用户少操心，功能找得到”：首页优先连接、选节点与测试；技术状态由软件维护；每个页面和对象有可预期的主动作、就近次要动作及可发现的设置入口。默认值承担可安全自动处理的技术决策，高级选项按需展开，返回保留原对象和位置。Shadowrocket 移动端截图的桌面转译及不照搬项见[交互启示](design/u27-shadowrocket-mobile-lessons.md)。

U28 落地细则：首页路由选择就地说明三种模式的流量去向，并保留当前项勾选。节点行及可选卡片视图的详情图标常显，详情与延迟测试各有独立命中区；点击主体仍按组规则选择成员。统一配置卡片主体点击使用，非当前项显示动作提示；刷新、菜单、候选查看与应用独立。更新失败保留可用的原配置，卡片提示重试，完整错误可从提示中查看。此前“配置列表普通单击打开详情”的历史描述已由 U22 统一卡片方案取代；配置内容从卡片菜单进入。

U29 界面层级修订：进入「数据 › 流量」就直接显示速率、连接、曲线与累计，不再出现第二次「流量明细」展开；配置卡片保持有界等宽和白色卡面，蓝色用于当前标识而非整面铺色；配置内容的节点与组名单常驻搜索、逐行等高，低频维护操作在就近「更多」菜单；首页当前策略组设置以独立小窗口编辑，不挤占节点列表。各入口保持原有草稿、候选与 Controller 提交边界。若 UI 在子页面里还需再次展开同一内容，或同一状态重复占据两块面积，应先重审页面职责，再调整控件。

颜色同时配合文本、图标或状态点，不只依赖红/绿判断。主要动作使用品牌色，普通浏览/管理保持中性，删除与断开标明对象；必要的确认基于实际后果。

正常控件不因鼠标点击保留额外焦点框；键盘导航保留清晰焦点及标准快捷键。只读文本可选中/复制，省略字段保留完整提示和可访问名称。错误作为纯文本显示，避免把 HTML 样式字符解释成富文本。

## 功能分区与视图职责

| 页面 | 首要任务 | 主要入口与边界 |
|---|---|---|
| 首页 | 了解并控制当前运行状态，并直接换节点 | 控制区三行（当前代理与代理总开关、路由方式、连通性）+ 节点与策略组列表、搜索/排序/测速/筛选；指标、探测与摘要进「更多运行信息」 |
| 订阅 | 维护来源、版本和订阅配置 | 添加、下载更新、查看变化、使用并启动/应用更新；编辑配置集中管理节点/组、DNS、上游代理链与节点源 |
| 网站测试 | 检查网站响应与出口 | 指定测试节点、开始/停止、目标卡片/详情、出口与服务诊断；不承诺带宽与解锁 |
| 规则 | 维护分流规则与观察实际规则 | 优先规则列表、完整规则编辑/规则源、内核实际规则；按订阅保存，运行视图标明真实归属 |
| 连接 | 观察并处理当前会话连接 | 活动/已离开并列，搜索/列/详情/复制/关闭就近 |
| 日志 | 阅读与导出诊断 | 级别/关键词、暂停、跟随/历史、脱敏导出 |
| 设置 | 应用偏好、全局网络和备份维护 | 常规/网络与内核/备份与工具分类、搜索定位、固定全局应用栏；订阅配置与网络诊断归所属页面 |

功能由其对象与任务归属页面拥有；跨页捷径只导航或打开同一工具窗口，不创建另一套配置流程。设置搜索可导航到其他页面，内部页号/持久化值不随用户可见名称变化。后续结构决策见 [ADR 0043](adr/0043-task-ownership-and-clear-actions.md)。

## 首页与首次使用

无订阅时在引导卡片直接提供添加动作，已有订阅但未选用时直接导航选择；隐藏重复顶部主动作。导入校验成功后导航订阅页，由用户明确使用并启动；不自动启用系统代理。运行时首页按「控制区 → 节点列表」顺序展示，保留已保存的显示偏好。

首页把状态与节点合并在同一滚动视图：控制区三行（当前代理与代理总开关、路由方式、连通性测试）在上，节点与策略组列表在下，共用一次页面滚动。代理总开关的文案是「开启代理 / 关闭代理」，它表示「让所选接管方式生效/失效」，不是内核启停——内核单独启停移到「更多运行信息」与托盘。控制区之后在 840×560 下仍须看到至少 3 行节点。指标、探测与摘要统一进「更多运行信息」收纳入口；该入口只展开不执行，不计入控制区控件上限，但必须保持可见。系统代理与 TUN 的偏好开关在设置里：那是「允许哪种接管方式」，首页总开关是「现在是否接管」；首页状态句只报告两者的观测结果。

控制区的当前节点名称只读；开关、路由方式和连通性按钮各有独立命中范围，避免父行截获子按钮。首页状态、节点测试和运行指标说明观测对象及新鲜度；未知/失败不沿用旧数字。TUN 与系统代理独立控制，内核运行不等于接管流量，关闭窗口不等于退出。首页节点列表单击成员即生效（手动策略组），不设预选—提交两段式；自动策略组不提供切换语义，只显示当前选路结果。切换组/运行代次或操作忙碌时撤销旧选择，失败回滚为原成员并就地提示。TUN 设置打开同一管理工具。

## 订阅、候选与草稿

来源更新和版本应用是两个动作，正在运行的版本始终明确。查看变化只展示有界数量/名称，不暴露原始定义或凭据；候选变化后，旧比较不能直接应用。

剪贴板、拖入和自有协议先进入确认窗，不自动请求网络或激活。节点链接可离线预览、去重，再确认新建快照或加入节点草稿。失败保留原输入与完整的脱敏错误，重试路径可见。

运行中编辑明确标出对象为运行版或候选版，已打开窗口保存时校验期望快照。来源、版本、覆盖或核心上下文变化使旧草稿失效时，保留内容并要求重新载入，不静默覆盖。

配置列表只负责选择对象、导入和批量更新；单击对象进入其分组详情目录，使用、编辑、查看候选与维护动作归于该对象。多字段任务从目录行展开就近检查器，单值选项使用行尾菜单，右键/菜单键/Shift+F10 提供少量对象快捷动作并固定配置 ID。回滚是切换运行版本、不删除数据，因此不按危险动作处理，也不要求额外确认；删除才是危险动作，须确认并含宾语。多选禁用单对象编辑和使用，只保留批量更新；自动更新/文件监测须显式开启，真实用量缺失时不编造。

## 节点表格与卡片

节点区在首页控制区之下：当前组标题、成员数和当前成员上下文常驻；组切换低频，默认折叠。工具带围绕搜索、默认/名称/延迟排序、表格/卡片视图和测试组织，窄窗换行并避免箭头/文字重叠；该工具带不计入控制区控件预算。

两种视图使用同一数据、过滤、选择和滚动语义。卡片采用虚拟绘制、紧凑单行、8 DIP 圆角、名称左对齐、延迟右对齐；键盘高亮使用柔和选择背景，内核当前成员另用状态标记区分。

地区图标从名称推断，仅是位置提示。51 地区旗帜内置，地区组也可识别；未知使用组/地球/直连/拒绝回退，不下载远端图标。子组提供浏览入口，浏览不自动选择。

手动策略组（`select` 类）单击成员即生效，没有「切换」提交条；自动策略组（`url-test`/`fallback`/`load-balance`）不提供切换，只展示当前选路结果与进入手动组/修改规则的入口。方向键只移动高亮、Enter 等同单击，二者在自动组下都不写入。Ctrl+F 定位搜索，Esc 清除高亮而不撤销内核当前成员。延迟区域独立悬停/点击可重测，F5 提供键盘入口；排序/过滤变化后仍校验按下和释放目标，避免误测或误切换。

重复选择当前成员不提交；切换失败回滚为原成员并就地提示。测速期间保持浏览和取消，不禁用整个表格。延迟未知、进行中、成功、失败及过期状态分开；按名称排序不改变来源默认顺序语义。

## 网站测试与诊断

默认测试节点来自可明确解析的实际叶子，不能以列表高亮行代替。无法确定单一出口时需手选；选择测试对象不写策略组。开始后冻结归属；切换节点显示该节点暂存结果，切回仍可查看旧结果，同节点单卡重测保留其他结果。显式清空、目标定义改变或配置写入才清除暂存。

服务卡片显示内置图标、名称、主延迟、点与文字双重状态、可键盘访问的重测动作；完整地址保留在提示与结果详情，测试说明从标题栏就地展开；结果详情在对应卡片内显示打开时快照，离页清理。完成统计和真实最近时间位于列表上方，无结果不显示未测日期。0ms 是有效响应，超时/受限/未测分别显示。没有模拟曲线或自动周期采样。无配置时下一步直达配置；有配置且内核停止时才提供启动内核；内核正启动或运行但未就绪时只呈现等待状态，不重复发启动命令。

出口与服务诊断按明确传输路径请求，由数据页的网站测试区域进入；首页的「连通性测试」直接测试当前浏览策略组的全部可测成员，不跳转网站测试。实际 IP/地区/ASN、时间、目标和响应依据可以查看；疑似支持不等于账户/播放/全部流量可用。切换上下文或关闭后清理会话证据，不将它保存为订阅事实。

## 规则与高级编辑

默认显示优先规则的类型、匹配内容和目标列表，直接添加、删除及排序；高级文本为显式切换，二者共享同一草稿。双击或“完整规则编辑”打开包含前置、订阅原规则、追加和规则源的页面内任务。内核实际规则视图单独标明当前运行订阅，不沿用浏览中的编辑对象。类型、目标和选项采用中英说明，写入仍使用真实协议值；错误定位行或单元格，取消不写，保存失败留稿。

规则/DNS/节点/拨号链编辑遵循“沿用来源、明确清除、指定覆盖”的区别。常用表单与高级 YAML 共享草稿，不丢未触及字段；移除影响只提供有界分析，最终校验和引用修正责任不因预览而消失。

## 连接与日志阅读

连接的活动/已结束使用并列页签，搜索、大小写/整词/正则和列设置直接可达；三个搜索开关紧邻搜索框，列菜单只承载列选择。非法正则保留最后有效结果。详情、复制和断开围绕选中对象；右键菜单非阻塞，动作以打开时的连接 ID 重新定位，原行消失不作用于别的连接。单连接通过显式“断开选中”直接执行，断开全部明确确认；回读只判断原连接 ID 是否消失。无配置时表格空态只有“选择配置”并直达配置；有活动配置而内核未就绪时显示相应状态，停止时才提供“启动内核”，不在汇总栏复制第二个按钮。连接摘要仅在有速率、累计量或当前活动连接时显示；“断开全部”仅在当前活动连接非空时可见，搜索结果为空不改变这个判断。

暂停冻结当前快照并显示采样时间，恢复重新建立速率基线；字段查询/主动排序和可行写操作仍可用。详情为打开时快照，不冒充实时数据。离页、隐藏或内核变化清空观察会话及详情。

脱敏诊断导出在日志页标题工具带直接可达；复制选中、清空视图、自动换行和日志目录只在「日志选项」菜单中。日志默认跟随尾部，滚到历史或选中文字后保持阅读位置，工具带的“回到最新”恢复跟随。暂停保留视图并停止详细订阅；清空视图不删除磁盘日志。容量与订阅机制仅在提示中说明。筛选、复制和脱敏导出不清除只读保护或恢复错误。
暂停时清空视图也清除暂停的显示快照，保持暂停；之后的新记录在恢复显示前不进入可见列表。

## 设置与页面内任务

设置先显示单列目录，按常用、通用、连接与网络、维护与数据、关于分组，每行展示名称及当前值。常驻搜索仅检索；选中结果才定位目录行或进入所属任务。「本地代理」只含本地端口与节点延迟测试地址；「内核管理」集中 mihomo 文件、日志等级、IPv6、统一延迟、运行配置预览，并从此处进入更新工具。登录启动和关闭窗口释放界面由目录行直接持有控件，不在隐藏表单中复制。备份的创建、恢复、自动计划和 WebDAV 为同级页签。普通偏好在行尾选择或开关；页面宽度不足时纵向滚动，保留可见返回入口。

偏好类修改即时提交并保存：登录启动、启动时隐藏窗口、启动内核、恢复代理开关、轻量关闭、启动页面、托盘单击、外观和文字大小；失败时显示原因并把控件恢复到实际值。需要显式应用的项（本地端口、节点延迟测试地址、日志等级、内核文件、IPv6、统一延迟）只有存在改动时才显示保存/取消栏；端口、内核文件等需要内核安全重启，不使用全局“还原/应用”草稿栏。提交经 Controller 串行化，操作期间控件保持可见但不可写，重复快速切换只在空闲后提交一次最终差异。分类切换与搜索不隐式写入。订阅 DNS 与上游配置在订阅页编辑，设置搜索提供路由。

设置分组内的下拉框与数字框在未聚焦且未展开时忽略滚轮，避免滚动页面误改偏好；获得焦点或展开后滚轮与键盘照常可用。TUN 管理、DNS/Geo、内核更新、备份/WebDAV 和快捷键使用按需页面内任务，同一工具/对象复用已有会话。返回目录和同级切换保留草稿；取消任务或切换编辑对象时只对实际修改确认放弃，进行中的写入不能被关闭绕过。普通说明就地展开，只读详情与有副作用动作清晰区分。

窗口标题栏是纯显示偏好：设置目录的「窗口标题栏」在系统栏与融入现有页眉的应用内栏之间即时切换，不改变代理、内核和 TUN。应用内栏的窗口控制、标题拖动、双击最大化和边缘缩放遵循系统预期。维护目录的「Mlash 更新」由用户显式检查、下载与取消；下载后只显示已校验候选及打开包动作，不能把候选写成已安装版本。整组节点测速逐项显示结果与进度，有限并发，取消后旧结果不可写回。

快捷键默认不绑定；录制、冲突、实际注册与持久意图分开。动作可打开页面或执行明确绑定的有限网络控制，但不能自动接管外部代理或安装服务。

备份恢复先明确停止条件，再预览和选择新增项，最终确认后才提交；不会自动运行。内核维护先副本预检再确认应用，TUN 固定版本冲突先说明条件，不静默替换原文件。内核管理维护最多 8 个有界历史版本（sha256、版本、记录时间与来源），可预检并切换到任一历史版本；切换同样走预检、校验和写前恢复。清理未使用副本时保留当前、上次与历史在册版本，删除的副本同步移出历史。

## 状态栏、弹出层与可访问性

全局进度/结果/错误使用固定高度的单行状态栏；空闲不重复版本与地址，详情按钮只在有消息时显示。出现、成功反馈超时复位和切页不改变主体边界；失败持续保留。长消息省略但可查看/复制全文，失败的处理入口指向相关页面或工具。表单错误仍就近显示，不能只留瞬时提示。

组合框、菜单和托盘共用应用级样式，首帧直接呈现圆角，禁用先方后圆的展开/淡入效果。首页路由和连接右键临时菜单在显示前限高、测量、裁切屏幕范围并非阻塞打开；弹出视图处理长列表与键盘，换肤时配置已有 view，不在 Qt 样式遍历中销毁它。

节点筛选以“更多 › 筛选”打开工具按钮旁的独立浮层，不把五项输入嵌在命令菜单。收起后保留地区、协议、状态、延迟与收藏条件；Esc、换页或主窗移动/隐藏关闭浮层并把焦点交还触发按钮。菜单触发后若节点页已不可见，不再延迟打开浮层。

配置的重命名在对象详情页行内进行；列表右键“重命名”直接打开该行。取消不提交，名称为空时禁用保存，保存失败保留输入，未保存返回列表需确认放弃。重新加载当前候选版本与回滚至上次良好版本是不同命令，不共用动作身份或参数。

配置页“导入…”先在该行旁选择订阅地址、本地 YAML 或节点分享链接，再进入页面内导入任务；空列表入口、剪贴板、拖放与协议链接可直达相应来源。列表右键仅保留与该对象有关的短操作，完整配置编辑在详情工作区。连接表列选择使用限高浮层连续勾选，名称列始终可见；列显隐与顺序仍按既有偏好保存。设置的行内动作不依赖隐藏菜单刷新启用状态。托盘最多显示五个快选组、每组六个节点和五个订阅，余项由主窗口进入。

控件具备明确名称与可访问描述，按 Tab/方向键/Enter/Esc/菜单键遵循标准语义。自动刷新保持有效的选择、滚动、焦点、打开的下拉和草稿；未变化的模型/图标不重建。

## 托盘与轻量生命周期

托盘提供核心状态、开启/关闭代理、系统代理/TUN、模式、具体组、订阅、主窗口与退出入口，业务命令与页面共用 Controller；代理总开关与首页同命令、同确认规则。具体组停留后按需测试、复用短期缓存；快速划过和忙碌/未就绪状态不触发，关闭菜单取消自己的读取，不影响其他任务或自动选节点。

小象为静态状态变体，仅状态键变化时更新，不用动画定时器。启停/退出、失败、未知、接管/待命/外部管理按优先级显示；颜色、动作和提示共同说明实际归属/模式，不作为节点健康证明。

轻量关闭销毁主窗口对象树，停止页面请求/计时器并清空敏感快照；托盘重开后恢复有界视图书签。Controller、内核及明确开启的后台维护计划继续运行；没有托盘时关闭进入安全退出。未保存草稿须先处理。

## 修改后的验收

对改动的完整任务链检查空/加载/成功/失败/取消、过时结果、未保存/候选/运行版本，以及窄窗、文字缩放、浅深/高对比、鼠标/键盘和轻量重建。几何检查确认控件不相交、短标签不误省略、箭头命中正确；原生检查确认层级与输入。实际结果记录到验证报告，未执行的人工/系统测试保持未验。
