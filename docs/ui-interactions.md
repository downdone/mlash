# 当前 UI / UX 契约

本文描述当前原生界面。字阶、色彩、控件状态和尺寸见 [VI](design/u32-mlash-visual-identity.md)，页面层级见[多层内容大纲](design/u35-information-architecture.md)。历史设计见[归档](archive/README.md)，修改流程见[工程方法](engineering.md)，调度和事务见[功能模块契约](development/feature-contracts.md)。

## 整体原则

- 左侧固定导航，右侧为内容区。首页、配置、数据、设置各有固定入口，右栏标题左对齐，常用操作就近显示。数据页签为流量、连接、测试、日志。流量页直接展示速率、连接、曲线与累计。
- 浏览、搜索、排序和打开详情只读取。使用、应用、保存及手动组的节点激活由 Controller 写入。忙碌时限制重复写入，保留可行的浏览和取消。
- 状态来自实际观测。未知显示「—」或具体原因。内核就绪、代理归属、TUN、路由模式与节点健康各自呈现。活动版本、待应用候选、上次良好版本和当前浏览对象分别标识。
- 一级导航保留编辑草稿、选择和滚动。返回配置详情恢复原对象和位置，同一入口复用工作区。写入事务中守住原路由，隐藏提交的回读结果显示在所属对象，避免抢占用户正在浏览的位置。
- 默认界面显示当前对象、状态和下一步。失败、未保存、权限后果和不可恢复操作就地可见，解释与低频维护由对象附近的入口承载。

## 视觉与排版

- `UiTheme` 和设计 token 提供 Noto Sans SC、Daymark 明暗语义色和统一间距。
- 默认窗口 1040×720 DIP，最小 840×560 DIP。首页、配置、数据在侧栏单列竖排。展开显示图文，折叠为保留四个入口的图标栏。顶部折叠按钮与底部设置保持位置，切页保留正文左边界。配置卡与网站测速卡共用表面、图标底块和布局规格。配置网格支持双列和单列，按可用宽度与内容决定。
- 鼠标悬停与键盘焦点可区分。状态颜色辅以文字、图标或状态点，省略文本保留完整提示和可访问名称，错误作为纯文本显示。
- 覆盖系统、浅色、深色、增强对比和 90%–120% 文字比例。空间不足时允许换行或滚动，并保留独立命中区。

## 功能分区与视图职责

| 一级入口 | 职责 |
|---|---|
| 首页 | 开启／关闭代理、切换路由、测试连通性、选择节点与策略组。 |
| 配置 | 导入、使用、更新、比较和应用候选。配置内容包括节点与组、规则、DNS、拨号链和来源。 |
| 数据 | 流量提供实时与累计指标，连接可筛选和断开，测试可检查网站响应和出口，日志可阅读与脱敏导出。 |
| 设置 | 应用偏好、全局网络、备份、维护工具与关于。 |

功能由其对象与任务归属页面拥有；跨页捷径只导航或打开同一工具窗口，不创建另一套配置流程。设置搜索可导航到其他页面，内部页号/持久化值不随用户可见名称变化。后续结构决策见 [ADR 0043](adr/0043-task-ownership-and-clear-actions.md)。

## 首页与首次使用

首页、流量、连接和网站测试按同一规则引导首次使用。无配置时「导入配置」聚焦快速输入，已有配置但未使用时「选择配置」聚焦可用卡片。说明紧邻主动作。导入成功后停在配置列表，由用户明确使用，再从首页开启代理。运行时首页按「控制区 → 节点列表」顺序展示，保留已保存的显示偏好。

首页把状态与节点合并在同一滚动视图：控制区三行（当前代理与代理总开关、路由方式、连通性测试）在上，节点与策略组列表在下，共用一次页面滚动。代理总开关的文案是「开启代理 / 关闭代理」，它表示「让所选接管方式生效/失效」，不是内核启停——内核单独启停移到「更多运行信息」与托盘。控制区之后在 840×560 下仍须看到至少 3 行节点。指标、探测与摘要统一进「更多运行信息」收纳入口；该入口只展开不执行，不计入控制区控件上限，但必须保持可见。系统代理与 TUN 的偏好开关在设置里：那是「允许哪种接管方式」，首页总开关是「现在是否接管」；首页状态句只报告两者的观测结果。

控制区的当前节点名称只读，开关、路由和连通性按钮有独立命中区。路由整行可触发菜单，菜单对齐行尾模式值并显示当前项和各模式的作用。连通性测试显示整组进度，允许手动切换节点或停止。内核或配置改变时取消原测试。工具栏可更新当前配置来源，候选仍需显式应用。首页状态、节点测试和运行指标说明观测对象及新鲜度；未知/失败不沿用旧数字。TUN 与系统代理独立控制，内核运行不等于接管流量，关闭窗口不等于退出。首页节点列表单击成员即生效（手动策略组），不设预选—提交两段式；自动策略组不提供切换语义，只显示当前选路结果。切换组/运行代次或操作忙碌时撤销旧选择，失败回滚为原成员并就地提示。TUN 设置打开同一管理工具。

## 订阅、候选与草稿

### 配置导入

配置列表上方常驻一个输入框，接收 HTTP/HTTPS 订阅、绝对 YAML 路径或文件 URL。输入区右侧的文件夹按钮和拖放都填入输入框，点「导入」或按 Enter 提交。订阅地址默认遮挡，失败保留输入并在该行附近显示原因，成功定位新卡片。卡片的更多菜单提供「使用此配置」。

「高级新增」打开独立窗口，保留命名、下载设置、完整文件表单和节点链接预览。快速框中可识别的来源带入窗口，取消回到原输入。首页快捷入口聚焦快速框。验收覆盖快速 URL 与文件提交、取消／失败重试、窄窗口、浅深色及独立窗口键盘操作。

来源更新和版本应用是两个动作。批量入口明确显示全部或所选范围，只有快照的条目会跳过。配置卡按宽度将状态与完整动作标签分行。差异页优先呈现变更和受影响的选择，版本身份和时间跟在明细后；报告只展示有界数量和名称。配置卡与快捷键进入同一候选比较，过期结果提示重新比较。应用和回滚确认绑定目标版本，Controller 在接受写入前复核目标身份。失败反馈使用实际已确认的运行版本。

从剪贴板或自有协议触发的外部导入先确认来源。拖入配置页快速输入只预填，提交或使用各需显式动作。节点链接可离线预览、去重，再确认新建快照或加入节点草稿。失败保留原输入与完整的脱敏错误，重试路径可见。

运行中编辑明确标出对象为运行版或候选版，已打开窗口保存时校验期望快照。来源、版本、覆盖或核心上下文变化使旧草稿失效时，保留内容并要求重新载入，不静默覆盖。

配置列表负责导入、使用、更新和打开内容。点击卡片主体或按 Enter 进入配置内容。卡片使用来源类型、最近成功更新时间和状态标签，悬停来源类型显示公开来源。右上角的刷新按钮在有来源时可用。带候选的卡片显示「查看更新…」，进入比较后可确认应用。更多按钮、右键、菜单键或 Shift+F10 打开固定到该配置的操作菜单。来源维护提供原始地址、来源报告的用量和回滚到上次良好版本的入口。删除需确认并指出要删除的配置。多选禁用单对象编辑和使用，只保留批量更新。自动更新和文件监测须显式开启。来源维护保存失败时保留表单。

## 节点表格与卡片

节点区在首页控制区之下：当前组标题、成员数和当前成员上下文常驻；组切换低频，默认折叠。工具带围绕搜索、默认/名称/延迟排序、表格/卡片视图和测试组织，窄窗换行并避免箭头/文字重叠；该工具带不计入控制区控件预算。

两种视图使用同一数据、过滤、选择和滚动语义。卡片采用虚拟绘制、紧凑单行、8 DIP 圆角、名称左对齐、延迟右对齐；键盘高亮使用柔和选择背景，内核当前成员另用状态标记区分。

地区图标从名称推断，仅是位置提示。51 地区旗帜内置，地区组也可识别；未知使用组/地球/直连/拒绝回退，不下载远端图标。子组提供浏览入口，浏览不自动选择。

手动策略组（`select` 类）单击成员即生效，没有「切换」提交条；自动策略组（`url-test`/`fallback`/`load-balance`）不提供切换，只展示当前选路结果与进入手动组/修改规则的入口。方向键只移动高亮、Enter 等同单击，二者在自动组下都不写入。Ctrl+F 定位搜索，Esc 清除高亮而不撤销内核当前成员。延迟区域独立悬停/点击可重测，F5 提供键盘入口；排序/过滤变化后仍校验按下和释放目标，避免误测或误切换。

重复选择当前成员不提交；切换失败回滚为原成员并就地提示。测速期间保持浏览和取消，不禁用整个表格。延迟未知、进行中、成功、失败及过期状态分开；按名称排序不改变来源默认顺序语义。

## 网站测试与诊断

默认测试节点来自可明确解析的实际叶子，不能以列表高亮行代替。无法确定单一出口时需手选；选择测试对象不写策略组。开始后冻结归属；切换节点显示该节点暂存结果，最多暂存八个其他节点的内存结果，切回仍可查看旧结果，同节点单卡重测保留其他结果。显式清空、目标定义改变或配置写入才清除暂存。

服务卡片显示内置图标、名称、主延迟、点与文字双重状态、可键盘访问的重测动作；完整地址保留在提示与结果详情，测试说明从标题栏就地展开；结果详情在对应卡片内显示打开时快照，离页清理。完成统计和真实最近时间位于列表上方，无结果不显示未测日期。0ms 是有效响应，超时/受限/未测分别显示。没有模拟曲线或自动周期采样。无配置时下一步直达配置；有配置且内核停止时才提供启动内核；内核正启动或运行但未就绪时只呈现等待状态，不重复发启动命令。

出口与服务诊断按明确传输路径请求，由数据页的网站测试区域进入。无配置时保留「出口诊断」次级入口。可显式选择直连，经内核的检测须等待内核就绪。首页的「连通性测试」直接测试当前浏览策略组的全部可测成员。实际 IP/地区/ASN、时间、目标和响应依据可以查看。切换上下文或关闭后清理会话证据。疑似支持仅反映相应探测结果，会话证据独立于订阅数据。

## 规则与高级编辑

默认显示优先规则的类型、匹配内容和目标列表，直接添加、删除及排序；高级文本为显式切换，二者共享同一草稿。双击或“完整规则编辑”打开包含前置、订阅原规则、追加和规则源的页面内任务。内核实际规则视图单独标明当前运行订阅，不沿用浏览中的编辑对象。类型、目标和选项采用中英说明，写入仍使用真实协议值；错误定位行或单元格，取消不写，保存失败留稿。

规则/DNS/节点/拨号链编辑遵循“沿用来源、明确清除、指定覆盖”的区别。常用表单与高级 YAML 共享草稿，不丢未触及字段；移除影响只提供有界分析，最终校验和引用修正责任不因预览而消失。节点与策略组的来源读取错误和「重新读取」同组出现，保存错误保留在保存动作附近。

## 连接与日志阅读

连接的活动/已结束使用并列页签，搜索、大小写/整词/正则和列设置直接可达；三个搜索开关紧邻搜索框，列菜单只承载列选择。非法正则保留最后有效结果。详情、复制和断开围绕选中对象；右键菜单非阻塞，动作以打开时的连接 ID 重新定位，原行消失不作用于别的连接。单连接通过显式“断开选中”直接执行，断开全部明确确认；回读只判断原连接 ID 是否消失。未使用配置时，表格空态沿用首次使用的引导动作。有活动配置而内核未就绪时显示相应状态，停止时才提供“启动内核”，不在汇总栏复制第二个按钮。从详情定位策略组后，返回连接页恢复筛选和列表位置。连接摘要仅在有速率、累计量或当前活动连接时显示；“断开全部”仅在当前活动连接非空时可见，搜索结果为空不改变这个判断。

暂停冻结当前快照并显示采样时间，恢复重新建立速率基线；字段查询/主动排序和可行写操作仍可用。详情为打开时快照，不冒充实时数据。离页、隐藏或内核变化清空观察会话及详情。

脱敏诊断导出在日志页标题工具带直接可达；复制选中、清空视图、自动换行和日志目录只在「日志选项」菜单中。日志默认跟随尾部，滚到历史或选中文字后保持阅读位置，工具带的“回到最新”恢复跟随。暂停保留视图并停止详细订阅；清空视图不删除磁盘日志。容量与订阅机制仅在提示中说明。筛选、复制和脱敏导出不清除只读保护或恢复错误。
暂停时清空视图也清除暂停的显示快照，保持暂停；之后的新记录在恢复显示前不进入可见列表。

## 设置与页面内任务

设置先显示单列目录，按常用、通用、连接与网络、维护与数据、关于分组，每行展示名称及当前值。目录右上角提供紧凑搜索。输入只检索，选择结果才定位目录行或打开任务。Enter 和 Shift+Enter 前后定位，Esc 清空。网络设置有未应用修改时保留原任务并提示先应用或放弃。子页标题提供就近返回。普通偏好菜单对齐对应行尾。「本地代理」只含本地端口与节点延迟测试地址；「内核管理」集中 mihomo 文件、日志等级、IPv6、统一延迟、运行配置预览，并从此处进入更新工具。登录启动和关闭窗口释放界面直接在目录行操作，登录启动冲突提示紧邻对应行。备份的创建、恢复、自动计划和 WebDAV 为同级页签。普通偏好在行尾选择或开关；页面宽度不足时纵向滚动，保留可见返回入口。

偏好类修改即时提交并保存：登录启动、启动时隐藏窗口、启动内核、恢复代理开关、轻量关闭、启动页面、托盘单击、外观和文字大小；失败时显示原因并把控件恢复到实际值。需要显式应用的项（本地端口、节点延迟测试地址、日志等级、内核文件、IPv6、统一延迟）只有存在改动时才显示保存/取消栏；端口、内核文件等需要内核安全重启，不使用全局“还原/应用”草稿栏。提交经 Controller 串行化，操作期间控件保持可见但不可写，重复快速切换只在空闲后提交一次最终差异。分类切换与搜索不隐式写入。订阅 DNS 与上游配置在订阅页编辑，设置搜索提供路由。

设置分组内的下拉框与数字框在未聚焦且未展开时忽略滚轮，避免滚动页面误改偏好；获得焦点或展开后滚轮与键盘照常可用。TUN 管理、DNS/Geo、内核更新、备份/WebDAV 和快捷键使用按需页面内任务，同一工具/对象复用已有会话。返回目录和同级切换保留草稿；取消任务或切换编辑对象时只对实际修改确认放弃，进行中的写入不能被关闭绕过。普通说明就地展开，只读详情与有副作用动作清晰区分。

窗口标题栏是纯显示偏好：设置目录的「窗口标题栏」在系统栏与融入现有页眉的应用内栏之间即时切换，不改变代理、内核和 TUN。应用内栏的窗口控制、标题拖动、双击最大化和边缘缩放遵循系统预期。维护目录的「Mlash 更新」由用户显式检查、下载与取消；下载后只显示已校验候选及打开包动作，不能把候选写成已安装版本。整组节点测速逐项显示结果与进度，有限并发，取消后旧结果不可写回。

快捷键默认不绑定；录制、冲突、实际注册与持久意图分开。动作可打开页面或执行明确绑定的有限网络控制，但不能自动接管外部代理或安装服务。

备份恢复先明确停止条件，再预览和选择新增项，最终确认后才提交；不会自动运行。内核维护先副本预检再确认应用，TUN 固定版本冲突先说明条件，不静默替换原文件。内核管理维护最多 8 个有界历史版本（sha256、版本、记录时间与来源），可预检并切换到任一历史版本；切换同样走预检、校验和写前恢复。清理未使用副本时保留当前、上次与历史在册版本，删除的副本同步移出历史。

## 状态栏、弹出层与可访问性

全局进度和结果使用固定高度的单行状态栏左侧，持续告警用右侧的形状标识和短标签。空闲时隐藏操作详情和告警。成功反馈超时复位，失败持续保留，切页及反馈显隐时主体边界稳定。长消息可在详情中查看及复制，表单错误就近显示。

「只读保护」直接打开详情，说明写入暂停，显示初始加载失败原因，提供「打开数据目录」和「复制原因」。详情和目录入口只供检查。运行告警经「处理」可打开完整原因，并使用原有日志和维护入口。

组合框、菜单和托盘共用应用级样式，首帧直接呈现圆角，禁用先方后圆的展开/淡入效果。首页路由和连接右键临时菜单在显示前限高、测量、裁切屏幕范围并非阻塞打开；弹出视图处理长列表与键盘，换肤时配置已有 view，不在 Qt 样式遍历中销毁它。

节点筛选以“更多 › 筛选”打开工具按钮旁的独立浮层，不把五项输入嵌在命令菜单。收起后保留地区、协议、状态、延迟与收藏条件；Esc、换页或主窗移动/隐藏关闭浮层并把焦点交还触发按钮。菜单触发后若节点页已不可见，不再延迟打开浮层。

配置列表的菜单绑定打开时的配置 ID，完整编辑在该对象的内容工作区。连接表列选择使用限高浮层连续勾选，名称列始终可见；列显隐与顺序仍按既有偏好保存。设置的行内动作不依赖隐藏菜单刷新启用状态。托盘最多显示五个快选组、每组六个节点和五个订阅，余项由主窗口进入。

控件具备明确名称与可访问描述，按 Tab/方向键/Enter/Esc/菜单键遵循标准语义。自动刷新保持有效的选择、滚动、焦点、打开的下拉和草稿；未变化的模型/图标不重建。

## 托盘与轻量生命周期

托盘提供核心状态、开启/关闭代理、系统代理/TUN、模式、具体组、订阅、主窗口与退出入口，业务命令与页面共用 Controller；代理总开关与首页同命令、同确认规则。具体组停留后按需测试、复用短期缓存；快速划过和忙碌/未就绪状态不触发，关闭菜单取消自己的读取，不影响其他任务或自动选节点。

托盘使用 Mlash 标志的静态状态变体，状态键变化时更新。启停/退出、失败、未知、接管/待命/外部管理按优先级显示；颜色、动作和提示共同说明实际归属/模式，不作为节点健康证明。

轻量关闭销毁主窗口对象树，停止页面请求/计时器并清空敏感快照；托盘重开后恢复有界视图书签。Controller、内核及明确开启的后台维护计划继续运行；没有托盘时关闭进入安全退出。未保存草稿须先处理。

## 修改后的验收

对改动的完整任务链检查空/加载/成功/失败/取消、过时结果、未保存/候选/运行版本，以及窄窗、文字缩放、浅深/高对比、鼠标/键盘和轻量重建。几何检查确认控件不相交、短标签不误省略、箭头命中正确；原生检查确认层级与输入。实际结果记录到验证报告，未执行的人工/系统测试保持未验。
