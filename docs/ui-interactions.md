# 当前 UI / UX 契约

本文维护当前交互，历史方案见 [归档导航](archive/README.md)。修改界面前遵守 [先审视、先设计、后修改](engineering.md)；技术调度、容量和事务由 [架构](architecture.md) 与 [功能模块契约](development/feature-contracts.md) 维护。

## 整体原则

界面围绕“理解状态 → 使用订阅 → 选择节点 → 必要时调整 → 观察与诊断”组织。一级导航为首页、配置、数据、设置。首页包含状态/节点/网站测试，配置包含订阅/规则，数据包含连接/日志，设置拥有自身分类。域内任务在原页标题位置以常驻页签一键切换，与动作同一行；不新增重复标题。八个内部视图的 ID 不变，跨域定位同步选中分区/页签，各分区在当前窗口记住最后浏览视图。页面承担完整任务，菜单收纳对象操作与低频管理，不将常用主动作埋入多层“更多”。

显示与写入分开：浏览、搜索、排序、详情和临时预选不改变运行状态；使用、应用、保存和确认选择才调用 Controller 写命令。操作忙碌优先限制重复写入，保持可行的浏览与取消。节点预选、内核当前成员、下载候选、运行版本和上次良好版本分别表达。

状态只呈现实际观测。未知显示“—”或原因，不以 0、旧成功值或选中的浏览对象填充。模式、内核就绪、系统代理归属、TUN 状态和节点健康互不代替。结果保留失败/取消/未完成边界。

默认内容围绕对象、状态和动作组织；同一信息不在标题、正文和页脚重复。自解释控件不附教学段落，正常无修改时保持安静。实现细节进入提示或可用键盘打开的说明；失败、草稿/待应用、来源覆盖差异、密码不可找回及权限后果仍直接显示。信息减噪的逐页取舍见 [U02 审视](ui-apple-review.md#u02-信息减噪与任务重审)。

## 视觉与排版

借鉴用户提供的 macOS 系统设置及 Shadowrocket 的少量一级入口、分组列表和直接动作，采用 Apple HIG 启发的桌面布局：连续侧栏、克制的蓝色主动作、浅层分组和清晰文字层级，保留 Windows/macOS 原生窗口装饰与输入习惯。UiTheme 是颜色、字号和间距的唯一实现来源，各页不复制调色板。逐项设计与取舍见 [U01 审视](ui-apple-review.md)，单列与平台字体决策见 [ADR 0042](adr/0042-grouped-settings-and-platform-typography.md)。

| 角色 | 当前基线 |
|---|---|
| 字体 | macOS 系统 UI 字体/苹方，正文 12pt、页标题 20pt、分组 13pt、主值 22pt；Windows Segoe UI/YaHei，正文 10pt、页标题 18pt、分组 11pt、主值 20pt；代码使用平台等宽字体 |
| 颜色 | window/sidebar/surface、ink/secondary、brand/selection/focus、success/warning/error 等语义角色 |
| 尺寸 | 常用控件最小约 30 DIP、表格行 32 DIP、侧栏 172 DIP、主区边距 20 DIP、面板间距 12 DIP/圆角 12 DIP、弹出圆角 8 DIP；文字放大允许增高/换行 |
| 窗口 | 默认 940×620，最小 840×560 DIP；不足时有序换行/滚动，不能靠裁字或放大主窗掩盖冲突 |
| 外观 | system/light/dark；文字比例 90/100/110/120%；系统高对比优先 |

颜色同时配合文本、图标或状态点，不只依赖红/绿判断。主要动作使用品牌色，普通浏览/管理保持中性，删除与断开标明对象；必要的确认基于实际后果。

正常控件不因鼠标点击保留额外焦点框；键盘导航保留清晰焦点及标准快捷键。只读文本可选中/复制，省略字段保留完整提示和可访问名称。错误作为纯文本显示，避免把 HTML 样式字符解释成富文本。

## 功能分区与视图职责

| 页面 | 首要任务 | 主要入口与边界 |
|---|---|---|
| 首页 | 了解并控制当前运行状态 | 当前订阅/实际成员、内核/模式、系统代理/TUN、可见时指标；低频摘要和探测折叠 |
| 订阅 | 维护来源、版本和订阅配置 | 添加、下载更新、查看变化、使用并启动/应用更新；编辑配置集中管理节点/组、DNS、上游代理链与节点源 |
| 节点 | 选择节点和测延迟 | 订阅/策略组上下文、筛选、表格/卡片、当前与待切换、显示偏好；订阅内容编辑归订阅页 |
| 网站测试 | 检查网站响应与出口 | 指定测试节点、开始/停止、目标卡片/详情、出口与服务诊断；不承诺带宽与解锁 |
| 规则 | 维护分流规则与观察实际规则 | 优先规则列表、完整规则编辑/规则源、内核实际规则；按订阅保存，运行视图标明真实归属 |
| 连接 | 观察并处理当前会话连接 | 活动/已离开并列，搜索/列/详情/复制/关闭就近 |
| 日志 | 阅读与导出诊断 | 级别/关键词、暂停、跟随/历史、脱敏导出 |
| 设置 | 应用偏好、全局网络和备份维护 | 常规/网络与内核/备份与工具分类、搜索定位、固定全局应用栏；订阅配置与网络诊断归所属页面 |

功能由其对象与任务归属页面拥有；跨页捷径只导航或打开同一工具窗口，不创建另一套配置流程。设置搜索可导航到其他页面，内部页号/持久化值不随用户可见名称变化。后续结构决策见 [ADR 0043](adr/0043-task-ownership-and-clear-actions.md)。

## 首页与首次使用

无订阅时在引导卡片直接提供添加动作，已有订阅但未选用时直接导航选择；隐藏重复顶部主动作。导入校验成功后导航订阅页，由用户明确使用并启动；不自动启用系统代理。运行时优先展示控制状态、当前订阅、实际解析成员与紧凑指标；低频摘要和节点探测放入默认收起区域，保留已保存的显示偏好。

主摘要的主要值可导航，快捷操作保持独立命中范围，避免父卡片截获子按钮。首页状态、节点测试和运行指标说明观测对象及新鲜度；未知/失败不沿用旧数字。TUN 与系统代理独立控制，内核运行不等于接管流量，关闭窗口不等于退出。首页节点下拉仅预选，点击“切换”才写入，切换组/运行代次或操作忙碌时撤销旧预选。TUN 设置打开同一管理工具。

## 订阅、候选与草稿

来源更新和版本应用是两个动作，正在运行的版本始终明确。查看变化只展示有界数量/名称，不暴露原始定义或凭据；候选变化后，旧比较不能直接应用。

剪贴板、拖入和自有协议先进入确认窗，不自动请求网络或激活。节点链接可离线预览、去重，再确认新建快照或加入节点草稿。失败保留原输入与完整的脱敏错误，重试路径可见。

运行中编辑明确标出对象为运行版或候选版，已打开窗口保存时校验期望快照。来源、版本、覆盖或核心上下文变化使旧草稿失效时，保留内容并要求重新载入，不静默覆盖。

来源与更新、编辑配置、查看变化及使用/应用在列表下方直接可达；编辑配置为单层菜单，集中节点/组、DNS、上游代理链与节点源。行管理菜单及菜单键/Shift+F10 提供重命名、回滚、排序、兼容性及删除。多选禁用单对象编辑和使用，只保留批量更新；自动更新/文件监测须显式开启，真实用量缺失时不编造。

## 节点表格与卡片

当前组标题、成员数和当前成员上下文常驻；组切换低频，默认折叠。工具带围绕搜索、默认/名称/延迟排序、表格/卡片视图和测试组织，窄窗换行并避免箭头/文字重叠。

两种视图使用同一数据、过滤、选择和滚动语义。卡片采用虚拟绘制、紧凑单行、8 DIP 圆角、名称左对齐、延迟右对齐；预选使用柔和选择背景，内核当前成员另用状态标记区分。

地区图标从名称推断，仅是位置提示。51 地区旗帜内置，地区组也可识别；未知使用组/地球/直连/拒绝回退，不下载远端图标。子组提供浏览入口，浏览不自动选择。

单击预选，使用选中成员或双击才提交选择。Ctrl+F 定位搜索，Esc 清除临时预选而不撤销内核成员。延迟区域独立悬停/点击可重测，F5 提供键盘入口；排序/过滤变化后仍校验按下和释放目标，避免误测或误切换。

重复选择当前成员不提交。测速期间保持浏览和取消，不禁用整个表格。延迟未知、进行中、成功、失败及过期状态分开；按名称排序不改变来源默认顺序语义。

## 网站测试与诊断

默认测试节点来自可明确解析的实际叶子，不能以临时预选行代替。无法确定单一出口时需手选；选择测试对象不写策略组。开始后冻结归属，切换节点清空旧结果；同节点单卡重测保留其他结果。

服务卡片显示内置图标、名称、主延迟、点与文字双重状态、可键盘访问的重测动作；完整地址保留在提示与结果详情，测试说明从标题栏打开。完成统计和真实最近时间位于列表上方，无结果不显示未测日期。0ms 是有效响应，超时/受限/未测分别显示。没有模拟曲线或自动周期采样。

出口与服务诊断按明确传输路径请求。出口与服务诊断统一从网站测试页进入，首页只提供到该页的捷径。实际 IP/地区/ASN、时间、目标和响应依据可以查看；疑似支持不等于账户/播放/全部流量可用。切换上下文或关闭后清理会话证据，不将它保存为订阅事实。

## 规则与高级编辑

默认显示优先规则的类型、匹配内容和目标列表，直接添加、删除及排序；高级文本为显式切换，二者共享同一草稿。双击或“完整规则编辑”打开包含前置、订阅原规则、追加和规则源的编辑窗口。内核实际规则视图单独标明当前运行订阅，不沿用浏览中的编辑对象。类型、目标和选项采用中英说明，写入仍使用真实协议值；错误定位行或单元格，取消不写，保存失败留稿。

规则/DNS/节点/拨号链编辑遵循“沿用来源、明确清除、指定覆盖”的区别。常用表单与高级 YAML 共享草稿，不丢未触及字段；移除影响只提供有界分析，最终校验和引用修正责任不因预览而消失。

## 连接与日志阅读

连接的活动/已结束使用并列页签，搜索、大小写/整词/正则和列设置直接可达。非法正则保留最后有效结果。详情、复制和断开围绕选中对象；断开全部明确确认，回读只判断原连接 ID 是否消失。

暂停冻结当前快照并显示采样时间，恢复重新建立速率基线；字段查询/主动排序和可行写操作仍可用。详情窗口为打开时快照，不冒充实时数据。离页、隐藏或内核变化清空观察会话及详情。

脱敏诊断导出在日志页标题工具带直接可达，目录与自动换行保留在日志选项中。日志默认跟随尾部，滚到历史或选中文字后保持阅读位置，工具带的“回到最新”恢复跟随。暂停保留视图并停止详细订阅；清空视图不删除磁盘日志。容量与订阅机制仅在提示中说明。筛选、复制和脱敏导出不清除只读保护或恢复错误。

## 设置与工具窗口

设置使用常规、网络与内核、备份与工具三个可见分类；每类保持单列分组列表，阅读宽度最多 760 DIP；组内细分隔，每行左侧名称/必要说明、右侧控件，URL/路径上下排列。分类页签占据与其它分区相同的标题位，搜索与该行同排右对齐，不额外渲染“设置”标题。各分类再按启动与托盘、网络与分流、备份与恢复等任务分组。

偏好类修改即时提交并保存：登录启动、启动时隐藏窗口、启动内核、恢复代理开关、轻量关闭、启动页面、托盘单击、外观、文字大小和延迟测试地址在控件变化时立即写入，失败时显示原因并把控件恢复到实际值。需要内核安全重启的项（本地端口、日志等级、内核对文件、IPv6、统一延迟）保留显式的“应用网络设置”，只有存在此类改动时才出现，并提供“放弃修改”回到已保存值；不使用全局“还原/应用”草稿栏。提交经 Controller 串行化，操作期间控件保持可见但不可写，重复快速切换只在空闲后提交一次最终差异。分类切换与搜索不隐式写入。订阅 DNS 与上游配置在订阅页编辑，设置搜索提供路由。

设置分组内的下拉框与数字框在未聚焦且未展开时忽略滚轮，避免滚动页面误改偏好；获得焦点或展开后滚轮与键盘照常可用。TUN 管理、DNS/Geo、内核更新、备份/WebDAV 和快捷键使用按需工具窗口。主体可滚动，反馈与提交固定；关闭取消未提交编辑，已授权写事务由 Controller 安全完成。只读详情与有副作用动作清晰区分。

快捷键默认不绑定；录制、冲突、实际注册与持久意图分开。动作可打开页面或执行明确绑定的有限网络控制，但不能自动接管外部代理或安装服务。

备份恢复先明确停止条件，再预览和选择新增项，最终确认后才提交；不会自动运行。内核维护先副本预检再确认应用，TUN 固定版本冲突先说明条件，不静默替换原文件。内核管理维护最多 8 个有界历史版本（sha256、版本、记录时间与来源），可预检并切换到任一历史版本；切换同样走预检、校验和写前恢复。清理未使用副本时保留当前、上次与历史在册版本，删除的副本同步移出历史。

## 状态栏、弹出层与可访问性

全局进度/结果/错误使用固定高度的单行状态栏；空闲不重复版本与地址，详情按钮只在有消息时显示。出现、成功反馈超时复位和切页不改变主体边界；失败持续保留。长消息省略但可查看/复制全文，失败的处理入口指向相关页面或工具。表单错误仍就近显示，不能只留瞬时提示。

组合框、菜单和托盘共用应用级样式，首帧直接呈现圆角，禁用先方后圆的展开/淡入效果。弹出视图处理长列表、键盘和屏幕范围；换肤时配置已有 view，不在 Qt 样式遍历中销毁它。

控件具备明确名称与可访问描述，按 Tab/方向键/Enter/Esc/菜单键遵循标准语义。自动刷新保持有效的选择、滚动、焦点、打开的下拉和草稿；未变化的模型/图标不重建。

## 托盘与轻量生命周期

托盘提供核心状态、系统代理/TUN、模式、具体组、订阅、主窗口与退出入口，业务命令与页面共用 Controller。具体组停留后按需测试、复用短期缓存；快速划过和忙碌/未就绪状态不触发，关闭菜单取消自己的读取，不影响其他任务或自动选节点。

小象为静态状态变体，仅状态键变化时更新，不用动画定时器。启停/退出、失败、未知、接管/待命/外部管理按优先级显示；颜色、动作和提示共同说明实际归属/模式，不作为节点健康证明。

轻量关闭销毁主窗口对象树，停止页面请求/计时器并清空敏感快照；托盘重开后恢复有界视图书签。Controller、内核及明确开启的后台维护计划继续运行；没有托盘时关闭进入安全退出。未保存草稿须先处理。

## 修改后的验收

对改动的完整任务链检查空/加载/成功/失败/取消、过时结果、未保存/候选/运行版本，以及窄窗、文字缩放、浅深/高对比、鼠标/键盘和轻量重建。几何检查确认控件不相交、短标签不误省略、箭头命中正确；原生检查确认层级与输入。实际结果记录到验证报告，未执行的人工/系统测试保持未验。
