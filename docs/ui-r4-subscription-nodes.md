# R4 施工记录：订阅菜单重排与首页单击即生效

> 归属：[界面分层设计](ui-layered-design.md#实施切片) 的 R4 片，规格见 [5.6b 菜单](ui-layered-design.md#56b-菜单) 与 ADR 0048 的节点切换条款。

## 1. 范围

1. 订阅管理菜单按 5.6b 的五组重排，命名规则逐条适用（动词开头、会弹窗才加省略号、危险项含宾语）。
2. 首页节点区取消「切换节点」提交条：手动组单击/Enter 即写入，自动组行内不写入。

## 2. 订阅菜单（实施前设计）

目标结构（一级项 13 个、六段）：

```
<订阅名> · <运行状态>              ← 只读头，禁用
─────────
重新加载当前版本
回滚上次运行版本
─────────
编辑配置 ▸  （复用工具条同一子菜单：节点与策略组 / 节点源 / DNS / 上游代理链）
─────────
重命名…
来源与更新…
配置兼容性…
─────────
分享订阅二维码… / 上移 / 下移 / 更换文件… / 打开数据目录
─────────
删除订阅…
```

- 「回滚上次运行版本」留在常用动作组：它只是切换运行版本、可再切回，不删数据，不染危险色。
- 「删除订阅…」永远最后且与上一段强制分隔；文案带宾语。
- 只读头由 `aboutToShow` 填充，让用户先确认对象。
- 该子菜单与工具条「编辑配置」是**同一个** `QMenu` 实例，避免两份同义菜单各自维护。

## 3. 首页节点区（实施前设计）

- 删除 `chooseMember`（「切换节点」按钮）与其成员 `chooseAction_`。
- 表格视图 `clicked` 与卡片视图 `clicked` → `selectNodeInHome(index)`：
  - 组类型为 `Selector` 才提交；`URLTest`/`Fallback`/`LoadBalance` 只移动高亮（自动组不提供切换语义）。
  - 点中的成员已是当前成员、或忙碌/只读时不提交。
- `Enter`/`F5` 的既有快捷路径保留，语义与单击一致。
- 「恢复自动」按钮保留在自动组行内，文案仍随固定状态变化。

## 4. 验收点

1. 菜单一级项顺序与上面一致；`编辑配置` 为子菜单；「删除订阅…」在最后一段。
2. 菜单打开时只读头显示订阅名与运行状态。
3. 手动组单击成员后 `now` 变为该成员且只产生一次操作；自动组单击不改 `now`。
4. 无 `chooseMember` 控件；既有测试断言相应更新。
5. 完整 `ctest` 全绿。

## 5. 实际结果

**已实施并自动测试（2026-10-29）。**

订阅菜单：`aboutToShow` 里先填只读头（`<订阅名> · 运行中 / 已选用·未运行 / 尚未使用`），随后统一重排为只读头 / 常用动作（重新加载、回滚）/ 编辑配置 ▸（复用工具条同一个 `QMenu`）/ 对象维护（重命名、来源与更新、配置兼容性）/ 文件与目录（分享、上移、下移、更换文件、打开数据目录）/ 危险动作（删除订阅…）。

实现细节：重排时**不能用 `QMenu::clear()`**——它会 `delete` 全部 action，包括成员指针（`profileMenuHeader_`、`profileReload_`、`deleteProfile` 等），直接导致悬空指针与段错误。改为逐个 `removeAction` 后再按目标顺序 `addAction`。这个崩溃是跑测试时 3 个套件同时段错误暴露的。

首页节点区：删除 `chooseMember` 与 `chooseAction_`；`selectNodeInHome()` 只在 `Selector` 组提交，自动组仅移动高亮；点中当前成员不重复提交。`Enter` 保留同义路径。

复核：`ui_interactions` 的节点交互按新语义改写（单击即写入、Enter 不重复提交、后续计数改为相对基线）；`appearance_tests` 改为断言 `chooseMember` 不存在；完整 `ctest` 34 项中 33 通过、0 失败、1 跳过，112 秒。

**未验**：真实鼠标/键盘下菜单的实际展开观感与读屏顺序。
