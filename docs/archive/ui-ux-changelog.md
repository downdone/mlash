2026-10-21，F09 / 1.17.0：添加订阅新增节点链接来源；检查、仅含名称/类型/端点的预览、最终导入分步明确，不在粘贴时请求网络。已有订阅在节点编辑窗批量导入到草稿，不自动加入组或切换路由。导入失败保持原窗和输入；原生复核后收紧链接输入/预览高度并增加默认窗高，固定反馈/提交，小窗正文滚动。编辑窗明确运行版/候选版，来源变化时保留草稿并阻止陈旧提交。本地快照显示来源语义，禁用没有来源的更新/自动监测。设计与实测分别由ui-interactions、verification-report维护。

2026-10-21，U22 / 1.16.0：按U21专项方案统一任务层级。首页主摘要采用普通面板和具名导航，模式分段直达；代理压缩上下文、测量换行，固定当前选择与测试进度，节点保留主要空间。网站测速开始/停止同位，统计/阻塞共用单行，详情保留键盘入口；设置两列按内容顶对齐，窄窗口和大字号纵排。订阅操作归对象、规则工具归上下文、连接列与默认排序归组、日志可选本会话换行，托盘低频页面归“更多页面”。独立维护窗统一滚动正文与固定提交/反馈。普通hover、键盘焦点和持续选择区分，全应用覆盖独立弹窗；下拉保留既有view身份，避免换肤时销毁Qt正在遍历的对象。固定内核、状态/候选/草稿和轻量释放边界不变。设计见ADR0040和ui-interactions，实际通过及未验范围由verification-report拥有。

## 1.15.1 · M01 高频流程与刷新收敛（2026-10-20）

按先审视/先设计/后实现原则保留八页及固定状态栏。未变下拉和节点快照增量同步，维持预选、滚动与可用性；当前/待使用成员明确区分，延迟重测不切节点。导入失败留稿，文件导入不被URL高级草稿阻止；长错误纯文本省略并保留完整详情，在途关闭说明后台继续。备份先预览与选择，提交标明数量；需要停止时给直接入口，停止成功后仍须显式恢复，失败留稿。浅深/高对比、100/120%与实际DPR1.5/2.25原生复核通过。原样式体系和业务/系统权限边界保持，实际数值及未验范围见verification-report。
