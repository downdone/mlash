# Mlash 1.15.1 UI/UX 精修方案

> 历史归档：仅用于追溯当时的评审、阶段方案和决策过程。当前行为以 [交互契约](../ui-interactions.md)、[架构](../architecture.md) 和 [项目状态](../project-status.md) 为准；文中阶段状态不代表当前版本。

2026-10-21 · U21 专项设计 · **状态：已由产品要求采用，U22实施结果见[验证报告](../verification-report.md)，生效交互见[交互设计](../ui-interactions.md)**

本方案回答“日常使用是否清楚、顺手、精细”，不增加新业务能力。U21阶段只审视现有实现并形成可执行的改造与验收计划，没有启动日常实例、改用户数据、执行网络配置写入或提交产品代码。U22实施已把采用的设计合并到 [ui-interactions.md](../ui-interactions.md)，由它继续拥有生效交互契约；本文件保留问题、取舍、实施顺序和验收标准，不作为另一份长期产品规格。原规格、既有 ADR 的状态/恢复/权限契约保持。

## 1. 结论与设计方向

当前已经具备统一字体/主题、国旗、虚拟节点卡片、两列设置、固定状态栏、首帧圆角弹出、轻量释放和失败留稿。继续“换皮”或增加图标、卡片、提示，收益很小。主要问题是**同一信息多处重复、容器与按钮同权、工具区高于任务内容、设置说明密度不一致**。

采用一条主线：**状态看一眼，操作在对象旁，维护按需展开，结果原位反馈。**

- 首页聚焦实际运行、所用订阅、所浏览组的当前成员和实时指标，快速操作与页面导航分开。
- 代理页将上下文和工具整合，节点占主要空间；不改为同时展开所有策略组，也不把高频操作塞入“更多”。
- 测速保持网站身份与真实响应为主，详情降低视觉权重，开始/取消占同一稳定位置。
- 设置继续两列，按阅读与生效方式组织；统一行高和长字段，解决“长列表拼接”观感。
- 沿用当前中性灰白/蓝色家族，以字体、对齐、间距和真实状态建立层次，减少重复边框。

“macOS 的精细感”在本项目中落实为克制、相关分组、清晰层级、稳定反馈和键盘可达；保留 Windows 标题栏、鼠标右键、Tab/Enter/Esc 等习惯，不仿制 macOS 窗框。

## 3. 官方依据与适配取舍

2026-10-21 查阅 Apple 官方 HIG；HTML 入口需要 JavaScript，网页提供的 `.md` 官方正文通过只读请求获取。以下是适用于本项目的原则，不把 Apple 平台 API、点值或当前 Liquid Glass 建议直接照搬。

| 官方资料 | 采用原则 | Mlash 的具体适配 |
|---|---|---|
| [Layout](https://developer.apple.com/design/human-interface-guidelines/layout) | 按重要性排序、对齐/相关分组、渐进展示、适应文字与窗口 | 节点优先、两列设置可有序纵排；不使用模糊/玻璃背景 |
| [Color](https://developer.apple.com/design/human-interface-guidelines/color) | 同一颜色语义一致、浅深与高对比、状态不只用颜色 | 中性 hover；状态点配文字；Windows 系统主题优先 |
| [Typography](https://developer.apple.com/design/human-interface-guidelines/typography) | 少量字体、可读字重、层级稳定、文字放大时重排 | 保留 Segoe UI / Microsoft YaHei UI 和 10pt 正文，不装 SF 字体 |
| [Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility) | 键盘完整操作、足够命中/间距、多通道表达 | 可见键盘焦点、中文可访问名称、图标不独占语义；不据自动测试宣称读屏合格 |
| [Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons) | 最可能操作明确、用样式而非巨大尺寸分主次 | 每个任务区域一个主要动作，测试详情弱化；破坏动作不做主按钮 |
| [Menus](https://developer.apple.com/design/human-interface-guidelines/menus) | 常用优先、相关分组、避免过长/过深、图标有目的 | 托盘根菜单收敛，模式/组直达，次级页面按需导航 |
| [Settings](https://developer.apple.com/design/human-interface-guidelines/settings) | 设置以低频偏好为主，任务选项就近 | 本组偏好留在代理，下载策略留在订阅，不再复制到全局设置 |
| [Progress indicators](https://developer.apple.com/design/human-interface-guidelines/progress-indicators) | 反馈位置稳定、进度准确、可停止时说明后果 | 固定状态栏；只显示已有真实阶段/项数，未知时不造百分比 |

以上源事实与 Mlash 取舍区分：灰白色板、字号、间距和下列布局是本项目设计决定，**不是 Apple 强制尺寸或认证结果**。macOS HIG 不建议把关键控制依赖窗口底缘；Mlash 依据既有产品要求保留固定底部提交，同时提供顶部对象上下文和 Enter 快捷路径，并保证提交栏始终在屏幕可用范围内。

## 4. 统一结构与视觉规范

### 4.1 信息架构

八页名称、顺序与内部 ID 保持：**首页 → 订阅 → 代理 → 测速 → 规则 → 连接 → 日志 → 设置**。不增第九页、不按页面做第二套导航、不把导航首页重新变成六张等权菜单卡。

| 用户问题 | 所属页 | 高频入口 | 低频入口 |
|---|---|---|---|
| 现在是否在运行、谁管理代理 | 首页 | 已观测状态、系统代理/TUN、模式、启停 | 运行详情、显式出口诊断 |
| 配置从哪来、是否有更新 | 订阅 | 添加、更新、查看变化、使用 | 来源维护、回滚、删除、Provider/DNS/编辑 |
| 本组该用哪个节点 | 代理 | 当前组、搜索、排序、视图、测试、使用 | 筛选展开、本组偏好、提供者 |
| 这个具体节点对网站是否响应 | 测速 | 选节点、开始/取消、单卡重测 | 结果依据、编辑目标 |
| 这些流量应走哪条策略 | 规则 | 草稿编辑、匹配类型/目标、保存 | 原规则/提供者/高级文本 |
| 某个请求走了哪条规则与链 | 连接 | 活动/已离开、搜索、暂停、详情 | 列/搜索选项、关闭全部 |
| 为什么失败 | 日志 | 搜索、级别、暂停、复制、回到最新 | 脱敏导出、目录 |
| 改偏好或做维护 | 设置 | 两列分类、检索、固定应用 | 各有明确名称的维护窗 |

全局状态栏负责操作阶段、结果及恢复入口；字段错误属于字段，页面统计属于页面。不能为了让主页面干净，将所有错误只挪到状态栏。

### 4.2 视觉 tokens（拟采用值）

首先收敛到现有 `UiTheme`，避免各页单独 QSS。保留当前色系的具体值，新增的是控件角色和使用规则。

| 角色 | 浅色 | 深色 | 用法 |
|---|---|---|---|
| Window / Sidebar / Surface | `#F7F8FA` / `#EEF0F3` / `#FFFFFF` | `#191B1F` / `#22252B` / `#272A30` | 三层足够；不额外叠大面积灰底面板 |
| Ink / Secondary | `#1D1D1F` / `#60646C` | `#F5F6F8` / `#BBC0CA` | 正文与辅助；重要状态不用弱化色 |
| Border / Separator | `#DDE1E7` / `#ECEEF2` | `#454B57` / `#3B414C` | 容器轻边界与行分隔；避免边框套边框 |
| Brand / Primary / OnPrimary | `#0068D9` / `#0068D9` / `#FFFFFF` | `#88BEFF` / `#0064CB` / `#FFFFFF` | 选中/链接与主按钮背景分角色 |
| Selection / Hover | `#E9F2FF` / `#F2F5FA` | `#263E5D` / `#333A46` | 预选持续、hover 瞬态；hover 不改成蓝框 |
| Focus | `#0068D9` | `#9BCBFF` | 键盘来源的 2 DIP 清晰轮廓，不改变布局尺寸 |
| Success / Warning / Error | `#08745B` / `#965A00` / `#BF303C` | `#7AD7B5` / `#F2BF75` / `#FF9BA5` | 配合“已响应/过期/失败”等文字，不等于网络已解锁 |

高对比优先于手选外观：边框与分隔至少使用当前高对比 Border（浅 `#60646C`、深 `#B8BECA`）；状态与焦点不依赖微弱浅填色。文字/按钮/图形对比度按实际前景背景逐对验算，正文目标 ≥4.5:1，重要控件边界/图形目标 ≥3:1；禁用态有明确原因，不把禁用文字作为唯一说明。若固定色与系统高对比冲突，采用系统调色板角色；此为待实施验证要求，不声称现有色对全部通过。

| 度量 | 采用规则 |
|---|---|
| 字体 | Segoe UI / Microsoft YaHei UI；正文与辅助 10pt；页标题 15pt/600；分组 11pt/600；主要数值 15pt/600；普通名称常规字重，仅当前成员/重点值加重 |
| 字号比例 | 沿用 90/100/110/120%；不新增任意缩放，不为塞进窗口自动缩字；图标/命中区随字体下限增长 |
| 间距 | 4/8/12/16/24 DIP；页面间距 12，字段内 8，面板内 12–16；分组间 16–24，不到处加分隔线 |
| 圆角 | 面板 10、节点/网站卡 8、输入/按钮 7、弹出 8 DIP；不逐页发明圆角 |
| 控件 | 标准 32 DIP 起；按 `fontMetrics` 加上下留白确定最小高；120%可到 36–38，不裁字；图标按钮命中区至少 28×28，常用动作以32为基准 |
| 表格/节点 | 普通表格 30 DIP 起，虚拟节点卡54 DIP起；当前/预选/hover/focus是四种不同状态；名字省略、完整内容可读 |
| 图标 | 导航18、一般动作16、节点国旗约20×14等比、服务标记32容器内24–26；品牌资源不重画，不下载favicon；国旗仍仅按名称提示地区 |
| 外框 | 主内容每任务一个必要表面；工具栏可以无独立外框，不能用多重边界凑层级；取消强阴影、玻璃、渐变与动画 |
| 状态栏 | 固定一行，高度只在字体变化时重算；消息省略、详情完整/纯文本/可复制；不插入页内横幅 |

10pt 是当前实现值；不采纳旧文档的9pt作为本轮“紧凑”手段。所有 DIP 只缩放一次，描边按设备像素对齐；Qt 的文字比例与 Windows DPR 分开处理，测试记录实际 `devicePixelRatio`，不只记录环境变量。

### 4.3 交互角色一致性

- 主动作是明确“应用/使用/保存”，每任务区域一个实心蓝按钮；常规动作中性边界；浏览/详情为轻量入口。停止/删除/关闭连接不做蓝色主动作。
- 只有一个默认提交动作。普通工具按钮 `autoDefault=false`，防止 Enter 误执行停止/删除；字段编辑 Enter 不越过未通过的校验。
- 所有下拉箭头共享测量和绘制，右侧保留独立空间，垂直居中；拆分测速主区域直接测试，右侧只开菜单，命中互不重叠。
- 不用 `NoFocus` 消除焦点。鼠标/菜单返回不画键盘焦点框，Tab/Shift+Tab 恢复清晰焦点；控件内部编辑、方向键、Space、Enter、Esc 全保留。
- 只对有实际后果的丢稿、删除、接管外部代理、关闭全部等确认；不新增“保存成功”弹窗，不给每个轻量动作加确认。

## 5. 八页与托盘具体方案

### 5.1 首页：真正的运行概览

固定阅读顺序：**内核实际状态 → 网络控制 → 当前订阅/所浏览组 → 指标 → 按需信息**。运行状态不再把“运行中/就绪/可上网”混成一个判断。顶部蓝点旁显示内核事实，系统代理归属和 TUN 观察值分别呈现。

```text
首页                                      [规则 | 全局 | 直连] [停止内核]
┌──────────────────────────────────────────────────────────────────────┐
│ ● 内核运行中           系统代理  [开关]            TUN [开关]          │
│ 系统代理：由其他程序管理 / 已由 Mlash 接管 / 未知                      │
├──────────────────────────────┬───────────────────────────────────────┤
│ 当前订阅              [订阅›]│ 浏览组：[示例订阅 ▼]        [查看节点›]   │
│ 示例订阅                       │ 当前：🇯🇵 日本专线 2       248 ms     │
│ URL订阅 · 最近获取10-20 21:45 │ [选择组内成员… ▼]                      │
│ 有更新待使用 [查看变化]       │ （需要手动固定时显示真实固定状态）      │
└──────────────────────────────┴───────────────────────────────────────┘
```

这是结构草图，数字是示意，不是新运行证据。实际布局可将状态与主摘要做独立相邻面板，但不得再出现“外层大框+内层同样大卡”的双边界。

具体决定：

- 订阅摘要可保留整卡路由，内部不嵌输入/动作；若有“查看变化”，该卡也改普通容器，用明确“订阅”入口导航。两种做法不能在同一张卡混用。**当前成员面板一定是普通 QFrame，不是整卡按钮。**
- 浏览组只在组合框标签表达一次；已观测当前成员一行、快速选择一行。快速选择弹出显示组成员，激活后调用既有 `selectMember` 并回读，等待时显示“正在切换”；不把临时预选冒充当前。首页为快速操作，代理页用于比较/筛选/排序/批量测试与候选确认。
- 规则模式标“浏览组”，不虚构全局当前节点；全局固定 GLOBAL；直连模式收起无效组/成员输入，写“直连 · DIRECT”。LoadBalance 等无法解析叶子时展示真实组当前信息与明确未知，不挑一个假节点。
- 页顶模式统一使用现有分段控制，三项常用且无需下拉；较窄时与内核动作换到下一行，不缩字号。系统代理与 TUN 各有名称，不能共用一个“连接”开关。
- 内核已启动但尚未就绪显示“正在确认内核”，不让主标题“运行中”掩盖不可用；启停阶段来自已有状态机，不新增业务状态。
- 首次无订阅：单一“添加订阅”引导；已导入未使用：单一“选择订阅并使用”；内核停止：显示所用订阅、启动操作，未知指标不放四个假0。只在用户设定的展开/布局条件变化时重排，不随普通成功/错误插行。
- 默认940×620/100%/更多收起：状态、主摘要及四项指标可读且不被状态栏遮挡；840×560或120%允许原有纵向滚动，快速操作和指标完整可达。保留产品默认小窗，不扩大默认窗口掩盖布局。

### 5.2 订阅：围绕版本，不围绕按钮

顶部添加为主动作；剪贴板导入常规文字按钮，批量更新按现有多选规则执行。列表是内容主体，对象工具与列表保持同一上下文。

```text

  backup              文件快照          10-19 10:00          可使用
维护状态：…（固定一行，错误可读；无任务不重复解释每个按钮）
```

同一份订阅按真实状态呈现“使用此订阅 / 应用更新 / 当前已使用”。当前且没有新候选时不放一个可重复重载的蓝按钮。文件来源的“同步原文件”保留直接动作；“更换文件”进入行菜单/来源维护窗，避免常驻五个同权按钮。低频重命名、顺序、回滚、删除、节点/DNS/Provider编辑继续右键与 Shift+F10，可在“来源与更新”旁用对象菜单提供可发现补充，不复制到页底。

“更新只准备新版本”在首次使用/确有候选时就近说明，常态缩为“有更新待使用”；不反复占两行。来源失败、候选失败与运行失败分开；不显示token。刷新保留多选和滚动，更新时可继续浏览，不把整表禁用。

订阅/组可在足够宽度时共用上下文行；草图分行表示逻辑分工，**不是要求新增第三条常驻工具栏**。具体布局目标是当前的订阅行+组行合为一条紧凑上下文区域（最多两行），搜索工具一行；没有额外标题重复“策略组”。候选到达只更新预留动作槽，不追加提示行或挤高上下文区。低频组切换仍默认折叠，常用组优先，展开时是受限高度的原虚拟组选择区；确认组后收起，不改成所有组和节点同时展开的长页面。

布局验收指标：940×620 DIP、100%文字、筛选/组列表均收起且无候选提示时，**节点 viewport 高度至少占代理页可用内容高度的60%**（分母为页面标题下到页内选择栏上的空间，不含侧栏/全局状态栏）；同时记录像素高度，不能通过缩小分母隐藏工具。相同条件比1.15.1节点高度增加，目标至少多一整行54 DIP；若不满足先调间距/容器，不能缩字。840×560/120%不硬套60%或同时展示全部工具：允许工具带按逻辑换行、选择栏两行，但至少可操作两行节点；筛选/组展开本就占暂时空间，单列记录，不伪装满足收起指标。

- 搜索、默认/名称/延迟排序、卡片/表格切换、测试本组始终直接可达；最近选择保留明确入口，不以一堆无标签图标替代。窄时换行，控件按 measured sizeHint 分配，不卡箭头。
- 取消节点区与外层面板重复灰底，只保留一个轻边界/内容表面。卡片继续54 DIP起，一行名称与右对齐延迟；三列须满足每卡可用宽度和命中区，窄时两列。无需每卡再加“…”按钮，收藏/详情等低频保留上下文菜单。
- 名称区域单击只预选；使用按钮/Enter/双击按既有契约提交。子组标箭头，进入与使用该组不同命令。延迟区域 hover 显示轻底+手型，点击只测该节点；未测“—”和失败均可重测，不改变预选/当前；按F5为可访问补充。
- 当前用点/字重，预选用浅底/边界，hover用中性浅底，键盘焦点用独立轮廓；不能把当前和预选全用同一个蓝块。失效/60秒旧结果标为旧并保留真实时间，不因为同色而冒充刚测。
- 页底固定当前/待使用摘要，长名称中间省略、完整可读；确认后才更新当前。测试中只禁用重复测试，筛选、排序、滚动、详情和取消继续可用。

- 卡片最小宽度拟236 DIP、间距12，列数按实际 viewport 和文字测量决定，最多3列；默认940/100%争取3列，840/100%通常两列，120%按实际长名称/动作宽度降列，不以隐藏主机/压小字硬塞。卡片高度100 DIP起，允许文字放大增长；同一行等高，留白不靠固定空白占位。
- 节点下拉只在身份变化时更新模型；刷新、主题变化、单卡结果不会关闭popup或改变手选节点。切节点依既有契约清旧结果，UI清楚区分本页测试节点与代理页运行选择。

### 5.5 规则：编辑方式和生效对象先讲清楚

上下文行：订阅选择、规则提供者；编辑方式行：`自定义规则 / 当前内核规则`，在自定义页同一行提供“列表编辑与来源…”，不独占整行造成第二层工具栏。

基础快捷输入继续中文+原标识，用独立 itemData 保存；较窄类型框优先显示中文短名，完整 `DOMAIN-SUFFIX` 在popup/tooltip/可访问描述，不裁成难辨代码。主输入按类型改变placeholder。文本入口保留，不在本轮强制切结构化模式或暗改草稿往返。

“当前内核规则”明确对应正在运行订阅；正在编辑另一份订阅时给出短标签，不把API结果混入其草稿。底部固定草稿状态、还原和保存；匹配顺序/MATCH影响在必要说明或来源编辑处可读，不同时显示多个技术段落。字段错误定位行/单元格，状态栏保留完整失败；保存失败继续编辑，跨页/轻量关闭保护草稿。

### 5.6 连接：先观察，再处理

第一行累计/速率与暂停、关闭全部；第二行活动/已离开并列页签和主搜索。搜索选项Aa/整词/正则可以紧邻搜索形成一组轻量状态按钮，不能全做同权大框；“列与视图…”收纳列配置/恢复默认顺序，已排序表头继续表达排序，不再常驻一个大“默认顺序”按钮。

默认仍是目标、网络、命中规则、链、上传/下载、速率、状态七列，不本轮擅自重置用户已保存的15列视图。宽度优先目标与规则，数值对齐；完整链在详情，不能为了少列丢失关键命中规则。暂停明确“已暂停 · 快照时间”，不继续展示旧速率为实时。刷新失败清当前快照并保留最后成功时间的既有语义不变。

底部固定详情/复制/关闭选中，双击/右键补充；选中对象消失时无效动作禁用，并可知原因。添加规则/跳到代理继续只预填或浏览，不隐式保存/切节点。“已离开”不改名“已关闭”，关闭ID回读消失不假报TCP原因。搜索无匹配、无活动、未就绪、失败分开空态。

### 5.7 日志：阅读优先，原文复制准确

搜索、级别、暂停、复制、清空视图、诊断工具保持一条工具带。缩减页标题旁对任务的重复解释；页底一行显示暂停/跟随状态、行数/上限，“回到最新”保留直接入口。可以在诊断工具加入本会话“自动换行”，默认保留当前NoWrap，开启仅改变显示；不截断文本、重排内容、写用户日志或改复制原文。是否落地换行由长行实测决定，属于UX-P2，不阻塞主要四页。

复制错误/历史选区、用户滚动位置优先于自动跟随；新日志只在原位尾部且无选区时跟随。清空只清视图，导出仍脱敏。辅助文字和日志内容使用不同层次，不为让日志“好看”隐藏时间、来源与错误。

组菜单保留常用置前、当前勾选、国旗/延迟；自动测试沿用300ms停留、60秒缓存、三并发与关闭局部取消。右侧结果列原位变化，不重建菜单/改变活跃项，不因测速完成跳到顶端或扩大为多列。超长名称省略且完整可读，长列表单列滚动，不承诺123项全部一屏可见。无主窗口首次打开也使用同一主题/字体/圆角与键盘操作。

## 6. 重要弹窗与完整任务状态

### 6.1 弹窗结构

所有维护窗使用同一顺序：**名称/对象上下文 → 可滚动任务正文 → 预留错误/前提区域 → 固定动作区**。窗口不因请求完成、错误长度或展开内容自动改变外部尺寸；可由用户调整尺寸，最小尺寸受当前屏幕约束。错误纯文本，长错误单行省略并有完整详情/可访问描述；输入错误就近指出字段，不能只弹一个模态错误盒。

| 弹窗 | 本轮精修决定 | 保留的任务与安全边界 |
|---|---|---|
| 导入 | 文件页取消大块拉伸空白；来源/名称/必要说明连续；高级下载按需展开，主体滚动而不是撑窗 | URL默认遮蔽；显式提交；失败保留来源/名称/下载草稿；文件不被隐藏URL校验阻断 |
| 订阅来源/更新/变化 | 标明来源、已使用/新候选；比较摘要在上、名称明细滚动；应用一个明确主动作 | 旧比较过期拒绝；失败保留旧运行与候选；不显示定义/凭据 |
| 备份恢复 | 选择列表为正文主内容；“需先停止内核”与“停止内核”放前提区；底部预览/恢复N项/取消，不让停止和恢复同权 | 停止不自动恢复；SHA/密码变化废弃预览；保留选择、同名新增、不覆盖现有数据 |
| TUN | 服务观察/运行观察/意图区分；启用/栈/严格路由优先，诊断详情按需 | 缺服务/核心不匹配/待清理各给下一动作；UAC取消留稿，失败不假报关闭 |
| 内核管理 | 当前版本与待应用版本并列、来源/SHA明确；检查→下载/预检→应用按阶段启用 | 官方/本地补丁不同；不静默替换默认内核或放宽TUN固定SHA；失败保留旧版本 |
| DNS/节点/链/规则集 | 常用表单/高级文本用同一草稿，单项编辑少装饰；流向和引用影响先可读 | 未触及字段保留；解析同步中禁提交旧稿；过期快照拒绝；不额外重启或改源YAML |
| 连接/测速/服务依据 | 快照身份、目标、时间、规则/链、结果分组；复制固定 | 原始依据可滚动/换行/完整复制；未知不伪造；离页/隐藏按既有生命周期清理 |
| 本地/WebDAV备份、Geo、快捷键 | 分组说明简短、长列表滚动、固定提交，工具项使用一致动作样式 | 保留计划/手动任务边界、取消范围、密码遮蔽、录制零网络动作与失败恢复 |

### 6.2 五条日常任务链与异常状态

以下是呈现契约，状态仍来自现有 Controller/任务对象，不另造业务状态机。

| 任务 | 正常链 | 在途/禁用与取消 | 失败、过期与恢复 |
|---|---|---|---|
| 添加订阅 | 选择URL/文件→校验格式→导入并校验→订阅选中新项→明确使用 | 提交锁本窗冲突字段，不锁全应用浏览；“关闭”明确导入继续，不能写“取消任务” | 原地持久错误、留稿可重试；成功不自动接管/启动；无关busy拒绝不结束本窗任务 |
| 更新/使用 | 更新来源→新候选→查看变化→应用更新→实际回读 | 下载进度/阶段固定位置；停止后续批量与取消当前请求区别；不因更新成功换运行版 | 下载失败保留旧版；候选变动需重新比较；应用失败显示恢复旧版实际结果，不把恢复成功改写成操作成功 |
| 选节点/测速 | 选组→搜索/排序→单击预选→需要时测试→使用→回读当前 | 单卡delay点击不选择；测试期间可浏览/排序/取消，冲突写入受控；自动组固定状态明确 | 失败保持实际当前与预选，原因可复制；当前即所选不重复写；旧测试回调不能污染新组/新目标 |
| 测试网站 | 确认具体节点→整组或单卡→排队/测试中→响应/超时→依据 | 只禁重复测试与测试节点修改；停止保留已完成；离页/隐藏取消未完成；轻量重建不自动测 | 错误不称“封锁/未解锁”；403可已响应，HTTP状态未知照实；换节点清旧归属，不混代理缓存 |
| 改设置/恢复备份 | 编辑→N项待应用→应用/预览选择→校验→保存/恢复 | 窗口释放先保护未保存内容；提交在途不能释放其受保护编辑；停止/恢复分两次明确操作 | 设置失败留稿定位；恢复失败保留选项和现有数据；停止失败不解锁恢复；旧快照不可覆盖新设置 |

补充通用状态：

- **未知/无数据：** 用“— / 尚未检测 / 内核未就绪”，不以0替代未知；搜索无匹配提供清筛选，非自动清掉用户条件。
- **禁用：** 必须知道原因：未就绪、只读保护、任务冲突、无改动或尚未选择。说明靠近任务对象；tooltip作为补充，键盘可访问描述同样可读，不只依赖hover。
- **只读保护：** 固定状态栏保持保护原因和日志/诊断入口；普通成功反馈不能覆盖保护错误。可查看与复制，业务写入保持Controller拒绝。
- **长操作：** 有实际项数显示项数，只有阶段则显示阶段；不发假百分比，不增加一个常驻动画线程。取消范围用明确文案，不假装回滚已经提交的写操作。
- **关闭与轻量重建：** 已保存结果/会话书签按现有边界恢复；QObject全部释放，隐藏采样停止，授权后台任务由Controller继续。不能为了保留精美界面缓存第二套页面或延迟销毁所有窗口。
- **确认与回退：** 只在丢草稿、接管外部代理、删除/关闭全部等真实后果确认。退出恢复失败保留程序与日志、明确重试路径；绝不设计“忽略失败并强制退出”为默认主操作。

### 7.2 低资源边界与比较方法

沿用 M01 的虚拟视图、有限图标键/名称识别缓存、增量更新、局部取消。UI精修不得增加逐节点QWidget、隐藏页定时采样、无限图标/结果缓存、网络favicon、强制GC/工作集裁剪或定时重启。节点资源仍51地区+4回退；网站目标仍既有最多24；Controller workers/请求并发/超时不因布局更改而扩大。

实施后对照1.15.1同一核心/500节点夹具/同主机/同Qt/相同操作计划，两种GUI生命周期分别记录十分钟Private Bytes、Working Set、CPU、打开下拉/切视图与六次关闭重建；对比过程不得边测边build。先保存操作与环境指纹，再解释变化；至少一次相同条件复测以区分噪声，若重测仍回归则优化或撤回。原预算55MiB保持原口径；**本方案不宣称达到，1.15.1一小时样本仍超过目标**。内核内存单列；不把十分钟/一小时样本推为72小时稳定，也不把菜单准备时间冒充系统托盘点击/绘制延迟。

## 8. 风险、刻意不做与设计原则复核

| 风险/取舍 | 约束与应对 |
|---|---|
| 过度精简使功能难找 | 保留搜索/排序/视图/测试直达，详情始终可键盘到达；低频采用有名称的入口，不只有右键/hover |
| 同时改八页导致回归 | 按完整任务批次、既有命令/状态不变、先局部再整体，不重写Controller或存储schema |
| 把圆角和蓝框修复变成第二套样式系统 | 只在UiTheme/WidgetStyle归一，不用逐页QSS覆盖；首帧/无主窗托盘一起验 |
| 更紧凑造成文字/命中太小 | 不缩10pt正文；用测量、换行、降列、滚动解决；840/120%不硬套大窗空间比例 |
| 首页快速切换误改变运行 | 明确浏览组、操作对象和当前回读；普通面板承载输入；测试页的节点选择仍只改测试上下文 |
| 固定栏隐藏错误 | 字段级错误保留；状态栏全文/处理入口；普通成功不清保护错误，长文本纯文本省略且完整可读 |
| 维护弹窗视觉改动破坏事务 | 不改恢复前提/候选/LKG/原始YAML/OS所有权；已提交写入取消与关闭区别继续明确 |

本轮刻意不做：重画吉祥物、SF Symbols/SF字体复制、自绘窗口标题栏、Liquid Glass/模糊/持续动画、主题插件、网页/QML替换、同时展开全部策略组、给每节点添加新操作按钮、假测速曲线/可用率、TUN/系统代理语义扩展、自动公网探测、再增加导航页、为了美观改默认网络设置。

原则复核结论：

1. **整体任务与层级：符合方向。** 从状态→配置→节点→验证→诊断组织，不再以“每个功能一张卡”堆首页；实施须按四页草图和任务状态验证。
2. **简约与可发现：有明确取舍。** 减重复边框/说明/详情权重，保留常用直达；托盘低频导航新增一层，常用网络控制不加深。
3. **状态真实：契约保持。** 实际状态/意图/就绪/健康、当前/预选/候选/草稿均独立；网站响应和服务解锁不混。
4. **输入与适应：方案覆盖。** 鼠标无焦点残框且键盘可见；浅深/高对比、文字/实际DPR、小窗、长字段与窗口释放纳入验收，不把文档写完当通过。
5. **安全与资源：边界保持。** UI只调用Controller，原恢复事务/本地补丁内核/TUN固定边界不变，无额外隐藏采样。无VM系统写入、72小时及人工读屏继续独立未验。
6. **工程流程：本轮只完成先审视与先设计。** 集成者登记U21、维护文档索引/状态；进入实施前先归并生效契约，每批实现后对照本方案并记录验证结果。方案不等于已实现或发布合格。
