# ADR 0005：首页与代理页分工

2026-10-13，接受。设计目标导航为首页、订阅、代理、设置，并强调紧凑、清爽。

原四页中的诊断改为辅助入口，新增首页汇总状态与全部策略组；代理页负责选择订阅、策略组和具体节点。
原规格保留，新信息架构以 ui-interactions.md 为准。

首页不新增常驻网络订阅或持续测速。复用原成员 REST 刷新，首页/代理可见时启用，离开或隐藏停止。
模式、Core ready、系统代理归属和单次节点延迟保持独立语义；无数据的流量、到期、健康比例不显示。

代理页选择订阅只是操作目标，必须明确点击使用并完成原事务，才展示该订阅节点；不能以旧运行节点冒充新选择。
诊断只在辅助页可见时订阅日志。窗口、菜单和页面调用同一 Controller，保留无 WebView/QML 的 Widgets 路线。

采用轻量静态浅色主题，原生键盘语义、静态绘制线条图标与滑动开关。深色、高对比、其他 DPI 和无障碍验收独立记录。
