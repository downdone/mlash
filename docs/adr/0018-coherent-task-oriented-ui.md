# ADR 0018：面向任务的整套 UI/UX

日期：2026-10-14。状态：接受。设计目标结合标注反馈整体梳理七页，替代 ADR 0008/0017 中过度收纳常用操作的部分交互；保留紧凑视觉、9pt 正文、轻量生命周期和实际状态契约。

交互以六条原则约束：页面有单一主要任务；常用动作直接可见；对象动作紧邻对象；浏览与写入分开；技术值配中文解释且底层标识保持不变；空态/任务/失败/草稿各表达真实含义。菜单只放命名清晰的低频管理或高级工具，不按“简约”隐藏日常动作。

首页汇总实际状态，直接呈现模式选择、系统代理和内核启停，移除重复日志入口及模式摘要。订阅工具栏显示更新/同步原文件、更新设置与使用新版本；本地同步复用来源刷新事务，只生成候选；更换文件/重命名/回滚/删除收进订阅管理。当前订阅无新版本时不能误示需要重新激活。

代理页先选订阅，再选策略组和成员；只有待切换或有新候选时显示使用动作，运行版本与候选分开说明。测速/其他后台命令只锁定冲突写入，节点、策略组、搜索、排序、复制与详情持续可用；取消测速直接显示，进度紧邻测速控件。

规则类型以中文 + 原标识显示，内置目标为直连 DIRECT/阻断 REJECT；自定义组名称不翻译。组合使用 itemData 输出准确语法，手工输入仍允许真实组名。连接全关为页面级动作，详情/复制/单关为选中行级动作；恢复排序就近表头工具栏，双击/右键为补充入口。关闭全部继续明确确认与真实 GET 回读。

设置保留启动/内核分组，但固定底部应用/还原及工具入口；未修改时不允许无意义应用，未应用草稿保持。日志的暂停/复制/清空视图直接可见，导出/目录使用明确的诊断工具菜单。七页统一空态、截断提示、焦点/键盘、按钮命名与操作反馈；危险操作与主任务分开。

这些调整不添加持续动画/模糊/WebView，不自动激活更新，不增后台连接采集，也不改变系统代理接管/恢复的权限和确认条件。

测速在代理页用就近进度，其他页用全局反馈，避免双份显示。用户明确取消是正常结束，清空普通错误、保留已得结果，与超时/节点失败分开；内核仍可能把已开始的短测试运行至其有界超时。
