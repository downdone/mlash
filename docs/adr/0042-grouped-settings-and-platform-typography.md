# ADR 0042：单列分组设置与平台排版

2026-10-28 · 接受。替代 ADR 0022、0040 中的两列设置与固定 Windows 字体呈现决定，其余业务、事务和输入语义继续有效。

## 原因

macOS 构建和八页截图审视发现，固定 Windows 字体、同权边框和双列设置在文字放大时降低可读性。用户明确要求按 Apple 风格精修，并提供系统设置及另一桌面工具作参考，要求提取长处而非复制。

## 决定

设计依据由 [U01 审视](../ui-apple-review.md) 维护。采用连续侧栏、平台 UI 字体与等宽字体、语义色和明确按下态；设置采用最多 760 DIP 的单列滚动分组，固定草稿/还原/应用栏。规则、连接和日志工具带按实际宽度换行，首页摘要工具的正文可滚动。字体、尺寸和配色继续由 UiTheme 统一拥有。

保留 Qt Widgets、原生系统标题栏、中文界面、已有图标与所有 Controller 命令；不引入 SF 字体文件、玻璃模糊、动画、WebView、QML、数据格式或额外后台请求。单列增加纵向滚动，以明确分组和设置搜索补偿；高密度数据页仍使用虚拟表格/卡片。

## 验证边界

八页空态/填充状态、浅深色、三种窗口尺寸、100/120% 文字、工具窗口、下拉首帧、焦点、草稿、状态栏及按下反馈使用隔离平台与本地 HTTP 夹具检查。未运行的原生人工、Windows 实机与发布资格保持未验；详见 [验证报告](../verification-report.md)。
