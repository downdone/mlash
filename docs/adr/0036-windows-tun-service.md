# 0036 · Windows TUN 权限服务

2026-10-15；设计目标“参照 clash，实现 TUN 服务”，据此取代原规格和 ADR0029 中仅关于 TUN/权限服务的排除项，其他工程边界继续适用。原规格保留。

## 决策与验收

GUI 保持普通用户权限；单独的 MlashTunService 由用户在设置中显式安装/移除并触发 UAC。Windows SCM 按需启动 LocalSystem 服务，安装资产进入 Program Files 的受保护目录。只有安装时绑定的账户可以通过本机命名管道控制一个运行会话；服务只执行固定哈希的随包 mihomo，不接收任意程序或命令行。普通模式仍由现有 QProcess/Job 管理。

TUN 默认关闭，受控配置覆盖来源 tun：固定 Mlash 设备、自动路由/出口检测、DNS 53 劫持，支持 mixed/system/gvisor 栈和严格路由选项。启停通过 Controller 既有配置事务，先校验、停止旧运行、启新运行及核对配置/实际接口和默认路由，成功才保存；失败恢复旧配置。下载候选不被启停设置消费。服务缺失/账户不符/内核哈希不同拒绝启用，不退回假成功。系统代理保持独立意图与原有恢复日志，不隐式覆盖外部代理。

服务 IPC 限定帧大小/时间、拒绝远程连接，客户端核对服务 PID，服务核对客户端 SID；本机固定磁盘源快照在客户端模拟身份下读取，只写受保护新会话目录。禁止重解析点及任意文件名，只复制 config.yaml、冻结 Provider 与 Geo 文件。配置再次按受控合成契约检查。核心在挂起状态进入 kill-on-close Job 后才恢复执行；连接断开、心跳过期、服务停止/崩溃均结束会话。结束时先请求内核关闭 TUN，再终止 Job 并核对接口/路由；恢复标记只有实际确认清理后才删除，失败保留。GUI 释放不会断开 Controller 所拥有的会话。

权限内核的完整 REST API 不向 GUI 开放。服务重新分配私有端口/Secret，TunApiGate 只开放实际使用的查询、成员选择/清除、模式和连接关闭；拒绝升级/重启/完整配置/Provider 写入和未知路由，避免借受控服务执行任意核心或追加监听。公开控制端口属于服务 PID，Mixed 属于核心 PID，分别核验。固定目录/安装文件由 Administrators 所有且普通用户只读，会话目录仅 SYSTEM/Administrators 可读写；不会给原安装用户隐含的文件所有者改 ACL 权限。

Native 管道连接在 worker 使用特定数据权限并显式允许模拟，不请求创建管道实例权；RAII 跨线程移交或取消关闭句柄。核对 Qt6.10.2 的 qlocalsocket_win.cpp 后避免其忙管道时同步 WaitNamedPipe 的5秒等待。单实例/first-instance/SCM PID 校验共同防止假管道取走快照请求。断线后 idle 仅在旧会话完整结束后确认清理，不关闭其他实例的会话；未确认停止不自动重启、不完成退出。源 IPv6 开启时配置受控 ULA 网卡地址并检查 IPv6 默认路由覆盖，IPv4 自动路由与网卡 DNS 设置亦需观察；这些观测不等于公网可达或服务解锁。

自动验收覆盖默认关闭/配置覆盖/恶意路径、协议预算、服务身份失败、启动/回读/取消/掉线/回滚与轻量生命周期；默认测试禁止安装 SCM 服务或改变宿主路由/DNS/代理。实际 UAC、驱动创建、路由/DNS 恢复及断电/休眠需要受控 VM 实测，未运行前明确标记未验证；不以模拟测试冒充系统级通过。

实现补充（2026-10-16）：私有 API 必须在连接建立后核对 TCP 四元组对应的内核 PID，认证随后才发送；停止请求也遵循此顺序。绑定账户只有有限进程查询/等待权限，不能读取内核私有凭据。服务快照禁用 Geo 自动更新；TUN 关闭时的栈/严格路由偏好不重启普通内核。移除服务前必须确认旧会话清理完成，未解决的恢复标记会阻止移除。

F08授权后的高级控制（2026-10-16）：按ADR0037扩展受控MTU、CIDR排除和DNS接管选择；字段预算/回读与兼容契约由api-contracts维护。服务设备名、固定核心与账户会话边界保持。新增明确UAC修复和idle清理确认，不能清理其他客户端/外部网卡。实际系统验收继续单列。

参考：本地 Verge 2.5.9 的 feat/tun.rs、enhance/tun.rs、core/service.rs；其外部服务 IPC 为 2.7.6，未直接复制外部服务实现。Win32 契约：[命名管道](https://learn.microsoft.com/en-us/windows/win32/ipc/named-pipe-client)、[Job 生命周期](https://learn.microsoft.com/en-us/windows/win32/procthread/job-objects)。
