# ADR 0010：小象吉祥物与轻量 GUI 生命周期

2026-10-13，接受。设计目标可爱小象 Logo，并增加关闭窗口释放 GUI、托盘重新渲染的轻量模式。

品牌改为圆耳、圆脸、卷鼻的小象，蓝灰和柔粉细节保持极简界面配色。仍由 resources/mlash.svg 拥有，生成 PNG/多尺寸 ICO；替代 ADR 0009 的双路径 M 品牌，七页导航/规则/连接契约不变。

设置增加 lightweight_mode，默认 true（旧状态缺字段也采用 true）；false 保留关闭仅隐藏。GuiHost 在非静默首次展示或托盘请求时创建 MainWindow，轻量关闭接受事件并删除窗口，所有窗口子对象/表格模型/页面定时器随之销毁；规则/连接 UI 快照清空，旧在途响应因可见性代次丢弃。QPixmapCache 清理。

Controller、内核、托盘、QApplication/平台插件及必要图标继续存在。Qt/系统分配器不一定立即降低工作集，因此不承诺卸载 Qt DLL 或指定内存降幅。

GuiHost 只保留页面号与几何位置；快速重开等待旧窗口完全销毁，避免新窗口被旧析构逻辑停止订阅；退出/清理撤销排队重开。有未保存规则/设置时提示丢弃或取消；无托盘时关闭仍走安全退出，不能将程序藏入不可访问状态。

后台 Controller 操作不因 GUI 销毁被取消；重新创建从实际状态渲染。功能/生命周期测试优先于未经验证的性能数字，证据见验证报告。
