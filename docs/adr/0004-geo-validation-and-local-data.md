# ADR 0004：Geo 校验与本地数据

2026-10-13，接受。

实际订阅包含 GEOIP 及其他 Geo 依赖。mihomo -t 会联网初始化，单项下载允许 90s；客户端原 20s
截止会提前杀死校验。数据源连接失败又被笼统超时隐藏。每次生成新 work 目录也丢失已有数据。

将异步校验总预算改为 360s，保留有界输出和退出取消，超时和取消分别报告；不把未知配置输出直接作为进度日志。
相同 geox-url/geodata-mode 的版本复制已用 Geo 文件；固定允许名单，不复制数据库缓存或符号链接。

提供脚本将用户已有 Geo 文件导入用户目录 geodata，记录 supplied-local 来源与 SHA256；默认 Geo 源配置
可使用这些明确提供的离线快照，自定义 geox-url 不使用它们。内核继续验证实际使用的文件。
不静默换在线镜像，不复制节点订阅或其他应用配置，不在公开发行包中捆绑本机数据。

离线快照不会自动追随在线数据变更；再次导入更新，既有版本保留已验证副本。公开数据自动分发仍需独立来源、许可与更新设计。
