# ADR 0035：常驻操作状态栏

用户指出全局反馈面板显示/隐藏会挤动界面，要求将这类消息和状态放入状态栏。以本决策替代旧设计中“空闲隐藏操作提示条”和代理页不显示全局测速摘要的呈现方式；业务命令和状态语义不变。

QMainWindow底部常驻QStatusBar，八页共用。高度按当前字号一次计算并固定，消息更新、换页、成功超时不改变主体可用空间；只有用户调整字号时重新计算。状态单行显示，换行转为空格、超长省略，完整内容保留在提示和详情中。右侧“详情”常驻，弹窗使用纯文本，可选中或点击复制消息。没有额外动画、轮询、通知历史或磁盘存储。

现有operationStarted/operationFinished/delayProgress与stateChanged继续驱动：执行时显示阶段，成功保留约3秒后显示空闲内核/本地地址，错误保持到后续操作或状态替代。readonly/lastError仍优先，节点列表原有就近进度保留。窗口销毁释放全部控件和局部定时器，重建时状态栏重新创建，Controller事务继续独立运行。

验证以八页主体/页面栈/状态栏的几何边界为准，覆盖进度、失败、成功、长文本、多行、三秒复位、切页和详情；原生截图与字号/主题适配另见验证报告。未更改系统代理、内核或持久化schema。
