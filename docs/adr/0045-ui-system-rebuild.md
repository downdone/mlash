# ADR 0045：界面系统重构方向

2026-10-29 · 拟定，未实施。本 ADR 替代 ADR 0042 中「页面标题位由页签替换」与 ADR 0043 中「分区页签常驻标题位、设置三分类、首页六卡仪表盘」的呈现决定；两者的分组排版、任务归属原则、状态与事务契约继续有效。ADR 0044 的设置即时提交与内核历史不受影响。

## 原因

用户要求对整体 UI/UX 做视觉、逻辑、布局与功能结构评审，参考 Apple 设计原则，允许推翻既有设计。两条独立评审线（信息架构、视觉系统）分别以实际代码为证据，交叉核对后指向同一批根因，而非孤立缺陷：标题位被页签劫持、首页六卡是第二套导航、每个容器都描边框、状态没有单一答案。仅调色或微调控件不能解决这些结构问题；反之，结构不改时重做视觉体系也会被布局决策抵消。

## 决定

**采纳两个层次的推翻，分阶段实施。**

结构层：以单一导航模型取代页号驱动；恢复可见的页面标题，规则与连接的子视图降为页内分段控件，取消「标题槽位替换」机制；删除首页六卡网格，改为状态优先的单焦点首页；设置固定分类并把备份、Geo、存储等长流程任务移出为「维护」；侧栏底部常驻状态条承载核心、代理归属、TUN 与当前订阅；状态栏只承载跨页操作结果，页面级错误就近显示。首页节点仍只预选，显式「切换」才提交。写命令继续经 Controller 串行化，候选与运行版本、系统代理归属、TUN 权限与恢复边界不变。

视觉层：保留语义角色名与浅/深两套骨架，重设 token 层——颜色成为三套平行 token（浅、深、高对比），高对比不再只加深边框，而是同时增强选中、控件填充、轨道、状态色与焦点；交互状态改用 accent 叠色阶梯（悬停、按下、选中各一档，选中另加 2px accent 条），不再依赖 1.05–1.35 的微弱色差；字号阶扩为七档，取消「一个大数字字号包打全部」；间距与圆角收敛到 8pt 网格与四级圆角；控件几何随文字比例缩放，不再只放大字号；焦点环、chevron 与状态点各自统一为单一绘制器；所有硬编码颜色与内联样式回归 token。

**不做的事**：不引入 WebView、QML、动画框架、模糊材质或第三方控件库；不改变 Controller 命令、持久化 schema、平台能力与恢复语义；不重写原始规格，只以本 ADR 与 [U05 方案](../ui-system-review.md) 记录接受的偏差。

## 实施顺序

S1 地基（token 与状态，风险低）→ S2 结构（导航、首页、设置，需逐页复核）→ S3 一致性（控件状态、工具窗口、托盘）→ S4 收尾（图标、缩放几何、深色资源）。S1 可独立发版；S2 起每阶段须更新交互契约与验证报告，未执行的真实系统测试保持未验。

## 验证边界

每阶段按交互契约的完整任务链做隔离复核：空/加载/成功/失败/取消、候选与运行版本、窄窗、90–120% 文字、浅/深/高对比、鼠标与键盘、轻量重建。本 ADR 与 [U05 方案](../ui-system-review.md) 的证据来自只读代码评审与静态对比度计算，未运行应用、未截图、未做系统代理或 TUN 实测；实施后仍需 Windows 实机、人工读屏与发行资格验收，不以自动检查代替。
