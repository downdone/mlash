# ADR 0011：按观测状态变化的小象托盘

2026-10-13，接受。设计目标不同代理状态/模式有不同小象动作与颜色，风格可以俏皮。

保留 EXE/窗口/侧栏蓝灰品牌，只在托盘使用静态状态变体。共 13 个 64px PNG，由同一 SVG 主形及 generate-brand.py 的配色/姿态定义生成，同时输出矢量派生稿和开发预览。无 SVG 运行库、帧动画或定时器。

托盘从 Controller 的 AppState 观测 core/ready/proxy/mode 派生：生命周期状态和异常优先，未就绪不表达已连接；已接管、待开启和外部代理各有模式变体。映射/表情说明唯一所有者为 ui-interactions.md。普通 busy 不覆盖正在生效的模式，待切换意图不能先改变颜色。

只有派生键改变才调用 setIcon；懒缓存最多 13 个小尺寸 QIcon，QResource 只初始化一次。提示文字包含实际内核状态、系统代理归属、内核模式；颜色和表情不代表节点公网健康，也不推测外部程序的代理模式。

验证涵盖优先级、资源在 16/24/32px 可加载且不同、缓存复用、浅/深背景预览及真实 /configs 模式回读联动。未通过默认测试写用户系统代理；Windows Explorer 重启/其他 DPI 仍属独立发布验收。
