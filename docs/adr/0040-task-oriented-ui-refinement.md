# ADR 0040：任务层级与统一输入反馈精修

2026-10-21 · 接受 · 设计目标按U21专项方案实施。此决策收敛ADR0018、0022、0028的具体布局/输入呈现，既有状态、安全恢复、轻量生命周期及原始规格不变。

## 原因

1.15.1已经具备国旗、两列设置、统一主题、圆角弹出和固定状态栏；专项审视发现重复上下文、工具占比和操作权重仍影响日常使用。整体方案及证据范围由`ui-ux-refinement-plan.md`拥有，不以旧截图的问题代替当前实现。

## 决定

生效交互以`ui-interactions.md`的U22章节为准：首页主摘要使用普通面板与独立导航，节点页压缩上下文、节点优先；测速响应卡片轻量详情与固定开始/停止，阻塞/统计共用固定行；设置两列按内容顶对齐、窄时纵排；托盘常用直达与低频归组；维护窗口滚动正文与固定反馈/提交。

UiTheme继续拥有单一语义视觉。WidgetStyle拥有全应用输入来源标记与普通按钮的显式键盘触发，独立弹窗和无主窗托盘不依赖MainWindow；不持有GUI引用或创建后台轮询。普通按钮不抢输入框默认提交，聚焦时Enter/Space可达。共用ElidedLabel绘制单行，原值、可访问文本与完整提示保留，消息/错误长度不改变布局高度。WrapLayout只用于有限工具控件，按实际宽度换行；节点继续虚拟绘制，不逐节点建Widget。

## 取舍与验证

保留Windows原生标题栏、字体与八页导航；不复制SF字体、Liquid Glass、动画或任意主题。首页规则模式明确浏览组、全局固定GLOBAL、直连为DIRECT，不用ready暗示公网健康。所有业务写入沿用Controller命令，未扩展权限、请求并发、超时、缓存或持久化schema。

空间/焦点/弹出首帧/草稿/取消/长文本/原生尺寸主题及实际DPR按专项方案验收。开发、自动测试、原生观察和性能证据只在`verification-report.md`记录；无VM系统级、真人读屏及72小时资格单列，不以验证包替代。
