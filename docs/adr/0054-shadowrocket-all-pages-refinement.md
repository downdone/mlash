# ADR 0054：Shadowrocket 原则驱动的全页视觉与密度修订

状态：接受，原生实施及自动验证完成。用户确认 [U14 全页设计](../design/u14-shadowrocket-all-pages.md) 并要求全面原生实现，内容字号和间距可进一步缩小。

四个一级分区和 U12 的页内工作区不变；首页、配置、数据四任务、设置任务与托盘统一采用“内容优先、连续分组、直接动作、渐进展开、真实状态”的视觉与交互规则。节点默认连续行，卡片为可选视图；配置围绕来源/版本/固定对象，数据围绕观察任务，设置为目录和页内完整任务。普通内容的字号、卡片和工具间距按 U14 修订，并以字体实际指标及 DPI 原生截图验收。

统一字体系采用内置 Noto Sans SC 可变字体（SIL OFL 1.1），缺字按平台字体回退。此资源不改变 Qt Widgets 选型，也不要求安装系统字体；便携包附带原许可。字体和行高联动验收，不通过 QSS 二次指定字体族或全局截图缩放掩盖实际渲染。

本决策修订 ADR 0051/0053 的外观、组件和局部尺寸，不撤销其信息架构与安全边界。Controller 仍唯一写入状态；浏览组、测速、候选下载、运行应用、系统代理接管分别遵循原有命令和回读契约。Windows 系统窗口装饰保留，不为了模仿 macOS 迁移 QML 或引入 WebView。

在实施证据足以证明实际清晰度和布局前，不将 U14 原型、自动几何断言或缩放截图当作完成。确认旧设计与 U14 冲突时，以本 ADR 的表现意图为准；具体控制器状态/存储/平台契约仍由原 ADR 和现行文档拥有。
