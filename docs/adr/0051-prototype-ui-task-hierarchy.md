# ADR 0051：最终原型的任务层级与共享 UI

状态：接受。用户要求完整落实 [U11 系统规范](../design/u11-ui-system.md)，替代 U08 的长表单/通用抽屉布局及 U10 的局部外壳取舍；安全、线程、版本与恢复契约不变。

## 决策

- 侧栏四项直接排列，品牌签名置底；Toolbar 按页提供导入/添加，标题居中。状态栏放在内容区底部，不随正文滚动。
- 配置列表进入绑定配置身份的后续详情页；内容/维护任务复用现有命令和高级编辑器，不再用通用抽屉替代配置详情。
- 设置默认显示目录。启动、本地代理、内核、备份与其他工具进入对应编辑任务；原字段仍只有一个编辑会话，即时偏好不夹带重启草稿。
- 历史入口 6 进入设置目录。显式 `Route{Settings,0/1/2}` 保留启动/网络/内核深链；分类不再解释为平铺卡片滚动位置。不新增持久化字段。
- 节点和连接共用 Inspector：宽内容区并列且实际收窄正文；窄窗替代正文，返回恢复布局/焦点。页面根对象保留身份，不能统一重命名覆盖任务标识。
- 节点名称、延迟、信息分别按本地事件坐标命中。自动组点击只读；搜索后定位隐藏成员先确认清除筛选，不切换业务成员。
- 连接 Inspector 复用既有快照/规则预填行为，增加代次检查；新建规则仍仅预填。默认列收敛为目标/命中规则/代理链/状态；既有自定义列偏好保留，字段 ID 不变。
- 连通性 URL 属于网络编辑草稿，失焦不写入；校验拒绝也必须返回 SettingsApply 结果，结束保存中状态并保留草稿。搜索可跨目录定位，不能悄悄放弃未保存字段。
- 实机复核后修正：开关圆钮使用 OnPrimary 前景角色，避免深色 Surface 生成黑色圆钮；搜索入口只显示“搜索设置”，快捷键进入提示，避免窄窗裁切。
- 第三方网站原色图标使用独立的浅色 ArtworkSurface 底托，深浅主题保持识别度，不把黑色品牌图标直接放在深色控件底上。

## 后果与验证

共享目录行、分组、返回、图标与视觉 token 后再装配页面；旧测试按新任务入口执行相同业务断言，不能删除失败/取消/版本保护断言。截图使用相同字体、主题与合成数据逐项复核，不以单元测试通过宣称视觉一致。实际结果在验证报告维护。
