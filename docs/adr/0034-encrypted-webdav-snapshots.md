# ADR 0034：密码加密的 WebDAV 版本备份

G22使用已有密码认证加密归档，不上传明文配置。WebDAV目录、账户/密码、独立备份密码、路径与计划仅保存在本机DPAPI索引；便携归档移除remote_backup，恢复保留本机配置，不因导入备份而开启网络计划。

显式保存不请求网络。HTTPS目录必须无URL凭据/查询/片段，证书严格验证；默认拒绝私有地址，本地NAS需要主动允许，仍不跳过TLS。直连使用NoProxy；经内核先验证当前就绪PID与端口归属，不回退直连。DNS全地址检查后固定目标IP，保留原Host/TLS身份；不跟随重定向。单任务120秒、DNS10秒、传输空闲15秒、目录1MiB、归档64MiB有界。

远端按唯一文件名保留：PUT随机临时文件（If-None-Match:*）→GET校验SHA→MOVE到新版本（Overwrite:F，要求201）→GET再次校验。MOVE规则依据[RFC 4918](https://www.rfc-editor.org/info/rfc4918/)；不覆盖或自动删除远端旧版本，失败可能留下加密临时文件，列表忽略它们。本机保留最多5份生成的加密快照，上传失败仍可恢复。目录只接受同源、配置目录直接子项的有效备份名，最多200份，拒绝XML实体/DTD和越界结构。

下载先写私有临时文件并验证密码/结构，成功才原子保存用户目的文件，再打开既有恢复预览；不自动导入/启动/接管。密码不符或损坏保持旧目的文件。周期1–168小时显式启用，首次为保存后一个周期，到期只在Controller空闲执行；GUI关闭仍继续，失败退避15分钟，成功保存实际时间。手动取消不继续网络阶段；退出等待有界操作取消/元数据保存。只使用已有Controller及有界worker，不持有GUI引用。

真实公共WebDAV账号/跨账户恢复未验收。本地HTTPS测试CA只加入测试进程的Qt配置，不安装系统证书；测试专用传输映射没有设置/CLI入口，生产始终使用用户配置HTTPS。
