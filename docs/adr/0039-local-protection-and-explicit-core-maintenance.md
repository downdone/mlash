# ADR0039 本地保护与显式内核维护

2026-10-20；设计目标完成成熟度评审建议2–5，真实VM场景暂跳过。

本地自动备份采用已有密码认证加密档案，密码仅保存在账户加密索引中；默认关闭，用户明确配置后执行周期和重大变更前快照。计划归Controller、与GUI生命周期无关。新档案验证成功才清理旧档案，清理只接受生成名称、固定六字段元数据和内容SHA全部匹配的本程序文件。损坏/未知/符号链接不自动删除；失败保留旧数据。变更前备份失败阻止原变更。账户恢复不迁入备份密码和自动计划，保持本机配置。字段契约见api-contracts。

官方在线维护为按需能力，使用MetaCubeX/mihomo官方GitHub最新稳定版API及Windows amd64-v1 ZIP，拒绝草稿/预发布、重复资产、非固定仓库HTTPS链接、缺失SHA和超预算元数据。下载大小及SHA匹配后才在有界worker解包；ZIP仅受控单卷、最多8项/64MiB输入/128MiB输出，不落盘解压路径，拒绝穿越、加密、多程序和不一致目录/CRC。复用当前固定Qt6.10.2 Core所导出的QtZlib 1.3.1解码器头接口，不增加运行DLL；Qt升级须重新构建和回归，不承诺私有接口跨版本ABI稳定。

解包后的字节复用CoreUpdate的Windows x64 PE、独立副本和版本预检，实际-v必须等于元数据版本，再允许用户显式应用；运行配置校验/回读/失败恢复保持原事务。检查/下载/预检不替换当前内核，取消旧结果不能生成可应用token。GitHub限流、无SHA、离线不降级为镜像或未校验执行，保留本地文件路径。

ADR0038的随包本地bugfix发布锁继续有效，本能力不更改cores/manifest、依赖发布pin或TUN固定SHA。官方版本不承诺包含本地半关闭补丁；TUN意图启用时禁止应用非固定SHA，并提示先关闭TUN。旧服务版本/目录/自启冲突仍显式报告，不自动删除其他安装、覆盖自启或提升权限。系统级验收继续独立列出。
