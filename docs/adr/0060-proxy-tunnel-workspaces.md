# ADR 0060　代理与隧道工作区

已采纳。此决策更新 ADR 0048 的首页层级和 ADR 0049 的主视图集合。其他历史视图 ID 与八个整数入口保留。

代理和隧道可以并行工作，配置使用、系统接管、会话观测和数据口径不同。总览查看整体状态，代理和隧道在一级工作区中提供运行、对象、流量和日志。配置导入和设置为全局入口。代理内核的实例名称由内核管理呈现。

Route 表达工作区作用域，GuiHost 保存会话书签。工作区选中状态只表示当前浏览位置，侧栏状态点独立读取 AppController 的就绪、会话及恢复观测。切页不执行应用、启停或接管命令，既有服务权限、应用状态和持久化格式继续遵循各自契约。
