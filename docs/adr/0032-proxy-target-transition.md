# ADR 0032：代理目标更新与完整快照恢复

G20开放系统代理排除列表，不新增PAC服务/监听/主动守护。受控目标增加规范化排除项，旧设置默认本地地址；最多64项/2048字符，不接受URL/路径/凭据/控制字符。只在当前完整快照仍归Mlash时立即更改，否则仅保存下次接管意图。

已接管状态更新目标不先释放再接管，避免把最初外部PAC当成新的授权或丢失恢复基线。先原子保存过渡日志：before保持最初快照，written为新目标，previous_written为本次更新前已写且核验的完整目标；然后重检旧目标、写新目标并回读。成功移除previous_written确认。恢复只接受当前快照完整匹配written或过渡期间已核验的previous_written；不是按端口/部分字段猜归属。

更改失败尝试恢复旧完整目标；索引失败也恢复旧排除目标，所有恢复都重新检查完整归属，外部修改时不覆盖并保留日志。过渡字段格式严格验证。旧版本遇到过渡旧目标不匹配其written时会保守拒绝恢复而保留日志，不会扩大写权限。默认测试只用模拟平台，真实宿主代理不写。
