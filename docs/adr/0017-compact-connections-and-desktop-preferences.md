# ADR 0017：紧凑连接观察与日常设置补齐

日期：2026-10-14。状态：接受。按日常任务补齐连接与设置能力；承接 ADR 0009/0014。

## 连接

保持仅 GUI 连接页可见时 2s/单请求/1.5s 超时读取。总量使用真实内核 uploadTotal/downloadTotal；条目和总速率由同一可见会话相邻单调时间差计算，首次、计数回退或间隔超过 10s 为未知，不显示虚构 0。活动最多 5000 条；截断时不把未列出的 ID 判为结束。

增加“活动 / 已离开快照”、有界 1000 条离开记录、全行/进程搜索、数值排序、详情/显式复制与关闭全部。离开记录只保存最后观察值和发现时间，不推断 TCP 结束原因；隐藏、离页、GUI 释放、运行代次改变即清空，失败读取清空活动/速率基线，不写磁盘/日志。替代 ADR 0009 的完全无内存历史约束，不扩展为历史连接分析器。

关闭全部需要用户点击并确认；DELETE /connections 后 GET 回读原快照 ID 已消失，允许期间新产生的 ID，未知/坏响应报错。没有自动关闭全部。活动行可单关闭，离开行只读。详情放在菜单/双击窗口，表上方只用一行真实总量/速率，保持紧凑。

## 设置

新增 startup_page 0–6、tray_click show/proxy-page/toggle-proxy。默认首页/显示窗口，重建仍记住本会话页面；托盘双击始终显示，切换代理的单击延迟至双击窗口结束，避免双击意外写 OS。外部代理接管仍保留既有冲突保护。

IPv6/unified-delay 用 source/enabled/disabled 三态；默认 source 保留原订阅语义。覆盖只改受控运行副本，真实 -t/启动/GET configs 回读后提交，失败恢复旧选项；不改系统 DNS 或源 YAML。新字段可选，旧 schema 兼容，非法类型/取值拒绝加载/保存。GUI 仍保护未应用草稿。

“更多工具”提供 PowerShell/CMD/sh 环境变量文本复制（不执行、不含 API 密钥），以及 GUI 本地 Geo 导入。Geo 只接受固定文件名、非链接文件、单文件 128 MiB，在 worker 内先复制/哈希完整暂存目录，再保存一份上一快照并交换目录；失败保持当前数据。当前 Core/版本不变，重新激活时优先使用本地默认数据；自定义 geox-url 不受覆盖。运行回滚明确复用原版本 Geo 而非新默认，避免坏数据破坏 LKG。

TUN/管理员服务/LAN 分享/外部控制/脚本/Web UI/主题引擎继续排除。DNS 高级语义继续来自订阅，不再添一套容易冲突的全局 DNS 编辑器。

“更多工具”同时提供当前激活配置的脱敏只读预览及内核目录。配置读取/脱敏在 worker 中执行，预览最多 512 Ki 字符；旧运行代次或已隐藏/销毁的请求窗口不显示结果，不记录原文，也不能在预览中修改运行配置。连接详情在离开页面/隐藏时关闭，所有临时窗口随轻量 GUI 释放。
