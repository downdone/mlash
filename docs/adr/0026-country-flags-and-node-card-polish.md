# ADR 0026：内置国旗与紧凑节点卡片

2026-10-15；状态：接受；细化 ADR 0020/0021/0025。

设计目标卡片更精细、地区显示国旗，并指出最近选择箭头位置异常。保留54 DIP单行、表格/卡片切换、共用排序/选择/测速模型，不增加逐节点 QWidget 或后台动画。

国旗使用固定 Twemoji v14.0.2 的51个原始 PNG，通过 qrc 编入程序；随包保留 Twitter, Inc. and other contributors 的 CC BY 4.0 授权和来源，原文件哈希在 resources/flags/manifest.json。显示时只裁透明边并按原比例缩放，不依赖 emoji 字体、SVG插件或网络。名称只提供地区提示，不增加地理定位请求。无法识别保留中性图标。

地区识别优先于组回退：HK/JP等组也显示国旗，未知地区组保留层叠图标。NodePresentation.iconKey 为节点视图和托盘提供同一个有限语义键，51地区与4种回退最多55类，避免不同地区组共享错误图标。子组另外用向右小箭头和提示区分；当前成员小圆点/粗体与预选蓝边独立。

卡片白底、轻边界、8px圆角、浅悬停/选中，名称/图标和延迟单行对齐；点击延迟仍只触发单节点测速。最近选择保留 QPushButton 菜单语义，由按钮独立绘制居中细箭头，关闭旧 menu-indicator 绘制并留出右边距，避免原生指示器与 QSS 盒模型混排。

验收由 verification-report 的 U17 记录：原始资源哈希/内置资源、两地区组不串图标、鼠标/键盘/关闭菜单、箭头像素居中、单卡测速不改变选择、原生多DPR与紧凑卡片检查。Windows实际剪贴板/系统写入等沿用既有独立验收边界。
