# ADR 0047：网站测试归属数据分区与页面标题移除

2026-10-29 · 拟定，未实施。本 ADR 记录 U06 分层设计中两项**用户可见的信息架构变更**，取代 ADR 0043 中「首页含状态/节点/网站测试」的归属与「域内页签占用标题位」的呈现。

## 原因

U06 分层设计评审指出，设计与现有交互契约存在两处未记录的冲突：

1. 设计把网站测试从「首页」分区移到「数据」分区（`MainWindow.cpp:470` 现把 `page==7` 归入 section 0），但 ADR 与交互契约仍写首页包含网站测试。
2. 设计删除页面文字标题、由页签承载视图名，但交互契约仍规定「页签占用页面标题位置」，且视觉基线仍有「页标题 18pt」角色。

两项都是用户可见的导航与层级变化，必须按 AGENTS.md 以 ADR 记录，不能只改设计文档。

## 决定

**网站测试归数据分区。** 理由：它与其他数据分区页面（连接、日志）同属「观察运行结果」，而首页只回答「当前状态与下一步」。首页保留到网站测试的捷径（经页签或状态页动作），不复制测试界面。

**删除页面文字标题。** 分区名由侧栏选中态表达，视图名由页签选中态表达，窗口标题栏显示「Mlash · 当前视图名」供任务栏与 Alt+Tab 识别。页签不再占用标题位，而是内容区第一行。

**既有持久化不变。** `startupPage` 仍为整数 0–7，无需迁移；`Settings.connectionView` 中已持久化的列序、列宽、可见性**保留且不得回退**。

## 影响与约束

- 交互契约的分区表、标题规则、视觉基线字号角色需同步修订。
- 设置搜索的跨页路由与启动页标签随分区变化更新，但数值不变。
- 页签与标题的行高差异会改变各页首屏起点，需按 840×560 与 120% 文字复核。
- 不改变 Controller 命令、状态字段或持久化 schema。

## 验证边界

实施后按交互契约的完整任务链复核：跨分区跳转、页签同步、窗口标题随视图变化、窄窗与文字缩放下的首屏几何。真实 Windows 实机与人工读屏不因本 ADR 获得验证。
