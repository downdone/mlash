# ADR 0057：订阅优先的统一列表与对象菜单

状态：已实施；Windows 自动化验证记录见项目状态与验证报告。用户明确要求订阅列表和更新为配置页主任务，远程与本地同列，菜单按操作深度重组。

配置分区打开后直接显示一个配置卡片列表。来源位显示远程域名或本地文件名，不显示含令牌的完整 URL 或本地绝对路径。来源类型继续保留在模型和 Controller 中，决定更新、分享、文件选择能力；页面不因此拆成两张列表。批量更新仅包括有外部来源的配置，复用有界队列。

卡片主体负责使用配置，刷新按钮独立检查来源更新，候选条就近查看和明确应用；这三类主动作不在菜单重复。对象菜单只含“查看配置内容”“编辑订阅资料…”“分享订阅地址…”（仅远程）和“删除配置…”；本地最多三项。查看内容进入该配置的节点与组、规则、DNS、拨号链工作区；资料编辑进入单独的一层工作区，拥有一份草稿和保存/取消。分享先提示私人令牌风险，再明确显示二维码。删除需要点明对象和当前使用时的后果并确认。重新加载/回滚/兼容性等低频维护入口位于相应工作区；列表排序属于列表级操作，数据目录归设置或诊断。

内容工作区顶栏使用配置名称，不叠加第二个泛化详情标题；首屏直接显示组和节点行，不提供再点一次的目录。内容各视角只换正文，浏览不切换运行对象；来源规则只读，覆盖规则可编辑，DNS 默认沿用来源。候选条的“查看”打开候选与已保存版对比，不跳来源编辑。返回恢复列表位置和原触发控件焦点；草稿按对象及视角保留或在明确离开时处理。

同一卡片的右键、菜单键和省略号使用同一菜单，固定配置 ID；Esc 收起后恢复原触发控件焦点。来源不可用时隐藏不适用动作，不通过灰色条目凑菜单。返回订阅列表恢复原滚动与焦点。Controller 仍为唯一写入者；使用、更新、应用候选分别以实际回读状态显示，候选与运行版及上次良好版不混同。原始 YAML 不因下载覆盖，失败保留运行配置和草稿。

本决策替代 ADR 0051 中配置列表→详情目录→编辑任务的**默认入口和菜单表现**，以及 ADR 0052 中对应的多层表现树安排；保留两者的分区、对象身份、同区工作区、草稿保护和 Controller 命令边界。实施和验收以 [U22 设计](../design/u22-config-rethink.md#6-同列订阅与菜单层级修订) 为准。原生人工读屏和正式发行资格仍以独立证据判断。
