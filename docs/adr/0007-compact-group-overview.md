# ADR 0007：紧凑策略组总览与嵌套浏览

2026-10-13，接受。设计目标代理页参考紧凑表格与 Clash 策略组操作方式。

用最大 120px、行高 24px 的策略组总览替代单一下拉框。下部保持虚拟化节点表，行高 26px，四列左/右对齐。
按 API all 数组区分子组与节点；显示实际组 now，不把 Selector 当成叶子协议，也不推测地区和持续健康。

进入子组只改变 UI 浏览路径；实际父组/子组成员选择仍通过 Controller 命令与回读。提供返回、16 层限制和循环检查。
切换到未激活订阅时同时清空两张表，不能显示原运行订阅的组为新订阅内容。
滚动与相同成员的索引在普通刷新中保留，不创建逐节点 Widget、常驻网络流或新持久化 schema。
