# ADR 0008：五页统一视觉与操作层级

2026-10-13，接受。设计目标重新审视美观程度与合理性并更新，保留紧凑、小字号基线。

统一 Qt 内置 Fusion Widgets 风格、8pt 正文、薄边框、8px 圆角、白底细线表格与浅蓝选中态；去掉交替灰底。首页状态颜色辅助实际状态文字，避免暗示网络已经可用。

订阅增加单一导入入口，按来源只显示有效的更新入口；使用订阅为主动作，重命名、回滚、删除移入更多菜单，继续由 Controller 执行。设置分为启动行为与内核/本地代理两组，应用保持显式提交。

订阅与策略组总览共用一个面板，降低竖向占用；成员数量移动到底部，保留搜索与排序空间。继承 ADR 0006/0007 的导航、小字号和嵌套浏览约束，总览高度从 120px 缩为 110px。

不引入图表、流量订阅、新图像资产、动画、数据库或新的持久化 schema。视觉与功能证据见交互设计和验证报告，其他主题/DPI/无障碍验收仍独立进行。
