# ADR 0052：同分区工作区与减少弹窗

状态：接受。用户明确要求减少弹窗、尽可能减少设计层级并完整实施。

在 ADR 0051 的四分区、对象身份、单份草稿及 Controller 命令约束上，将高级编辑从独立工具窗口迁入同分区正文工作区。同级任务使用页签或就地选择，内核/备份取消纯中间目录；来源与维护合并。Inspector 仅在稳定的正文宿主内部切换，不隐藏顶栏/状态栏之间的伸展宿主。

同一工具与对象只有一个会话，任务切换保留未提交输入；关闭主界面的草稿与提交检查覆盖隐藏会话。普通错误和只读详情就地显示，文件选择、危险/恢复/权限操作及放弃草稿的必要确认保留。定位当前成员的普通确认改为可见筛选状态和恢复操作，不切换运行成员。

替代 ADR 0051 中高级编辑器独立窗口及定位先确认清除筛选的表现取舍；不改变业务提交、版本、恢复、安全及平台范围。设计与验收见 [U12](../design/u12-flat-workspaces.md)。
