# ADR 0050：Shadowrocket 方向的紧凑 Widgets 外壳

状态：接受；实施与验证按 [U10](../design/u10-implementation.md) 记录。

## 背景

用户接受 U09 最终交互原型并要求开始开发、略微收紧。既有 U08 的左标题、状态胶囊、侧栏状态、宽松配置行与新方向存在重复；订阅下拉的“仅浏览”提示和实际激活行为不一致。

## 决策

保留 Qt Widgets 和 Controller 命令边界，先实现原生紧凑外壳，不引入 QML。四个一级分区和 ADR 0049 的视图路由继续有效。

居中标题采用等宽两侧槽位；侧栏不再重复展示状态，固定状态栏与首页实际状态继续承载反馈。此项替代 ADR 0048 对侧栏常驻状态的展示要求，不改变状态句计算或托盘状态。

节点与配置采用连续行、内缩分隔线和行尾信息入口。延迟和选择分别命中，自动策略组显示实际当前成员但仍不可手动选择。订阅下拉仅改变浏览对象，显式“使用此配置”才调用激活命令；取消 U08 的下拉即使用行为。候选/运行/LKG 和代理恢复事务保持原契约。

## 后果

紧凑尺寸统一在 UiTheme 管理，文字放大允许行高扩展。测试分别固定浏览/应用边界、测速不选中和路由稳定性。原型中的设置编辑层级、窄窗检查器后续页等未完成细节不得因本 ADR 视为已实现。
