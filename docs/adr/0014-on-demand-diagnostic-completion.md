# ADR 0014：按需诊断与最近成员

2026-10-13，接受。继续实现原规格 Windows 诊断增强，保留紧凑七页、轻量生命周期和 Controller 唯一命令入口。

日志级别及文本可联合筛选；内核流按所选级别请求，全部对应 debug，应用筛选不请求内核详细流。暂停冻结当前视图并停止详细流，核心异常/应用诊断继续有界记录；离页、隐藏、GUI 释放同样关闭流。恢复显示当前有界日志，不采集暂停期间的详细流历史。清空仅清除内存视图，不删除磁盘文件。

显式选择文件导出 JSON：白名单状态摘要与最多 2000 条再次脱敏的日志，不包含来源/原始或运行配置、Profile 标签/节点目录、连接快照。敏感值与日志以值快照传给 worker，再脱敏/序列化/原子写入；完整已知订阅 URL（包括路径令牌与 query 值）也进入脱敏集合。导出不解密并遍历用户配置。

每订阅最多 32 个最近手动成员（group/member 对），回读成功后记录 MRU、去重并加密保存。源 store-selected=false 同时关闭选择记忆与最近记录；自动恢复/轮询不产生 MRU。菜单仅列出当前组仍有效的成员，点击才通过 Controller 选择，不自动改变代理。

规则查询仅在“当前内核规则”页签实际可见时读取和保留；编辑器与事务的校验回读独立，切换页签清空查询快照不影响草稿或保存。检索只过滤 GUI 模型。

连接的关闭功能仅接受 GUI 当前快照中的单个有效 ID 和设计目标，DELETE /connections/{id} 后 GET 回读确认消失；不提供关闭全部入口。隐藏过程中已明确发出的关闭操作可完成回读，但不向隐藏视图保留连接快照。活动连接刷新尽量保留有效行/选择/滚动，不把瞬时字段变化当作连接状态变化。

HTTP 连通/延迟测试继续使用 5s 单节点 delay，新增可配置 HTTP/HTTPS 测试地址，默认 gstatic 204；只由手动测试触发，最多三并发/500 条/可取消。不提供持续测试，也不将成功视为全部协议/目的地可用。test_url 与 recent_selections 为兼容旧状态的可选字段，非法新字段拒绝加载。

后台订阅/节点记忆的索引提交不覆盖设置页尚未应用的字段；实际设置与草稿逐字段区分。暂停、筛选和规则检索仅属于当前 GUI，不增加后台 GUI 资源。
