# ADR 0046：导航可寻址、反馈路由与设置分类深链

2026-10-29 · 拟定，未实施。本 ADR 部分取代 ADR 0045 中「备份等长流程任务移出为维护页」的目标结构，并记录 U06 分层设计相对「Controller 命令与持久化 schema 不变」边界的偏差。

## 原因

U06 分层设计评审指出三处若按原边界实施则无法落地的问题：

1. 设置三分类当前只是页内的 show/hide（`selectSettingsCategory` 切换可见性），不改变 `pages_->currentIndex()`。托盘跳转、启动页、设置搜索都只能定位到视图 6，无法直达「设置 › 备份与工具」；轻量重建后分类状态丢失。用户明确要求分类可被深链。
2. 页面级错误要就近显示，但 `operationFinished(bool ok, const QString& message)`（`AppController.h:183`）不带操作标识，UI 无法区分某次结果属于哪个页面或对象，只能全部写入全局状态栏。
3. ADR 0045 与 U05 目标信息架构把备份/Geo/存储列为独立「维护」页；用户决定保留在设置第三分类，两处文档给出相反指令。

## 决定

**路由键扩展为 `(viewId, category)`。** 视图 ID 0–7 与 `pages_` 索引不变，设置三分类作为索引 6 的内部状态，以复合键寻址。全部导航表面（侧栏、页签、托盘、启动页、设置搜索、`GuiHost`）从同一路由模型表取值。

**`operationFinished` 增加可选的操作标识。** 新增参数标识动作来源，UI 据此把结果路由到页面提示、状态栏「最近操作」或「当前告警」。这是接口变更，相对 AGENTS.md 记录的 Controller 契约边界属于已接受的偏差；命令集合、状态字段与持久化 schema 不变。

**备份保留为设置第三分类，不拆独立页。** 相应放弃「维护页可被独立深链」的结构；长流程任务与偏好同页的代价由分类深链部分补偿。

**分区名保持首页/配置/数据/设置。**

## 影响与约束

- `startupPage` 仍为整数 0–7，无需数据迁移；设置分类为会话内状态，不持久化，轻量重建后回到默认分类。
- 表格列宽与列序**保留既有** `Settings.connectionView` 持久化，不新增字段，也不得回退为仅会话内记忆。
- `GuiHost::show()` 的 `page < 8` 改为路由模型条目数校验。
- 信号扩展后，现有 emit 与 connect（含测试）需同步；加默认参数可保证旧调用点继续编译，新增调用点应显式传值。具体数量以实施时统计为准。
- 现有 `state.lastError` 不再无条件占用状态栏，改为「当前告警」段，并在条件解除时清除。

## 验证边界

实施后按交互契约的完整任务链复核：分类深链可从托盘、搜索、启动页到达；页面级失败只出现在所属页面；跨页结果出现在状态栏；轻量重建回到视图与其默认分类。真实 Windows 实机、人工读屏与发行资格不因本 ADR 获得验证。
