# ADR 0043：功能归属、明确动作与设置分类

2026-10-28 · 接受。替代 ADR 0040 中“代理/测速”的用户可见页名、首页直接选择成员及规则默认文本呈现；补充 ADR 0042 的设置组织。既有状态、恢复、读写分离与持久化契约不变。

## 原因

用户要求从完整流程审视逻辑、入口深度、命名、布局和可理解性，允许删除、补充与重设计，并明确要求功能按对象组织，不能散落到各处。仅删除说明没有解决首页缺少下一步、订阅专属配置分散、网站测试名称歧义和默认规则语法门槛。

## 决定

用户提供 Shadowrocket 截图后，一级入口收敛为首页、配置、数据、设置；原八个内部视图 ID 保留。首页内为状态/节点/网站测试，配置内为订阅/规则，数据内为连接/日志，域内切换使用标题工具带中的常驻页签，分区在窗口会话内记住最后浏览视图。用户可见“代理”改为“节点”，“测速”改为“网站测试”。订阅拥有来源/版本、节点/组、DNS、上游代理链和节点源维护；节点只拥有选择、切换、延迟和显示偏好。规则拥有优先规则、完整编辑、规则源及实际内核规则。网站测试拥有响应和出口/服务诊断。首页展示状态与直接下一步，捷径导航至所属页面。设置分为常规、网络与内核、备份与工具，保留单列、全局草稿与固定应用栏；分类切换与搜索不写入或丢稿。

首页节点预选须显式点击“切换”才提交，与节点页保持一致。规则默认列表，文本是同一草稿的高级视图；实际规则显示真实运行订阅。导入、下载、使用并启动、应用更新仍为不同动作；不因流程简化而自动接管代理、安装权限服务或发起测试。

完整逐页取舍由 [U03 审视](../ui-apple-review.md#u03-任务流程与信息架构重审) 维护，当前行为由 [交互契约](../ui-interactions.md) 维护。Controller 命令、持久化 schema、平台能力不变。

## 验证边界

隔离夹具检查下一步、分类/搜索/草稿、单/多选、规则列表/文本共享及节点预选零写入；通过本地 HTTP 夹具检验显式切换后回读。八页和工具窗口以多主题、尺寸及文字比例复核。真实系统、人工读屏和发行资格依实际执行另记，不由截图或模拟状态代替。
