# ADR 0024：统一下拉与托盘弹出层

2026-10-14，接受。视觉评审发现页面下拉仍有旧式方框/凸起边界，托盘菜单与主界面风格脱节。此前 Fusion 只在主窗口安装，托盘先显示或静默启动时可能使用另一风格；页面局部菜单 QSS 与组合框默认 popup 路径也不统一。

新增 UI 模块 WidgetStyle，在应用入口安装且 Tray/MainWindow 幂等兜底。采用同一 Fusion 代理：白底、8px 圆角、1px 轻边界、浅蓝高亮、蓝色勾选、细箭头、26px 起的紧凑行，取消空复选框及旧式厚阴影。仅改变绘制与布局，Qt QAction/QMenu 和模型/信号继续负责行为。

组合框改用正常列表展开与共用委托，通常锚到控件下方、最多十项再滚动，编辑、itemData、方向键/回车、Esc、鼠标选择保留。通过公开的 view()->window() 准备透明圆角弹出面板，不包含 Qt 私有头/原生窗口接口；绘制过滤器属于弹窗对象树。窄控件弹出层独立扩宽，至少 120px，并按文字/勾选留白测量至 460px（宽控件保持自身宽度），最终受目标屏幕约束；不挤大主布局。长菜单采用单列滚动，并在 Show 时约束到可用屏幕和 720px，避免巨型多列菜单遮挡桌面。

排查核对了锁定 [Qt 6.10.2 组合框源码](https://github.com/qt/qtbase/blob/v6.10.2/src/widgets/widgets/qcombobox.cpp) 的展开/背景分支及 [菜单源码](https://github.com/qt/qtbase/blob/v6.10.2/src/widgets/widgets/qmenu.cpp) 的屏幕范围逻辑；实现只使用公开 Widgets API/样式钩子，不复制私有实现。透明圆角需验证内部白底不丢失，不能只验证边角 alpha；超长列表需实际到末项选择。

删除 MainWindow 局部菜单 QSS 的另一套边界，保留鼠标/键盘焦点区分和真实选中态。不添加动画、模糊或阴影插件，无新定时器/网络/持久化字段；主窗口释放时所属视图、委托及面板过滤器销毁，托盘仍按现有菜单树清理。自动测速、写优先、系统恢复契约不变。验收覆盖原生弹出图像、无主窗口托盘、长列表、可编辑框、取消、自动测速及轻量重建。
