# ADR 0009：品牌更新、订阅规则覆盖和可见连接快照

2026-10-13，接受。设计目标新 Logo/配色、EXE 图标、较小默认窗口、规则与连接导航。

新品牌为双路径组成的 M，石墨底、白色与柔蓝路径。resources/mlash.svg 是矢量主文件；generate-brand.py 产生 PNG 和 16–256px ICO，Qt 资源与 Windows ICON 资源使用同一品牌。无需 SVG 运行库。用户随后明确参考 Apple 极简，因此将初步石墨/薄荷方向改为中性灰白、轻边界与少量蓝色强调；保留 Windows 原生标题栏。初始 940×620、最小 840×560 逻辑像素，8pt 正文不变。

导航为首页、订阅、代理、规则、连接、日志、设置；在 ADR 0006/0008 基础上扩展，原始规格保留。

规则覆盖按订阅独立、前置、显式保存。先 worker 构建和 mihomo -t，再进行必要的安全重载与 /rules 回读；运行规则编辑不自动使用新下载候选。支持常用域名/IP/进程/端口/Geo/MATCH；逻辑组合和新增 RULE-SET 引用暂不作为自定义覆盖入口，原订阅规则语义保留。更新与来源回滚保留当前覆盖意图。

连接采用普通 /connections GET 快照，每 2s、1.5s 超时、单请求、最多展示 5000 条；GUI 连接页可见且内核就绪才运行。隐藏/销毁窗口或离页停止并清空；不记录历史，不在应用日志输出目标和进程。活动状态按 API 当前快照显示，不声称远端健康。

此项有意超出原规格首版“不获取规则/连接”的范围，授权来自本次设计目标。仍无 TUN、WebView、数据库、服务或后台连接订阅。
