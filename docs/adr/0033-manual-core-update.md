# ADR 0033：本地内核预检与独立副本更新

G21本轮实现差异清单中优先的本地新版工作流，不引入在线版本通道/自动更新框架。设计目标Windows x64 PE文件后，worker建立私有core-updates/<SHA256>/mihomo.exe与清单；不覆盖原程序或运行内核。单文件128MiB、最多8份；显式清理只处理验证过归属/目录边界的副本，保留当前、上次和已预检版本，跳过链接和额外文件。

异步-v进程3秒/8KiB，必须返回Windows amd64 Mihomo语义版本；预检后的SHA绑定一次性应用token。应用前后重新核对副本，保存当前程序独立回退副本，以新程序校验当前配置后才切换；启动API版本必须等于预检版本。运行失败沿用旧配置/旧程序恢复，独立下载候选不激活。停止状态只校验并保存内核路径，不启动核心或系统代理。

previous_core_path为本机回退副本路径，不导出到便携备份，恢复保留本机值。版本/哈希是完整性和行为绑定，不是来源真实性或数字签名认证；任意新版仍需现有兼容性及实际使用验证。未声称Alpha或未知版本矩阵已验收。
