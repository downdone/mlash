# ADR 0020：共用状态的节点表格与卡片

2026-10-14，接受。设计目标参考 Clash 增加位置图标和可切换视图，同时保留原表格。

默认表格，代理成员工具栏提供“表格 / 卡片”。两者共用 ProxyTableModel、同一个筛选/排序代理与选择模型，切换不调用业务写命令。卡片以委托绘制并随宽度分列，不为每节点创建 QWidget；当前成员、未知/失败延迟来自同一实际状态。点击仅选择，使用按钮、双击或回车才提交；右方向键仍可浏览子策略组。

位置只按节点名称中的旗帜、国家/地区名称和独立大写代码识别，支持常见地区；显示缩写图标并在提示中说明“按名称识别”。未识别使用通用地球，策略组/直连/拒绝分别使用语义图标，不伪造服务器实际位置。保留源名称；不增加 IP 定位请求或 Geo 数据依赖。

地区识别表达式预编译；图标缓存最多为有限地区/语义种类，由窗口委托拥有，随 GUI 释放。GuiHost 仅保存本会话视图索引，在轻量重建时恢复；新进程默认表格，不修改设置存储 schema。所有命令仍经 Controller，测速期间两种视图均可浏览。
