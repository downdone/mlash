# ADR 0019：摘要仪表盘与统一设置项

2026-10-14，接受。用户以五张标注图调整 ADR 0018 的具体布局。

首页不再重复代理页的所有策略组，改为订阅、代理、规则、连接、日志、设置六张摘要卡片，加实际运行控制与核心状态。卡片可进入所属页面，不增加底部重复导航按钮；连接没有采样时显示尚未观察，不能伪造零连接或增加后台采集。规则摘要使用本订阅自定义规则数，不冒充未知的内核全部规则数。

代理组改为 QListWidget + delegate 的可滚动卡片，只绘制组名/成员数，保持真实选择、最大组默认、子组进入/返回、键盘与稳定滚动。委托虚拟绘制不为每个组创建完整控件树。当前成员仍在节点区域呈现；已使用订阅的更新解释放按钮提示，未使用的目标保留短状态。

订阅管理使用所指行的右键菜单，同时支持菜单键/Shift+F10；菜单弹出前选中目标，空白处不借用旧选择。更新/更新设置保持可见；底部不再放重复管理入口。连接活动/已离开使用并列页签，列表/选择随页签变化，后台清空契约保持。

设置纵向分组列表，每行左侧名称/说明、右侧控件，轻量模式说明属于同一行。高级工具作为列表行进入主体滚动，固定底部只留草稿/还原/应用；不再混排开关与说明，也不增加新持久化字段。

开关仅在键盘 Tab/反向 Tab/快捷键进入时画焦点；鼠标点击保留正常焦点语义但不绘制框，不能以移除全部键盘焦点实现。侧栏删去重复的产品副标题，保留标识与七页导航。继续 9pt/紧凑尺寸、原生 Qt Widgets、按需 GUI，不改变代理所有权或配置事务。
