# ADR 0015：运行版本保护与 Windows 功能闭环

日期：2026-10-14。状态：接受。承接 ADR 0002、0013、0014；原规格保持不变。

## 问题与决定

订阅更新生成候选 B 后，重启、端口调整或失败回滚仍应运行已激活 A。构建 A 的受控运行副本只变更 active，不覆盖独立候选 B；显式激活 B 才消费它。来源更新时间也不随运行重建改变。

恢复日志解密成功不代表结构可信。代理快照必须包含完整 flags/server/bypass/pac，flags 为 0–15 整数，字符串有界且无 NUL；版本、事务 UUID、时间字段同时检查。结构异常保留日志与系统设置，禁止恢复写入。索引加载拒绝非法设置/字段类型，保存前限制明文和密文各 8 MiB，失败不替换旧索引。

普通退出恢复失败时保留内核与日志，解除 exiting，恢复必要健康检查和明确开启的维护，允许处理问题后重试。不会把退出失败当作成功停止。只读保护仍允许导出脱敏诊断，报告包含只读标志及原错误；成功导出不解除保护、不改损坏索引。

自启设置区分用户草稿、系统已知/开启/冲突观测及持久化结果。OS 回读确认后即使索引保存失败，界面仍显示真实系统结果并报告保存失败；再次启动重新读取 OS。测试注入 PlatformServices，生产仍选择 Windows 实现。

来源 URL 最长 4096 编码字节。下载地址检查补齐文档地址段、IPv6 特殊转换地址与 NAT64 私网嵌入。普通 IPv6 仅接受 2000::/3 中非禁用段，标准 NAT64 64:ff9b::/96 验证其嵌入 IPv4；2001::/23 按保守边界整体拒绝，包含少数公网协议例外，因此不承诺所有 IPv6 特殊用途地址可用。依据 [IANA IPv4 注册表](https://www.iana.org/assignments/iana-ipv4-special-registry/) 与 [IANA IPv6 注册表](https://www.iana.org/assignments/iana-ipv6-special-registry/)。这仍是来源下载约束，不构成 mihomo 完整网络沙箱。

保留本地 v1.0.0 基线，增量版本为 1.1.0，使用独立便携目录，用户数据格式向旧索引兼容。完成 Windows 17 项 P0 实现及已接受的 Windows P1 增强；需求映射逐项列证据。macOS、国际化与明确排除的 P2 不计入本次 Windows 实现目标。

## 验证边界

候选保护使用真实 mihomo 的模式回读；损坏索引/日志、恢复重试、自启写成功但索引保存失败使用隔离注入平台，绝不写用户代理/Run。构建、回归、原生界面和便携包结果由 verification-report 记录。真实 OS 写入、登录、Explorer 重启、干净机器、休眠、72h 与性能预算继续独立验收。
