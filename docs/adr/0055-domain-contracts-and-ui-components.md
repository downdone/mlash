# ADR 0055：纯契约库与按职责拆分的 UI 组件

状态：已接受（2026-11-16）。

## 背景

存储与订阅解析为了验证连接列、测速目标、TUN 参数和快捷键而包含上层模块。`MainWindowParts.h` 同时定义控件、委托、节点模型、导航和顶栏；`MainWindow.cpp` 混合页面布局、反馈、全局状态与路由。局部改动会扩大编译和审查影响，也难以判断模块所有权。

## 决定

纯值对象和无副作用校验放入独立 `mlash_domain` 静态库。`app/Types.h`、`app/ConnectionColumns.h` 暂作为旧路径的转发头，逻辑只保留一份。配置和存储直接使用 domain 契约。内核 API 路径由 `MihomoClient` 的具名方法集中持有，Controller 不拼接方法与路径。

UI 控件、列表模型、委托和导航按单一职责拆成独立头；`MainWindowParts.h` 仅作为兼容聚合入口。主窗口实现分为外壳、数据、反馈、状态、导航以及已有的首页、配置、代理、设置文件。拆分不改变页面对象的所有权或代理接管流程。后续逐页迁移到直接包含所属组件头，最后删除兼容聚合。

## 后果与边界

构建能单独编译 domain；适配层依赖纯契约，反向包含消除。当前 `AppController` 仍承载过多协调方法，页面生命周期与顶栏暂仍由主窗口管理，JSON 结果也尚未全面变为 DTO；这些属于后续切片，不能因本 ADR 宣称整体架构完成。数据格式、TUN 权限服务协议及系统代理恢复规则不变。
