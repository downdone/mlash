# 0030：密码备份与增量恢复事务

2026-10-15，G04。设计目标完整实现差异功能；提供本地可移植备份，不复制DPAPI密文到其他账户冒充迁移。

`.mlashbackup` v1 是 `MLASHB01`（8字节）、随机salt（16）、随机nonce（12）、GCM tag（16）、密文。固定PBKDF2-HMAC-SHA256 600000次派生256位密钥，使用Windows CNG AES-GCM；AAD为magic/salt/nonce。密码8–1024字符。每次独立系统随机数；错误密码、nonce或密文修改均认证失败，不输出未认证明文。非Windows明确Unsupported。算法调用依照[BCryptDeriveKeyPBKDF2](https://learn.microsoft.com/en-us/windows/win32/api/bcrypt/nf-bcrypt-bcryptderivekeypbkdf2)和[认证模式结构](https://learn.microsoft.com/en-us/windows/win32/api/bcrypt/ns-bcrypt-bcrypt_authenticated_cipher_mode_info)，不自写密码算法，不宣称已通过独立密码审计。

密文负载为无压缩JSON，避免解压膨胀；整体明文≤64MiB，读入source/provider累计≤32MiB，每份source/provider沿用8MiB界限，最多256订阅/每订阅3个被引用版本。负载含偏好、订阅元数据、source和冻结provider字节/原快照时间。可只备份偏好；包含订阅时会含URL令牌/节点机密，因此只输出加密文件。排除运行config里的客户端Secret、日志、恢复日记、内核程序、Geo缓存和OS归属；这些排除在界面显示。源缺失、清单损坏或哈希不符不生成不完整备份，不覆盖旧文件。

恢复必须先预览；预览摘要仅含名称/数量/创建时间/加密文件SHA256。实际恢复重新读取、解密并核对预览SHA，严格复用索引校验；重建新UUID/版本，以来源生成的固定provider相对路径写入，拒绝额外文件或缺失引用。不把归档文件名直接解包到磁盘。只新增订阅，保留已有数据；本地文件来源迁移为新订阅目录内的恢复源文件。每个provider重新校验并重建哈希清单，保留原快照时间。

恢复时内核必须已停止，Mlash代理已释放；不自动停止用户业务。可恢复偏好，但保留本机核心路径/实际自启设置；不恢复自动代理意图/恢复意图/自动启动核心/活动订阅，恢复订阅自动更新默认关闭。构建新文件不触及旧UUID；全部静态校验完成后由Controller原子提交索引，失败清理仅本次新建UUID，旧索引/订阅不变。内核可用性由后续明确激活时的既有校验负责，不把静态恢复声称为已运行。

加解密、文件读取、YAML和迁移在有界worker执行。UI按需打开/销毁，对话框关闭不留GUI资源；已提交写事务由Controller收敛。密码不记录日志、不作为公开事件字段；Qt/分配器可能有临时副本，不承诺进程内所有副本可强制擦除。

F08/S10补充（2026-10-19）：实际恢复可按预览SHA选择唯一整数索引集合，缺省保持旧全选语义；空集合仅在明确恢复偏好时允许。全归档元数据严格检查，只为所选订阅重建版本和Provider。新增名按当前名称和本次选择顺序统一计算，忽略大小写避重、120字符内追加（恢复 N），不覆盖已有订阅。预览列表随当前状态和勾选重算，实际提交再次依据当前索引分配，选择性恢复不扩大系统意图或权限边界。
