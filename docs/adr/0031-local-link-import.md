# ADR 0031：Mlash 自有链接与明确确认

接受G19的自有mlash协议；不注册clash/clash-verge或转换单节点URI。只接受mlash://import?url=<百分号编码HTTPS订阅>&name=<可选名称>，未知/重复参数、用户凭据、片段、控制字符和越界链接拒绝。解析一次保留内层URL编码；不把链接交给Shell或执行脚本。

关联只在设置显式启用，HKCU完整受控树匹配此程序路径才可移除；其他路径/额外内容不覆盖。新增关联在唯一临时键完整写入后重命名提交，回读实际状态。协议启动只允许--import-url和单个参数，不能附带其他命令行选项；冷启动抑制上次内核自动运行，仍检查必要恢复日志。

同数据目录实例通过UserAccessOption的本机管道转交，最多四个连接、2秒读取/19KiB帧；发送1.5秒预算，待确认队列最多四个。必须取得数据目录锁后才能监听。传输成功只代表交付确认队列，不代表导入完成。GUI确认前无订阅网络请求、无激活；取消不写。确认后复用既有下载安全检查与候选版本事务，不自动使用新订阅。
