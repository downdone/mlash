# ADR 0056：独立设计 token 与 Shadowrocket 风格特化

状态：已接受（2026-11-16）

## 背景

`UiTheme` 同时保存视觉值、系统外观状态、Qt 字体/调色板和样式表；页面直接引用其数值。这使系统级精修必须跨运行时与页面定位源值，也容易在明暗模式中产生不一致。

## 决策

以只读的 `UiDesignTokens` 描述语义颜色、几何与字阶；`ShadowrocketStyle` 是当前唯一的取值实现。`UiTheme` 保留 Qt 运行时适配、主题切换及兼容 API；信息架构和分组顺序由页面组合与交互契约管理，不随视觉特化改变。Widgets 仍是 UI 技术基线。

## 后果

可在一个特化中逐级修订颜色、尺寸与字体，而组件按语义使用。兼容桥迁移完毕前，旧调用仍可读取 `UiTheme` 常量；该桥不再是取值的第二来源。本决策不承诺运行时主题插件或无代码的全页重排。
