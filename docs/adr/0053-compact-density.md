# ADR 0053：以紧凑密度修订 U11 尺寸基线

状态：接受。用户指出 U12 与 Shadowrocket 的紧凑程度仍差距明显，要求继续收紧。

沿用四分区、U12 正文工作区与所有业务边界，按 [U13](../design/u13-compact-density.md) 修订 UiTheme 尺寸与 macOS 字号。节点/组头以 38 DIP 起，使用正文及副文实际指标扩展；目录 38 起、配置双行 40 起、顶栏 44、正文边距 12。图标命中与文字放大可访问性保留，正常态不以空白拉伸填满正文。

此决策替代 ADR 0051/U11 中对应的较宽松尺寸和 52 DIP 起节点行要求；不改变信息架构、存储格式、Controller 命令、平台范围或恢复契约。U12 草稿与层级规则继续有效。
