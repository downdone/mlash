# ADR 0041：公开文档基线与重新发布

状态：接受。

## 决策

文档分为使用指南、开发指南、当前契约与历史归档。README 只承担产品入口；版本变化进入 CHANGELOG。架构维护总体状态/安全/事务，功能模块契约维护有界字段与具体调度，交互契约维护当前八页/托盘/反馈。原始规格及已有 ADR 保留决策意图。

阶段方案、旧对照报告及旧交互迭代归档并说明时效，不能把历史“缺失/开发中”误当成当前状态。链接随移动修正，文档检查与隐私检查进入流水线。

重新建立的公开仓库以清理后的初始快照上传，提交身份使用项目身份，发布仅由该仓库验证通过的固定依赖流水线生成。旧验证匿名汇总标为历史结果，不当作新运行证据。

## 结果与边界

重组不改变产品源码、运行状态和数据格式。公开项目地址、通用产品路径和第三方许可署名保留；个人环境、原始配置/诊断、会话记录不随源码或说明分发。

预发布与正式资格继续分开。当前实际构建和发布结果由验证报告维护，不以仓库重建清除尚未完成的系统/长期验收。
