# 0059 · WireGuard Windows 服务权限范围

用户于 2026-11-21 明确授权本 ADR 的权限扩展。已有 Mihomo 资产和生命周期仍按 [ADR 0036](0036-windows-tun-service.md) 执行。

## 服务动作

- 现有按需安装且绑定账户的 MlashTunService 执行随包、固定 SHA-256 的 WireGuard helper。Wintun 采用锁定签名资产。SCM 继续在显式安装或升级时走 UAC。
- 只为该服务拥有的隧道创建一个接口及经过预检的分流路由。接口 DNS 仅允许配置所需且在受管分流范围内的解析器。服务操作必须针对已确定的 LUID 和地址，不接受用户指定进程、命令行、脚本、DLL 路径或任意 Windows 配置。
- 同一服务管道保留 Mihomo v1 消息。WireGuard v2 通过独立操作和有界配置帧使用同一个串行系统路由租约。身份检查仍为绑定账户 SID 和服务 PID。helper 使用白名单继承句柄，配置经私有通道传入，日志与回读保留白名单字段。
- 对路由、地址及 DNS 变更先持久化恢复意图。每次写入后从 OS 回读。撤销时比对完整归属及当前状态，外部变动进入人工确认，清理未确认则保留记录、阻止新接管。全隧道、防火墙、断线保护及修改系统代理不属于本次权限扩展。

## 验收与启用

在 Windows 受控 VM 上验证安装与签名、账户与进程身份、Wintun 创建、各地址族分流、DNS、三路并发、切网、服务异常及前后路由核对。发布门禁在通过实际验收后更新。导入解析、加密存储、SDK 私有控制帧和无权限测试可独立推进。 [双内核实施设计](../design/mihomo-wireguard-dual-engine.md)
