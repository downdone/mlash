# U01 界面精修审视

设计日期：2026-10-28。实现前完成本节审视；实际执行结果由验证报告维护。当前交互仍以 [交互契约](ui-interactions.md) 为准。

## 原则与参考取舍

按 Apple HIG 的 [布局](https://developer.apple.com/design/human-interface-guidelines/layout)、[按钮](https://developer.apple.com/design/human-interface-guidelines/buttons) 和 [排版](https://developer.apple.com/design/human-interface-guidelines/typography) 处理层级、对齐、渐进展开、按下反馈及文字缩放。Qt Widgets 保留原生窗口装饰，不绘制假交通灯、材质模糊或未实现的系统能力。

用户提供的系统设置参考用于分组列表、组内细线、左侧名称/说明与右侧控件；设置由双列表单改为一列可滚动分组，宽屏限制阅读宽度。另一桌面工具参考仅提取连续侧栏、轻量工具带、低对比面板及卡片留白，不复制其颜色、页签、内容或按钮组合。应用图标与服务资源沿用项目已有资源。

基线问题：macOS 强制 Windows 字体；侧栏悬浮容器与内容卡片层级重复；正文/标题差异小；普通按钮与输入框边框同权；按钮缺少明确按下反馈；设置两列的标签和控件互相挤压；日志与连接工具带缺少窄窗重排；网站卡片的辅助动作权重偏高。仅缩小字体或减少所有间距不能解决这些问题。

## 共用 widget、按钮与密度

| 对象 | 实现前决定 | 验收 |
|---|---|---|
| 主窗/侧栏 | 连续侧栏、单一细分隔；主区四边留白，保留原生窗口 | 默认 940×620、最小 840×560，内容没有横向溢出 |
| 导航项 | 图标/正文一条基线，选中为统一蓝色底/白字；悬停中性 | 八页顺序和路由不变，文字/图标都表达选中 |
| 字体 | macOS 使用系统 UI 字体与 PingFang SC；Windows Segoe UI/YaHei；代码字体独立 | 不再请求缺失的 Windows 字体；正文支持 90–120% |
| 页标题/说明 | 标题与辅助说明分层；辅助说明可换行或省略并保留全文提示 | 所有页标题、工具栏从同一边界开始 |
| 面板/卡片 | 圆角 12 DIP、中性表面、低对比边界；数据列表不套多层框 | 浅深色有层次，高对比保留可辨边界 |
| QPushButton/QToolButton | 常规动作中性，主提交蓝色，危险文字红色；悬停/按下/禁用/键盘焦点分开 | 不用尺寸区别同组动作主次；短按钮标签不裁切 |
| QLineEdit/QSpinBox | 输入框边界比次按钮明确，焦点不改变布局；搜索可清空 | 明文/密码、草稿和验证逻辑不变 |
| QComboBox | 足够箭头留白；已有弹出 view 保留；选项全文提示 | 换肤不销毁 view，首帧圆角，键盘可选 |
| QCheckBox/开关 | 勾选框保持标准键盘语义；设置开关固定轨道、圆形滑块 | 鼠标点击无残余焦点，Tab 有焦点提示 |
| QTableView/QTableWidget | 表头辅助色、清晰行高、柔和选择；滚动承载数据 | 当前/预选分开，不丢选中、顺序或滚动 |
| QPlainTextEdit | 代码/日志使用系统等宽字体，表单文本用 UI 字体；阅读区边界清楚 | 长文本可滚动、复制，不新增日志内容 |
| QTabBar/QTabWidget | 中性分段底座，选中表面，短标题清楚 | 页签与主动作有间隔，不与 corner widget 重叠 |
| 滚动条 | 细轨道、可辨拖动条，横/竖一致 | 设置和目标列表不出现意外横向滚动 |
| 状态栏 | 固定单行高，详情与处理独立；失败内容保留可复制全文 | 消息出现/切页不移动主体 |
| QMenu/托盘 | 统一圆角/边界/中性选择，保留禁用、勾选、子菜单 | 不加动画或轮询，不改变按需请求 |
| QDialogButtonBox | 取消/关闭与提交有明确间隔，按系统次序，默认主动作有区别 | Esc/Enter 保持既有语义，不新增确认 |

基准尺寸：主区边距 20 DIP、常用控件约 30–32 DIP、表格行约 32 DIP、面板内边距 14–16 DIP、组间距 12–16 DIP；文字变大时采用最小高度及换行，不用固定高度裁字。图标按钮至少保留 28 DIP 命中范围；这是桌面 Qt 密度选择，不宣称符合触控目标尺寸。

## 八页逐项决定

| 页面 / widget 或动作 | 布局、层级与紧凑程度决定 |
|---|---|
| 首页标题、规则/全局/直连、内核启动 | 标题左、模式/核心命令右；分段统一底座，启动为当前任务入口 |
| 首页实际状态、系统代理、TUN | 同一摘要面板中名称/观测与开关分行组织；未知不伪造为关闭 |
| 首次使用引导 | 单个清晰标题、简短说明，沿用顶部添加入口；避免再堆同权按钮 |
| 当前订阅、实际成员 | 两张主摘要同一内边距；跳转为弱动作；组/成员控件保持独立点击 |
| 指标、曲线、更多、探测间隔 | 指标紧凑对齐，更多默认收起；探测仍按原可见性策略 |
| 订阅标题、剪贴板、批量更新、添加 | 仅添加为主色；其余中性；标题工具带空间不足换行 |
| 订阅表格四列 | 名称弹性，来源/时间/状态稳定；空态居中，行高统一 |
| 订阅更新、变化、来源、管理、使用 | 选中对象才展示上下文；使用为主动作，管理不吞掉更新/变化 |
| 代理标题、模式 | 与首页同样的分段；页标题与顶部动作对齐 |
| 订阅、组展开、恢复自动、筛选、管理 | 独立上下文区，次动作弱化，展开组列表保留稳定高度 |
| 节点搜索、排序、表格/卡片、最近、测试 | 使用现有 WrapLayout 依宽度换行；保留搜索弹性和完整动作标签 |
| 节点表格/卡片、地区标志、当前点、延迟 | 主阅读区占剩余高度；单行卡片圆角/留白统一，延迟仍独立重测 |
| 使用选中、定位当前、取消测试 | 底部上下文反馈与提交分组；浏览和测速仍不直接切换 |
| 测速标题、编辑目标 | 编辑为次动作，标题工具带与其他页一致 |
| 节点选择、开始/停止、清空 | 主/次明确，开始和停止保留同一占位；节点选择有足够宽度 |
| 测速进度/最近时间 | 一条辅助信息，不与卡片主延迟竞争 |
| 目标图标、名称、主机、详情 | 名称清晰、主机辅助；详情使用小型安静图标按钮 |
| 目标延迟、状态、单卡测试 | 延迟为主值，状态点配文字；单卡测试中性，卡片按可用宽度重排 |
| 规则订阅选择、提供者 | 在分组顶部，操作对象始终明确 |
| 自定义/实际规则页签、列表编辑入口 | 页签与高级入口分行，避免窄窗 corner widget 挤压 |
| 类型、匹配、目标、添加 | 作为可换行的规则构造器；输入框主导宽度 |
| 高级文本/实际规则表格 | 主阅读/编辑区域，代码字体；空/错误提示就近 |
| 规则还原、保存 | 还原弱动作，保存主动作右侧；草稿/运行语义不变 |
| 连接流量、暂停、关闭全部 | 累计数据与动作分组，危险动作明确文案 |
| 活动/离开、搜索、Aa/整词/正则/列 | 页签单独一条基线；搜索和筛选工具带在窄窗换行 |
| 连接表格、空态、采样状态 | 稳定表头/行高；默认列适配可用宽度，完整值在详情 |
| 连接详情、复制、关闭选中 | 底部按阅读→复制→危险动作排列，选中不足时禁用 |
| 日志搜索、级别、暂停、复制、清空、诊断 | 可换行工具带，搜索弹性；复制/清空中性，保留原语义 |
| 日志正文、阅读说明、回到最新 | 等宽正文，轻边界；阅读/选中不受换肤影响 |
| 设置标题、搜索 | 标题左、搜索右；组内容一列、宽屏限制阅读宽度 |
| 登录/静默/内核启动/恢复代理/轻量 | 分组行，解释性条目更高；开关右对齐，不压缩文字 |
| 启动页/托盘动作/外观/文字/首页摘要 | 同列控件对齐；长选项保留箭头空间 |
| TUN/端口/排除/日志/IPv6/统一延迟 | 单列分组，短说明辅助；独立工具入口保持可发现 |
| 测速 URL、内核路径、文件选择 | 标签在上、宽输入在下，避免双列截断 |
| 备份/恢复/WebDAV/本地保护 | 归为数据与恢复；明确动词，不增加自动动作 |
| 目录/地址/环境变量/Geo/配置/快捷键/协议/诊断 | 归为工具，原命令保留，入口为安静按钮 |
| 设置还原/应用、待应用数量 | 固定底栏，主提交右侧；滚动不移出视野，失败留稿 |

## 验证设计与结果复核

使用隔离内存平台及公开虚构数据渲染空态和已填充状态，不启动 Windows 内核，不写系统代理。八页以浅/深色、三种尺寸及 120% 文字采图，核对可见按钮/标签边界、设置滚动、搜索、页签、下拉首帧、草稿、选中和状态栏稳定。至少覆盖：按钮有按下态、键盘焦点可见、普通鼠标无焦点残留、隐藏/重建、错误/取消和旧上下文不能写回。

实施后逐页回看同表，几何/行为回归和截图仅是自动化证据；macOS/Windows 人工读屏与系统资格仍单独记录。

## U02 信息减噪与任务重审

2026-10-28，在 U01 上继续调整。用户指出常驻描述杂乱，并授权必要的布局重设计；本节为实施前设计，不将计划当作已验结果。

原则：标题说明任务，控件名称说明动作；同一状态只在一个主要位置表达。正常状态不重复宣告“无修改”“没有待更新”“不会自动联网”“不改变运行版”；实现容量、调度、缓存、校验细节进入说明或提示。失败原因、尚待应用/保存、观测未知、来源/覆盖差异、备份密码及危险操作后果仍明确可见。不能把所有长文字一律隐藏。

| 范围 | 具体调整 |
|---|---|
| 全局状态栏 | 保留固定占位；空闲不重复内核版本/本地地址，只有初始化、任务、成功短反馈和持续失败才显示消息/详情。错误可复制，详情按钮随消息出现不移动主体 |
| 首页 | 首次使用只留订阅引导，去掉重复停止状态；正常保留运行摘要、实际代理归属及独立开关。删“点击上方”教学、未检测出口占位和展开区重复原理段落；有真实出口结果才显示摘要 |
| 订阅 | 选中名称已在列表中，不在工具带再复述；底部只提示待应用、未使用或失败，去掉“无待更新/自动更新关闭”常驻说明。来源、更新时间、用量仍在对应列/维护窗口 |
| 代理 | 组标题、当前成员、预选语义保留；未就绪原因在空态表达一次，底部不再重复教用户。搜索/排序/视图/使用仍直接可达 |
| 测速 | “未测试”和未知延迟仍保留；去掉未测日期、主机名与名称双行重复、底部方法长入口。方法为标题栏小型说明入口；正常汇总只列目标数/完成数，阻塞原因保留 |
| 规则 | 去掉标题副说明和编辑器教学段落；格式例子留在提示。列表编辑成为正常任务按钮。草稿/错误与保存合并到底栏，正常无修改时安静 |
| 连接 | 去掉页标题中的刷新周期；空态说原因，底栏只留暂停/失败/必要采样时间，不重复活动数量和“尚无成功采样” |
| 日志 | 去掉订阅范围/2000 行实现说明，移到提示；“回到最新”并入工具带，释放正文高度；阅读位置和暂停语义不变 |
| 设置 | 自解释行不再加副文；仅轻量模式与启动代理保留必要差异说明并缩短。无修改时底栏不写“没有未应用修改”，待应用数量/失败保留 |
| 工具窗口 | 常驻段落收敛为一句与当下决定有关的信息；较长技术说明经可键盘访问的“说明”入口按需阅读。权限、密码不可找回、规则匹配顺序、DNS 沿用/覆盖、TUN 独立关系保留必要短句 |
| 表单反馈 | 正常无修改不重复声明“字段保留/草稿同步机制”；错误、未同步和来源覆盖标签保留。输入例子与字段名称避免同时重复一段教学 |

## U03 任务流程与信息架构重审

2026-10-28，用户要求先整体、再逐页审视逻辑、入口深度、直白程度、布局与命名，并授权删除无必要内容、补齐缺失内容及必要重设计。以下为实施前方案；不以视觉清爽代替任务可完成。

### 整体任务与原则

首次使用为“添加订阅 → 导入校验 → 使用并启动 → 按需开启系统代理或 TUN → 选节点 → 网站测试”。日常为“首页确认运行与接管状态 → 节点切换/测延迟”；维护为“订阅下载更新 → 查看变化 → 应用更新”。每步必须有可见下一步，不能要求先理解候选、激活或 YAML 语法。

初始方案保留八个职责并列，用户随后提供 Shadowrocket 参考后收敛为下文四分区；内部页面 ID 与持久化值不变；“代理”改为“节点”，“测速”改为“网站测试”。节点页的 HTTP 延迟测试与网站响应测试分别命名，不承诺带宽或解锁。已使用订阅不等于内核就绪，内核运行不等于流量接管；仅显示实际状态，不自动开启系统代理、安装服务或执行测试。

结构遵循“页标题/全局操作 → 当前对象 → 内容 → 对象提交”。常用动作直接显示，低频管理保留单层菜单；同一动作复用现有命令，不另建含糊捷径。删重复标题、首屏不必要工具和纯技术词；必要状态及后果不能因减噪而消失。

用户进一步要求功能不散落：订阅拥有来源/版本及该订阅的节点、DNS、上游代理链、节点源；节点页只拥有选择/切换、延迟与显示偏好，不再另设订阅维护入口。规则页拥有规则编辑与规则源。网站测试拥有响应测试及出口/服务诊断；首页只导航过去，设置移除重复诊断和订阅 DNS 编辑。设置拥有应用偏好、全局网络/内核、备份维护；搜索可路由到其他功能的所属页面。跨页导航不复制独立配置流程。

自动策略组的手动选择会固定成员，动作明确称“固定节点”，显示“自动选择中/恢复自动选择”，不以普通切换掩盖该后果。设置日志等级显示中文、协议值留在控件数据；组内选项区分当前组的测试/显示与整份订阅的断开连接行为。规则列表只渲染有界行数，超限文本完整保留并阻止保存，不因视图整理截断输入。

### 逐页方案

| 页面/窗口 | 问题与取舍 | 采用方案与验收 |
|---|---|---|
| 首页 | 空态只有文字，行动在远处；启动与接管容易混淆，首页立即切成员与节点页预选语义不一致 | 空态卡片内直接添加/选择订阅；隐藏重复顶部入口。运行摘要明确内核与系统代理/TUN 的实际归属。首页节点下拉仅预选，显式“切换”才提交，切换组/状态更新不沿用旧预选 |
| 订阅 | “可激活/候选/管理”用词偏实现；对象操作堆在列表上方且主动作易消失；节点/DNS 编辑藏于管理 | 表头称“获取方式/获取时间”；状态区分正在使用/已选用但停止/未使用/有更新。顶部只添加/批量，列表下方固定使用/应用主动作；编辑节点与来源、DNS 等常用配置提供清晰单层入口。多选时禁用单对象入口，不以当前行冒充选中集合 |
| 节点 | 页面名不匹配任务；当前/预选表述不够明确，策略组入口只显示组名 | 页面与导航叫“节点”；策略组按钮有明确“策略组”语义；“测延迟/切换节点/待切换”直白命名；不同订阅或未就绪时，空态有可用的去订阅/启动路径，不只一行死文字 |
| 网站测试 | “测速”容易被当作带宽；诊断入口分散；不理解结果范围 | 名称改为“网站测试”，主动作“开始测试”；首屏保留一句“测试网站响应延迟”，带宽/解锁边界在说明；出口/服务诊断在页标题工具带。未就绪有“前往首页”入口，单卡详情保持直接可达 |
| 规则 | 默认裸文本要求语法知识；列表编辑藏在底部，优先与完整规则关系不清 | 默认按类型/匹配内容/目标显示优先规则列表；快速添加、删除/顺序操作直接可用，文本作为显式高级视图并共享草稿；“完整规则编辑…”在对象工具带直接打开前置/订阅原规则/追加/规则集窗口。区分可编辑订阅规则与内核实际规则，保存失败留稿 |
| 连接 | “已离开/关闭”容易混淆观察记录与断开动作 | 页签“活动连接/已结束”，操作“断开选中/断开全部”，详情明确快照。无内核时提供回首页动作，暂停和非法查询仍直接显示；不得自动断开 |
| 日志 | 诊断导出藏菜单，排障时还需查找；普通工具带过多 | 脱敏导出前移为直接按钮；目录和换行保留低频菜单，清空仍明确只清视图。暂停/恢复命名说明暂停的是显示，不冒充停止内核运行 |
| 设置 | 单列虽清楚但目录过长；“静默/轻量/恢复系统代理”不直白或有歧义，DNS 订阅范围不清 | 增加常规/网络与内核/备份与工具的可见分类，单列与固定全局应用栏保留；分类切换不丢草稿，搜索自动显示所在分类并定位。命名为启动时隐藏窗口、关闭窗口时释放界面、启动时恢复代理开关等具体行为；订阅 DNS 入口归入订阅，设置搜索提供路由 |
| 导入及编辑工具 | URL 页面子布局把短内容拉出大空白；Provider/拨号链等术语缺少中文任务含义 | 导入字段顶部对齐，链接/配置文件/节点链接清晰命名；导入成功给出“前往订阅”下一步。提供者称“节点源/规则源（Provider）”，代理拨号链称“上游代理链”，保留协议字段标识。工具窗口只在影响决策处解释范围与后果 |
