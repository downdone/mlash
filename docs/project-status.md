第二版把界面改为原型的分区与交互形态：

- **K1**：内容区首行固定 72px 顶栏（标题 + 副标题 + 状态胶囊 + 主题/更多），侧栏 4 项 43px；视图编号收敛为 `ViewIds`（首页 0 / 配置 1 / 规则 2 / 数据 3 / 设置 4），旧编号 0–7 只在 `ViewIds::fromLegacy()` 一处解释。
- **K2**：路由方式改为行点击弹浮层菜单（三项带勾），不再行内展开分段。
- **K3**：节点详情改为右侧 410px 抽屉，自动组不提供「切换」。
- **K4**：节点标题行照原型：计数 + 订阅 chip + 搜索 + 测速/排序图标钮，删除第二行「使用并启动」。
- **K5**：首页删除「更多运行信息」抽屉、曲线、出口摘要、探测间隔行、代理总开关按钮与空态卡；顺序固定为控制卡 → 节点标题 → 节点列表 → inline-stat。
- **K6**：连接/日志/网站测试合并为「数据」页的四个页签（流量/连接/测试/日志），可见性按当前页签 OR 合成。
- **K7**：配置页改为「远程订阅 / 本地配置」两张 76px 行列表 + 410px 详情抽屉。
- **K8**：设置页删除分类页签，改为「通用 / 网络 / 内核与维护」三张卡片，行尾「值 + ›」。
- **K9**：被删控件对应的测试改写为断言新结构（不删断言），并修掉改写过程中暴露的产品缺陷。

K9 暴露并修掉的产品缺陷：侧栏「数据」打开规则页、「设置」打开数据页（侧栏存的是视图 ID，却交给 `setPage()` 当旧编号解释）；`navigate()` 与 `PageRouter::go()` 各留一次「view==2 → 首页」的历史归一化，把规则视图吞掉；设置深链不滚动且导航后丢分类；两张订阅列表共用菜单对象名导致本地列表右键失效；菜单以模态方式挡住它打开的对话框；浅色品牌色与主色对比度不足；深色主按钮白字只有 3.55:1（原型 `#2488f5` 本身不达标，深色 `Primary` 取同色相深一档 `#1968c2`）；控制区路由行改名后行样式落空、失去行背景与键盘焦点环；非数据页的路由错误地带上数据页签。另有一处 QSS 陷阱：样式表里写了 `//` 注释，Qt 只认 `/* */`，其后的规则被静默丢弃且不报错。逐条根因见 [U08 §7.7](ui-u08-plan.md)。

视图编号收敛为 5 个、数据页四页签、设置三组平铺这三项是路由模型的实质变更，已按约定记入 [ADR 0049](adr/0049-view-ids-and-data-tabs.md)（取代 ADR 0046 的「设置三分类为可寻址视图」与 ADR 0048 的「索引 2 映射首页」实施细节；命令集合与持久化 schema 不变）。

**其余在途项**：S3（TUN 意图/观测分离）按其设计文档要求需独立 ADR，尚未开始。
