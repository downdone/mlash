# 使用指南

## 安装与升级

从 [Releases](https://github.com/downdone/mlash/releases) 下载 Windows x64 便携 ZIP 及同名 SHA256 文件。完整解压至独立目录，再运行 `Mlash.exe`；不要只提取 EXE。预发布的支持与未验范围见 [验证报告](verification-report.md)。

升级前在托盘退出旧版，并通过“设置 → 备份与工具”创建密码归档。若原版本启用了登录自启，应先关闭旧目录自启，再在新版本开启，以便系统登记新的程序路径。

默认数据目录为 `%LOCALAPPDATA%/Mlash`。程序目录可移动，但加密索引绑定 Windows 账户；跨账户迁移应使用密码备份，不能直接复制状态文件。首次启动不会自动接管已有系统代理。

主导航按首页、配置、数据、设置组织：首页查看状态、选节点和做网站测试；配置管理订阅与规则；数据查看连接和日志。域内页签直接切换，设置搜索也可定位其他功能。

## 导入订阅

在“配置 → 订阅”选择“添加订阅”，输入完整 YAML 配置的 HTTPS URL，或选择配置文件。节点分享链接可以先离线预览，再创建快照或加入已有订阅的节点草稿。确认导入后才执行下载/校验；取消不会自动使用配置。

导入成功后进入订阅页，选择订阅并点击“使用并启动”，等待内核就绪，再按需在首页开启系统代理或 TUN。启动内核本身不代表流量已经接管。错误会保留输入或草稿，使用状态栏详情查看完整的脱敏原因。兼容性说明可在订阅行右键菜单中查看。

URL 订阅可重新下载；文件快照维护方式由实际来源决定。来源与更新设置在列表下方；“编辑配置”集中提供节点/策略组、DNS、上游代理链和节点源编辑。重命名、回滚、排序和删除位于“管理”或行右键菜单，也可用菜单键或 Shift+F10 打开。

## 更新与切换版本

“更新订阅”只生成候选，不覆盖正在运行的版本。存在候选时先查看变化，再点击“应用更新”；失败保留原运行版本和候选。运行版与候选版的编辑对象会明确标注，旧编辑窗口不能覆盖已经变化的对象。

定时更新、文件监测和 Provider 自动计划均须明确启用，默认关闭。更新失败保留当前配置；源未提供用量时不显示推测的额度。

## 选择节点与测试

“首页 → 节点”默认优先展示当前组的成员，可展开切换策略组。表格和卡片共用搜索、筛选、默认/名称/延迟排序、预选和当前成员状态。单击预选，点击“切换节点”或双击后才提交选择；浏览其他组不会改变运行模式。

卡片延迟区域可悬停并单独点击重测，不会切换节点。“测本组延迟”测试本组成员；“首页 → 网站测试”用于指定节点到常见网站的响应测试。结果仅表示本次目标响应，不代表带宽、所有流量可用或服务解锁。无法确定单一出口时需要明确选择测试节点。

首页下拉选择节点后需点击“切换”；仅浏览或预选不会改变内核选择。网站测试页还集中提供出口与服务诊断。

托盘展开具体组并停留后可按需测延迟，短期复用结果；关闭菜单停止后续请求，不自动选取最快节点。

## 系统代理与 TUN

系统代理只影响遵循 Windows 系统代理的应用。已有外部代理时，Mlash 会说明归属并要求明确接管；退出只恢复仍完整匹配自身写入快照的设置。外部修改或恢复失败时保留恢复记录，不强行覆盖。

TUN 为可选高级功能，默认关闭。在“设置 → 网络与内核 → TUN 虚拟网卡”明确安装服务后启用；安装/移除会触发系统 UAC。GUI 保持普通权限，服务仅运行固定哈希的随包内核。移除前先关闭 TUN；不清理其他软件的网卡/路由。实际系统级验收仍有未完成项，详见验证报告。

## 规则、连接与日志

规则按订阅保存，可前置/追加或屏蔽来源规则；保存会校验并安全重载，失败留稿。“当前内核规则”显示观测结果，不代表尚未保存的草稿。

连接页可查看目标、命中规则、代理链、速率和详情，支持过滤与关闭。活动/已离开只表示当前观察会话；离页或隐藏后停止采样并清空记录，不作为所有系统连接的历史。“关闭”需回读确认，连接切换成功也不表示已有连接全部迁移。

日志页按需订阅，可暂停、筛选和导出脱敏诊断。提交问题时仍需检查导出内容，不公开原始 YAML、来源 URL、令牌、密码或连接快照。

## 备份与内核维护

密码备份支持预览和选择性新增恢复，恢复不会自动启动内核或接管代理。自动备份和 WebDAV 计划默认关闭；显式开启后关闭主窗口仍可能继续执行，退出程序后停止。请独立保管备份密码。

内核更新采用“检查/下载或选择文件 → 副本预检 → 确认应用”，失败保留可回退版本。TUN 仅允许固定随包内核；其他内核须先关闭 TUN，官方更新不保证包含随包补丁。

## 窗口与退出

“关闭窗口时释放界面”默认开启，关闭窗口释放主界面，内核和托盘继续运行；从托盘打开时重新创建界面。尚未保存的设置/规则会先确认处理。轻量模式不保证某个固定内存数值。

彻底退出使用托盘“退出 Mlash”。若恢复代理失败，按提示解决冲突后重试，不要把关闭窗口误认为已退出。

## 常见问题

| 现象 | 处理 |
|---|---|
| 内核尚未就绪 | 检查订阅是否已使用，查看状态栏详情和脱敏日志；首次 Geo 数据准备可能需要等待 |
| 更新后节点未改变 | 检查是否仅下载了候选，确认变化后应用更新 |
| 系统代理显示外部管理 | 检查其他代理软件；按需明确接管，避免多个客户端同时写入 |
| 网站测试超时或受限 | 重测具体目标并查看响应证据；不要把延迟测试当作服务解锁结论 |
| 索引损坏进入保护 | 保留原文件，按恢复流程处理；不要直接删除状态或恢复日志 |
| TUN 缺失/不匹配/待清理 | 在管理窗口检查服务、固定内核及恢复原因；处理后明确重试 |

产品数据、进程和恢复约束由 [架构](architecture.md) 维护；发行资格由 [验证报告](verification-report.md) 维护。
