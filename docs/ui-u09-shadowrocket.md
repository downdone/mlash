# U09：Mlash 桌面体验重新设计

状态：**设计提案，未实施**。本轮只形成最终整合方案、离线原型和技术评审，不修改产品源码、依赖、存储及已有未提交实现。

阅读顺序：本文（原则 → 元素 → UI）→ [系统设计](design/u09-system-design.md)（功能定义 → 架构 → 模块 → 协议 → 接口 → 功能设计）→ [技术选型](design/u09-technology-review.md)。[最终交互原型](design/u09-final.html) 使用合成数据，不连接真实程序。

## 1. 原则与依据

主任务顺序为：知道当前接管状态 → 使用配置 → 选择节点 → 必要时调整 → 定位问题。完整功能不等于首屏放满入口；简约依靠稳定层级、清楚对象和渐进展开。

macOS 设计原则是方法，Shadowrocket 是视觉与交互参考，不把每个截图按钮都当作功能需求。保留 Mlash 小象和名称，窗口按钮、文件选择与快捷键服从实际平台，不在 Windows 画假的 macOS 三色按钮。

官方依据：

- [Designing for macOS](https://developer.apple.com/design/human-interface-guidelines/designing-for-macos)：适应桌面窗口、键盘与指针，减少不必要的模态层级。
- [Sidebars](https://developer.apple.com/design/human-interface-guidelines/sidebars)：稳定顶层导航、简明标签、受控层级。
- [Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars)：工具作用于当前内容，常用动作有稳定位置。
- [Lists and tables](https://developer.apple.com/design/human-interface-guidelines/lists-and-tables)：区分选择、层级导航、详情与行内操作。
- [Split views](https://developer.apple.com/design/human-interface-guidelines/split-views)：不同窗口宽度下清晰安排列表与详情。

下文尺寸、颜色和分组是 Mlash 的设计决定，不是 Apple 的强制数值。不追求透明、磨砂、渐变和动效堆叠。

## 2. Shadowrocket 元素提取

| 元素 | 设计作用 | Mlash 采用方式 |
|---|---|---|
| 四项侧栏 | 顶层任务稳定 | 首页/配置/数据/设置，规则归配置，不增第五项 |
| 居中标题、少量工具 | 页面身份清楚 | 左右独立等宽动作位，不把标题挤偏 |
| 黑画布、深灰分组 | 层次而不是粗边框 | 浅/深主题采用同一语义表面，高对比独立 |
| 整组圆角、缩进细线 | 一组对象是一块 | 标题在组外，中间行不各画卡片 |
| 蓝色线性图标 | 提示动作和定位 | 有限统一图标，危险/失败单独语义色 |
| 国旗、协议、副标题、延迟 | 高效扫读 | 名称推断地区仅作提示；实际协议和真实测试值 |
| 当前勾选 | 生效对象明确 | 仅实际回读成功后打勾，预选/pending 不假成功 |
| 行末值与箭头 | 收敛复杂控件 | 设置目录到详情；直接布尔偏好使用开关 |

不复制真实订阅、节点/地址、无实现的 Wi-Fi 上传、Tailscale、模块商店或二维码扫描占位。信息按钮只看详情，子组用箭头进入；不能用同一个 ⓘ 同时承担两种行为。截图中的默认配置黄点不采用，因为当前产品没有独立默认配置语义。

## 3. 信息架构

```text
Mlash
├─ 首页：连接控制 → 浏览组 → 节点 → 详情
├─ 配置：来源列表 → 配置详情
│                    ├─ 版本与候选变化
│                    ├─ 规则与规则集
│                    ├─ DNS / 节点与组 / 拨号链
│                    └─ 来源、维护、删除
├─ 数据：流量 | 连接 | 网站测试 | 日志
└─ 设置：通用 / 连接与网络 / 维护与数据 / 关于
```

一个任务最多“分区 → 列表 → 详情/编辑”三级。规则保留独立任务页、明确返回配置和对象上下文，不能只藏在右键菜单。四项侧栏不随内核状态变化，数据页签只为当前可见任务采样。旧页号兼容留在单一适配边界，不能用旧数字推导新导航。

## 4. 布局与视觉规范

默认候选 1040×720 DIP，最小验收 840×560；保留已有保存尺寸。侧栏默认 204（允许 180–260），顶栏内容高 56，内容边距 20–24、组间距 24、组内 16，圆角 10。控制/节点/配置行高分别从 48/54/56 起，放大字号按字体度量增长，不能固定高度裁字。

顶栏标题居中约 15pt/semibold，左右动作位各至少 72；去掉副标题、状态胶囊和大品牌。macOS 用原生标题/工具栏规则，Windows 保留系统标题栏。窗口宽度不足 980 时详情转为页内后续页；大窗检查器 320–380，不能覆盖操作或挤坏列表。

| 语义 | 浅色候选 | 深色候选 |
|---|---|---|
| canvas | #F2F2F7 | #000000 |
| navigation / toolbar | #F5F5F7 | #202020 |
| group | #FFFFFF | #1C1C1E |
| separator | #E3E3E8 | #343436 |
| primary text | #1D1D1F | #F5F5F7 |
| secondary text | #63636B | #A1A1AA |
| link / icon | #0066CC | #4DA3FF |
| navigation selected | #0066CC / 白字 | #075FBE / 白字 |
| positive | #18724A | #64C98A |
| warning | #865000 | #EFB66A |
| error | #B32636 | #FF8A96 |

选中底与链接蓝分开，不能为截图蓝牺牲白字可读性。正文对比目标至少 4.5:1，焦点/关键边界至少 3:1，最终需计算/原生验收；此处未声称已达标。常规主文字 11pt、次要 9–10pt，使用平台系统字体和中文回退，不分发 Apple 字体。图标 20–22 DIP，线宽约 1.5–1.8；高 DPI 清晰绘制。

默认一页一个主滚动区域。首页控制组固定、虚拟节点列表占余量；配置/设置按内容高度滚动，不把少量行拉成大空框。无必要不加影子或装饰动画，减少动态效果时禁用转场；菜单首帧正确圆角。

## 5. 首页

```text
侧栏            ┌──────────── Mlash ──────────── ＋ ┐
首页            │ ┌ 当前成员 / 未连接        [开关] ┐ │
配置            │ │ 全局路由            规则模式 › │ │
数据            │ └ 连通性测试              测试 ⓣ ┘ │
设置            │ 当前组 ▾    搜索…    测速 排序 …   │
                │ ┌ 实际浏览组 · 当前成员          ┐ │
                │ │ 国旗 名称          ✓ 120ms ⓘ │ │
                │ │      实际协议                 │ │
                │ └ …                             ┘ │
                └ 最近操作               当前告警 ──┘
```

连接开关可访问名称明确“系统代理连接”，不暗示 TUN 或全系统流量都接管。TUN 在网络设置独立控制，运行时说明实际接管方式；外部/未知/恢复失败保留文字告警，不能只画关闭开关。

路由行弹带勾菜单，“配置规则 / 全局代理 / 全部直连”与实际 rule/global/direct 对应，写后回读才更新值。测试按钮只读探测，不切模式或成员。三行不重复堆长状态，完整原因在提示、详情及固定状态栏可达。

手动叶子单击提交一次，pending 局部显示，回读成功后勾选；自动组只能浏览/测试，不单击固定。子组箭头进入，ⓘ 只看详情。延迟独立 hover/键盘命中并重测，F5 测所选；排序在按下/释放间变化不能误测。失败不能画 0ms。

默认原顺序，可按名称/延迟稳定排序；未知/失败在有效结果之后。搜索只是浏览。更换浏览配置/组不自动激活；使用其他配置是明确的“使用此配置”操作，不能由 combo change 隐式触发。

空态保留控制组，列表提供导入或使用已有配置；启停/恢复显示具名阶段，仍可浏览详情，禁止破坏事务的重复写入。长名称单行省略、提示/详情可读全文，不靠缩小字体塞协议。

## 6. 配置

顶栏 ＋ 打开订阅链接/文件/节点链接菜单；页面显示导入与更新的任务入口，批量/低频操作收入有名称的菜单。远程/本地按实际行数分组，不等高填充。

行显示名称、来源类型、更新时间、当前勾选、有候选/失败；用量只有来源有效字段时显示。单击或 ⓘ 打开详情，不自动运行。详情主要动作是“使用此配置”或“查看更新”，下载、比较、应用始终分开。

“规则与分流 / DNS / 节点与组 / 维护与来源”直接可达。来源 URL 默认隐藏，复制需明确动作；版本差异不泄露原文。删除、恢复及重载说明影响，失败留稿和原运行版。冻结文件快照不因源文件删除失效。

## 7. 数据

四个稳定页签为流量/连接/网站测试/日志。流量只显示真实指标，首样本未知速率不填零。连接保留桌面表格的字段对照能力；窄窗可收起次要列，目标、状态和详情可达。

网站卡片保留图标、主机、状态、延迟和重测，不绘制假曲线；节点归属冻结，响应不等于解锁/带宽。日志保留选择、过滤、暂停与恢复跟随。连接已离开只属于观察会话，隐藏清空；断开回读确认原 ID 消失，不宣称所有流量已迁移。

## 8. 设置

通用（外观/文字/启动/托盘/快捷键）、连接与网络（代理排除/TUN/端口/DNS）、维护与数据（内核/Geo/备份/日志）、关于四组。组外标题，行内“蓝色线性图标 / 名称 / 当前值 / ›”，图标不再加彩色方底。

即时布尔偏好直接开关，失败回到实际值；枚举就地选单，多字段/敏感/重启类进编辑页，固定保存/取消。需重启明确“保存并重启”，不把旧网络草稿夹带到普通偏好提交。主题不占全局顶栏。

不是所有行都弹模态框：连续编辑走详情，长流程用单一任务窗口，同工具同对象只有一个编辑实例。备份先停机条件/预览/选择/确认，恢复不自动运行；内核先副本预检再确认应用，TUN 固定版本冲突先说明。

## 9. 状态和输入矩阵

| 场景 | 呈现/动作 |
|---|---|
| 无配置/未使用 | 明确导入/使用下一步，导航稳定 |
| 启动/切换 | 阶段和局部进度，写入串行，浏览可用 |
| 外部代理/未知 | 文字说明，接管须明确确认 |
| 测试超时/失败 | 显示失败和重试，不复用旧成功值 |
| 编辑失败/过期 | 保留草稿与原版，重新加载/重试明确 |
| 采样过期 | 当前数字未知，显示最后成功时间 |
| 恢复失败 | 常驻告警，不被成功提示覆盖 |
| 轻量关闭 | 先处理草稿，再停观察/销毁 UI，内核托盘保留 |

Tab 按阅读顺序，侧栏方向键导航，Enter 执行动作，Esc 关闭最近浮层并还焦点，Ctrl/Cmd+F 搜索。鼠标不残留键盘焦点框，键盘必须可见；延迟/详情不依赖 hover。固定状态栏分别呈现最近操作和当前告警，消息不推挤正文、不抢焦点。

验收覆盖浅深/高对比、120% 文字、125/150/200% DPI、长中英文、最小窗、详情返回与滚动恢复。非敏感书签有界，真实连接/来源凭据不持久化在 GUI。

## 10. 组件与验收顺序

组件：AppShell、SidebarItem、PageToolbar、GroupedList、ActionRow、ConnectionRow、NodeRow、ConfigurationRow、SettingRow、Inspector、EditorPage、OperationStatus。统一尺寸/颜色/命中；每行定义展示、鼠标、键盘、可访问名称、pending/disabled/selected/current。

顺序：线框 → 静态浅深视觉 → 空/忙/失败/取消 → 键盘/辅助功能 → DPI/生命周期 → 性能/部署。离线预览不是产品已实施或平台验收证据。先验证组件与选型，再逐层固化功能和接口，最后实施；旧 HTML 原型不作为新 UI 的直接规格。

## 11. Verge 优点补充

[Verge 静态源码评审](design/u09-verge-review.md) 定义 V01–V08 的适配理由与验收。采用其操作效率与对象上下文，不改变本方案的四分区及简约视觉：

- 节点工具将“定位当前”提升为直接入口；常驻组选择/搜索/定位/测速，排序采用明确带勾菜单，不盲循环。
- 本组测试目标与结果新鲜度可就近查看；子组显示直接 now，详情可查看有界解析链，未知成员不当叶子执行。
- 配置详情补充有效用量/到期、下次维护、最近失败和明确重试；Provider 更新仍只生成候选。
- 连接详情按目标→规则→路径→状态组织，支持明确转到组或预填规则草稿，不直接写规则。
- 常用/最近组、收藏和高级筛选为次级展开，不重新铺满首屏；hover 不自动跳组。

这些大多已有后端能力，本轮是设计入口与状态的提升，尚未实施产品。最终整合范围及原型覆盖边界见 [最终稿说明](design/u09-final-spec.md)，后续实施以该文件和最终原型为主，不再使用初稿作为并行规格。
