# U24：Daymark 配色体系与配置页重组

2026-11-19。依据 `src/ui/style/DesignTokens.qml`、`NavRow.qml`、`SmartViewTile.qml` 审视 Daymark 的**语义色与任务密度**，并对照 Mlash 的 `ShadowrocketStyle`、`ProfileCardDelegate`、`ImportDialog` 和配置页实际截图。继续保留 Mlash 的品牌与代理任务模型，不复制 Daymark 的任务类别色。

## 根因与原则

Mlash 目前在大面积冷灰画布上放置固定 144 DIP 的双列卡片；单配置时卡片占半列且内部留空，更新、菜单、状态散在四角。配置页页首还同时给地址、导入、本地文件和标题栏加号，输入状态与列表状态没有清晰关系。导入选择转入独立工作区，把一个输入任务放大为整页。当前主题虽然有语义 token，但背景、侧栏、控件、选中与卡片边界对比过强，视觉层级被边框而不是内容主次决定。

采用 Daymark 的表面层级：内容表面为中性白/近黑，侧栏为淡灰/深灰，分组底色仅围住真实集合；交互色只标识动作和焦点。明暗、高对比各有独立 token；链接、成功、警告和错误保持语义，不把业务状态染成装饰色。全局颜色只从 `ShadowrocketStyle::Colors` 流出，组件不另写主题常量。保留高对比模式原有可辨识边界。

## 页面与操作链

配置页首屏的焦点是**现有配置及更新**。页首只留单个「添加配置」入口；点击后在列表上方展开有限高度的导入面板，选择订阅链接、配置文件或节点链接，填写可选名称并校验。取消收起面板并返回原卡片位置；失败停留面板显示原因；成功收起并定位新增配置。拖入、从首页或数据空态进入也落到同一面板，不进入独立全屏任务。系统文件仍用文件选择器。已有外部链接的显式安全确认、草稿保护与 Controller 命令保持原有合同。

卡片按 Daymark 的紧凑列表密度重排。单个配置使用单列宽卡，多配置在足够宽时双列；卡片高度按当前内容（标题、来源、更新时间、用量/错误/候选）占位，而非长期留下大片空白。标题/来源左对齐，更新时间和独立更新/更多按钮右对齐；当前标识、候选动作在下部紧邻信息。选中/当前状态使用浅强调填充或细强调线，不用完整高饱和描边。空态在内容附近给一条明确动作，不在底部漂浮说明。低密度场景保留呼吸空间，但不占据与内容无关的卡片高度。

卡片视觉进一步取自 Daymark `SmartViewTile.qml` 与 `TaskRow.qml`：中性分组填充、独立圆形标识、标题和次级信息紧邻、选中只改变浅底，焦点才出现轮廓；悬停不靠永久边框。Mlash 的远程/本地以 globe/folder 标识区分能力，当前使用以细蓝条和文字表达，候选动作留在卡片底部同一行。操作命中区不因图标增加而重叠。

卡片是内容对象，不应随超宽窗口无限横向拉伸。单列和双列的卡片宽度均设上限，并保持左对齐；窄窗仍使用可用宽度。这样名称、来源与更新时间的阅读距离稳定，多出的宽度留给页面呼吸空间。
`QListView::IconMode` 的委托尺寸必须跟网格单元宽度一致，否则 Qt 会把固定宽度的卡片居中放入网格，形成卡片与集合标题错位。焦点边线使用低强度强调色，避免刚导入后的键盘焦点变成持久的高亮外框。
候选更新区沿用中性悬停层，不在普通卡片底部增加大面积警示色；「待应用」用文字表达，查看和应用更新维持独立命中区。错误仍使用错误语义色。

路由与状态：普通配置列表、导入面板、配置内容各自只有一个视觉焦点；打开/关闭面板不改变 `ViewIds::Profiles`。更新中不重复提交；面板未提交输入受草稿保护。鼠标点击、键盘 Enter/Escape、失焦、主题切换及 840 DIP 窄窗不得切到错误页面或丢失输入。旧协议外部导入仍须显式确认，不能无声提交。

## 验收

1. 明暗主题的首页、配置、数据、设置都使用同一套语义色；100% 与 120% 字体、840 和 1040 DIP 下，正文、侧栏、输入和卡片对比可辨，原有高对比断言通过。
2. 单配置卡片不出现固定大面积空白；双列仅在确有多个配置且足够宽时出现。更新、菜单与使用有独立命中区，当前与候选状态可见。
3. 页内导入的订阅、文件、节点链接三路及取消、失败、成功都保持原业务校验。关闭后列表位置不跳；外部导入继续要求确认。
4. 构建、配置相关目标测试、主题和路由回归、便携包完整性与包内冒烟通过。未做的系统代理/TUN、原生鼠标观感和跨机器验证不记为通过。

## 实施后复核

单卡在 1400×720 离屏截图中位于集合标题正下方，实宽受 560 DIP 上限约束；双卡在 900×650 并列，卡片源信息、更新时间和独立操作仍可读。最初宽窗截图暴露 Qt 图标视图将固定 300 DIP 的委托居中于 560 DIP 网格单元，已改为委托宽度跟随网格；导入完成后待布局收缩的截图也要求等到卡片回到标题下方再记录。候选底条改为中性底，焦点描边降低强度。明暗页面和具体测试结果以验证报告为准，离屏截图不能代替原生鼠标/显示器验收。
