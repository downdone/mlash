# U40 Mlash 末级任务设计与验收

每行定义一个可独立操作或复核的末级任务。组合在同一行的值、选项和字段须分别断言。左列编号对应[功能清单](u40-feature-inventory.md)，右列同时给出测试方法和通过判据。常规自动验证在临时目录使用合成夹具和注入的观测状态，原生补焦点、窗口、文本、屏边和输入。涉及系统特权的真实操作遵循[发布验收](../release-readiness.md)。

读操作与打开窗口默认零业务写入。即时偏好由 Controller 保存并回显失败。草稿组默认只修改当前会话，显式提交后回读，取消零写入。全局忙碌只锁住不适用的写动作，过期异步结果按对象、版本和请求代次丢弃。列表项目失效时回到所属列表和第一个可用操作。

## 连接

| 末级任务 | 入口、控件与结果 | 逐项验证 |
|---|---|---|
| F01.1 看运行状态 | 接管行固定显示代理，次级列显示内核、当前配置及系统代理/TUN 实际状态。未知、外部管理和故障提供说明 | 注入内核五态、代理四态和 TUN 两种确认状态。比较页面、顶栏和托盘文案的事实与时序 |
| F01.2 开启代理 | 代理行开关。无配置指向导入，已有未用配置指向选择。已用配置显示进行中，回读后更新 | 模拟延迟、重复点击、启动失败与无可用方式。核每次显式动作最多一笔命令和真实开关值 |
| F01.3 关闭代理 | 同一开关，关闭后回读接管状态，依原规则处理失败或所有权变化 | 模拟恢复失败及外部抢占，确认保留真实值、告警和下一步 |
| F01.4 外部冲突处理 | 从接管状态的解释进入显式确认，说明接管/恢复后果 | 分别取消、确认、确认前所有权变化，核写入计数和最终归属 |
| F02.1 路由模式 | 行尾菜单并列规则、全局和直连，勾选当前观测值。写失败说明并恢复原勾选 | 逐项 PATCH/GET 或替身回读，覆盖超时、失败和 Esc 关闭 |
| F03.1 找组与子组 | 组选择器和可返回的子组路径。均保持当前运行成员 | 用嵌套组打开/返回，确认无选路写入且恢复滚动 |
| F03.2 手动选成员 | 手动组单击行或 Enter 执行。方向键只移动焦点，当前成员有独立标志 | 对同一成员、切换失败及自动组执行点击/键盘，核一次真实命令或零命令 |
| F03.3 自动恢复 | 自动组显示当前选路和固定选择，符合条件时提供「恢复自动」 | 模拟清除并回读 fixed，失败保留原观测与处理入口 |
| F03.4 选择恢复 | 启用记忆时以回读验证规则恢复选择，成员消失时提示默认项 | 重启/回滚夹具覆盖有记忆、禁用、成员移除三种组合 |
| F04.1 搜索节点 | 工具带文本搜索，清除后恢复列表，不改变当前成员 | 合成中英长名称与空结果，验证只影响过滤 |
| F04.2 筛选节点 | 锚定面板提供地区、协议、状态、延迟范围、收藏及重置，地区标注为推断 | 分别启用各筛选并组合。确认结果与两种视图一致，Esc 后焦点回到触发处 |
| F04.3 排序和视图 | 默认、名称、延迟排序与表格/卡片切换。工具槽固定，当前对象与选择分开 | 排序后比对成员 ID、焦点和区域坐标，关闭重开验证保存的显示偏好 |
| F04.4 定位与近期 | 定位当前成员，独立查看最近项与收藏。定位动作只滚动与聚焦 | 在筛选隐藏目标时提示处理，定位后运行成员保持原值 |
| F04.5 节点详情 | 行尾或键盘打开就近只读详情，提供收藏/取消收藏 | 鼠标与键盘打开同成员，收藏保存失败回读。关闭返回原行 |
| F05.1 单节点测速 | 延迟区域、详情按钮和 F5 共用明确对象。显示等待、超时、过期和结果 | 按下后排序再释放，确认不会测错对象或选路。过期结果不会写回 |
| F05.2 当前组测速 | 工具带主动作显示进度和停止，保留浏览与允许的成员切换 | 重复点击、取消、切配置/代次恢复。确认已取消结果不覆盖新组 |
| F05.3 组测试参数 | 组设置编辑测试地址和常用标记。错误贴近字段 | 测有效/无效地址、地址变化引发的旧测速失效、保存失败和取消 |
| F05.4 当前节点探测 | 组设置选择关闭、60 秒或 5 分钟，标明目标叶子或不可解析原因 | 用受控时钟逐项测开、换路线、离页、隐藏和停测，无后台多余请求 |
| F05.5 测速所选成员 | 节点动作菜单显示所选集及「测速所选」，与 F5 的适用范围一致 | 单选和多选分别核对发送的成员 ID、取消与排序后的结果归属 |
| F06.1 切换后的连接清理偏好 | 策略组设置中独立开关，说明关联组范围 | 分别覆盖关闭、开启和设置失败。默认切换零断开 |
| F06.2 连接清理结果 | 节点切换反馈分别报告选路与关联连接清理结果 | 注入部分失败、超量、期间新连接与无关组，请求不作用于其他对象 |

## 配置

| 末级任务 | 入口、控件与结果 | 逐项验证 |
|---|---|---|
| F07.1 订阅 URL | 持久标签输入、遮挡、校验反馈。高级窗可显式显示地址 | Mock HTTP 成功、超时、坏 YAML，失败保留输入且日志无令牌 |
| F07.2 本地 YAML | 选文件和拖放预填，确认后导入快照 | 检查预填零导入命令、坏文件保留、来源删除后快照仍可使用 |
| F07.3 节点链接 | 高级导入第三类入口，先离线预览、去重，再提交 | 输入重复、坏链接和混合样本，检查预览零联网、未确认零写入 |
| F07.4 外部和剪贴板输入 | 从外部唤起或待处理来源恢复到确认界面，标明来源，取消回原位置 | 覆盖启动、忙碌延后、拒绝、确认，核无无意下载或激活 |

| F07.6 退出导入 | 统一取消、Esc、关闭和 Alt+F4 的草稿规则。已提交时说明关闭后任务是否继续 | 原生逐个覆盖继续编辑、放弃及提交中关闭，核对象归属、焦点和提交次数 |
| F08.1 浏览及使用 | 卡片/列表选中只定对象，打开查看。独立「使用」动作提交 | 对两个配置分别打开、键盘与鼠标使用，核状态回读、失败恢复及无意接管计数 |
| F08.2 重命名 | 配置详情可改名称，保留来源和版本身份 | 试空名、长名、取消，成功后配置 ID/版本保持 |
| F08.3 集合排序 | 列表工具可上移/下移，移动后保持对象焦点 | 两卡交换、首尾禁用、重开顺序和焦点 |
| F08.4 多选 | Ctrl/Shift 或明确多选入口，操作带说明适用范围 | 覆盖单选、多选、键盘切换，确认单对象使用及删除不会误作用集合 |
| F08.5 删除 | 对象菜单的危险动作，确认显示配置名和当前运行影响 | 分别删除非活动、活动，测试取消、停止失败、成功后列表焦点 |
| F08.6 分享/二维码 | 对象菜单「分享配置」，私人内容默认遮挡，显式显示本地生成二维码 | 校验点击前无二维码、过长源有提示、关闭清除当前呈现、网络请求为零 |
| F09.1 更新 URL | 来源区主动作，更新结果落到候选，独立显示用量/到期和错误 | 模拟成功、相同字节、过期/缺失元数据、网络失败。运行和良好版本保持原值 |
| F09.2 同步/更换本地文件 | 来源区区分同步现有路径和选择新源。更换先校验再保存 | 重复同步、文件删除、更换失败和成功，检查旧路径及活动版本 |
| F09.3 自动更新与监测 | 源类型决定 URL 定时或本地监测。查看上次结果、调度和退避 | 用受控时钟分别测关闭、触发、失败退避、退出与候选独立性 |
| F09.4 更新下载策略 | 来源设置改变方式、UA 和超时，字段关联提示继承情况 | 每字段独立输入有效/无效值，取消和保存失败保留版本，成功后下一次请求使用新值 |
| F09.5 批量更新 | 列表执行选中或全部更新，显示逐项状态和取消后续 | 三配置注入先成功后失败、取消时当前项收敛。核未开始项和活动版本 |
| F10.1 版本身份 | 对象头显示当前使用和有更新两个独立维度，记录上次良好入口 | 同一活动对象存在候选且最后更新失败时，验证三类状态可分别读出 |
| F10.2 查看差异 | 对比页固定两版本和比较摘要，浏览零写入 | 打开后换候选再确认，旧上下文应失效，重开才可对新候选应用 |
| F10.3 应用更新 | 明确动作和可能中断的说明，提交后显示校验、回读或恢复结果 | 实例启动、回读及索引失败分别注入，旧运行版可用或明确提示失败 |
| F10.4 重新加载 | 对象版本区「重新加载当前运行」，显示实际目标 | 同时存在待应用候选时触发，检查候选保持与运行版身份 |
| F10.5 回滚 | 版本区显示「上次良好版本」及确认，处理无法回滚原因 | 取消零提交，回滚后回读，缺少目标或失败仍显示实际运行身份 |
| F11.1 新增和覆盖节点 | 节点编辑器按协议提供字段，高级文本使用同一草稿 | 分别新增、覆盖，验证原始来源、未涉及字段与候选隔离 |
| F11.2 策略组和成员 | 组编辑器编辑类型、成员及引用，组选择保留原对象 | 分别新建、编辑与改成员，循环/缺引用失败保留整个草稿 |
| F11.3 移除和引用分析 | 当前对象选择移除，显示受影响的组/规则/上游及处理动作 | 检查预览零写入，引用变化后旧分析失效，最终校验失败可修正 |
| F11.4 导入节点到现有配置 | 节点编辑页执行链接预览，将合格项写入同一草稿 | 去重、取消和保存失败均保留草稿，活动/候选按事务更新 |
| F12.1 浏览来源规则 | 规则工作区只读显示来源、版本及规则集引用 | 分别打开来源、候选和运行规则入口，标题和内容对应对象 |
| F12.2 前置、追加与屏蔽 | 列表中明确分区，新增、排序、移除和勾选屏蔽按当前草稿执行 | 分别验证分区顺序、原规则保留、取消和保存后回读 |
| F12.3 规则文本与结构表单 | 单一草稿相互切换，错误定位字段、行号或单元格 | 输入非法规则，切换呈现保留内容，保存成功才提交 |

| F13.2 DNS 字段与 YAML | 常用字段和高级文本共享草稿，显示不可表单化的字段 | 校验复杂字段保留、非法 YAML 定位、旧草稿冲突与取消 |
| F14.1 拨号上游 | 选节点，查看当前上游，选择节点/组或清除，显示继承值 | 测继承、指定、清除、循环、动态来源禁用、回读和取消 |
| F15.1 Provider 快照 | 版本选择明确「待应用/当前运行」，列出名称、类型、时间及错误 | 对照版本冻结的元数据，失败保留可用快照与说明 |
| F15.2 Provider 刷新 | 行、同类型和全量三个作用域，操作前可读，进度归对应对象 | 三种作用域逐项断言重取范围，部分失败不会发布破损候选 |
| F15.3 Provider 下载及计划策略 | 对象设置支持继承/覆盖、显式启用周期，来源缺失时可清除旧策略 | 确认继承、覆盖、退避及旧策略清除，运行版本保持 |
| F16.1 兼容性 | 配置页显示受控字段、拒绝能力、校验状态及对应提示 | 用受支持、拒绝、无来源和过期请求夹具，核结果对象与脱敏 |
| F16.2 运行配置预览 | 配置对象提供脱敏的当前运行预览，未运行时说明不可用 | 预览含合成凭据的样本，检查脱敏、离页失效和只读 |
