# U28：按任务优先原则逐页实施与复核

2026-11-19。承接 [U27](u27-shadowrocket-mobile-lessons.md) 与用户要求“少操心，东西找得到”。先逐页追踪现有真实入口、主动作、次动作、返回和异常，再修改剩余缺口。桌面布局继续使用侧栏与紧凑行；不引入手机顶栏或底部导航。

| 页面 | 主任务与现有链路 | 本轮处理及可观察验收 |
|---|---|---|
| 首页 | 连接、路由、测试三行等高；下面是组与节点列表。无配置可就地导入。内核由代理开关自动准备 | 路由菜单给每种模式一句结果，当前项勾选；离开页面关闭菜单；键鼠可选择。失败继续在控制区提示下一步 |
| 节点 | 行主体选择或展开，延迟区域重测，行尾详情；搜索/组/更多在标题行，返回保留书签 | 行列表详情图标常显；可选卡片视图补同样独立详情入口，不依赖悬停才能发现；不改行高、主动作与测试区域；视觉复核窄窗及明暗主题 |
| 配置 | 统一卡片网格，卡片主体使用，刷新/菜单/候选各自命中；导入紧贴列表并就近展开 | 非当前配置明确标注主体动作；更新失败文案说明旧版保留、可重试；保留来源文件名、当前与候选标签、卡片尺寸和滚动位置 |
| 配置内容与新增 | 配置菜单进入节点、规则、DNS 等对象任务；新增为三来源内联表单，校验后提交 | 核对必填在前、高级下载设置按需、取消及返回保稿；已有链路无结构变更 |
| 数据 | 流量/连接/测试/日志固定页签；对象结果与详情就近；连接筛选与位置可恢复 | 复核四入口、空态和详情返回；已有链路无结构变更 |
| 设置 | 分组目录、行尾当前值、常驻搜索；选择结果才进入任务，未提交草稿阻止误跳 | 复核搜索前后同一目录、任务返回和脏草稿；已有链路无结构变更 |

改动仅涉及展示和动作提示，不新增 Controller 写入。验收按入口→选择/取消→离开返回→再次进入；配置卡片还检查鼠标命中区与键盘路径，节点确认详情图标、延迟命中区和主体选择互不抢占。对无配置、未就绪、更新失败、待应用候选分别复核。自动测试应覆盖路由菜单文本及动作身份、节点详情可见和配置卡片状态。真实内核、原生读屏与 DPI 人工验收需按实际结果单列。

## 实施后逐页复核

- 首页：保持三行同高和节点列表连续布局。路由菜单补全规则、全局、直连的实际流量结果，选中勾与动作属性保持一一对应。截图核对菜单未变成额外页面，短文本在窄窗内仍可读。
- 节点：行列表和可选卡片视图都常显独立详情图标。卡片详情、延迟重测、卡片主体使用分成三个互不重叠的命中区；详情不切节点，延迟重测不切节点；补 `Ctrl+I` 与详情悬停提示。截图复核未增加行高或卡片高度。
- 配置：列表仍是主视图，导入仍就近展开。非当前卡片底部给出主体动作，更新失败给出刷新重试动作；错误原文保留于详情提示，不把技术错误堆进卡片。候选仍在卡片内查看和应用，当前配置仍以蓝色侧线和底色区分。
- 配置内容与新增、数据、设置：逐条对照本页上表，现有就近工作区、内联表单、数据页签及设置常驻搜索符合任务路径；本轮不改页面结构，避免把已收敛的任务重新拆层。原生读屏与实际系统主题仍需单独人工验收。

截图采集与全量回归分开运行：`currentGroupSelectionAndNativePreview` 在采集整套截图时会超过常规 30 秒测试时限；关闭截图变量后用例约 17 秒通过。测试时限维持 30 秒，截图只在定向用例中生成，避免以加长超时掩盖测试输入差异。
