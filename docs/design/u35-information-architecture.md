# Mlash 多层内容大纲

2026-11-20 · 设计提案。对照现有原生页面、设置入口和用户提供的 Shadowrocket 截图。此文定义下一轮结构评审范围。

## 一级入口与下钻

| 一级 | 用户主要来做什么 | 进入对象后看到什么 |
|---|---|---|
| 首页 | 开关连接、切换路由、选择节点、测当前组 | 首页直接展示连接状态、路由值、节点与组。策略组展开仍在列表中；进入子策略组更换列表对象，提供返回上一级组。节点详情、组设置紧贴操作对象；路由模式用右侧值下的菜单。 |
| 配置 | 添加、查看、更新或切换配置 | 配置卡保留名称、来源、状态和就近操作。进入配置后以配置名为标题，同一层用页签切换节点与策略组、规则、DNS、拨号链、规则源与节点源、兼容性。来源与更新、更新差异从卡片打开各自的任务视图。 |
| 数据 | 观察流量、查活动连接、网站测速、查日志 | 流量／连接／测试／日志平切。连接详情、测试目标详情随所选对象打开，回到原列表时恢复筛选、节点与滚动位置。出口及服务诊断拥有自己的结果视图。 |
| 设置 | 调整应用偏好、管理运行环境、备份与恢复 | 目录和任务最多两级。搜索只在目录出现，可直达所属任务。常用选项就地修改，复杂能力进入有独立标题和返回键的工作区。 |

## 设置目录提案

| 分组 | 目录就地操作 | 二级工作区 |
|---|---|---|
| 外观 | 主题、文字大小、窗口标题栏 | — |
| 启动与托盘 | 登录启动、轻量关闭；登录启动异常贴着该项展示 | 启动与托盘，管理启动页面、启动时行为、托盘单击。快捷键从目录直达编辑 |
| 连接与网络 | 本地代理行显示端口，TUN 行显示实际状态 | 本地代理、TUN 虚拟网卡、系统代理排除。配置专属 DNS 直达当前配置的 DNS |
| 维护与数据 | 查看实际版本、打开目录、复制地址等单步操作 | 内核管理、备份与恢复、Geo 数据。Mlash 更新从「关于 Mlash」就近进入 |
| 关于 Mlash | 显示应用版本 | 关于页承载应用、Qt 与内核身份等技术信息 |

备份与恢复使用「创建／恢复／自动备份／WebDAV」四个同级页签。创建只显示文件、密码与范围；恢复才展示预览、选择和确认。内核管理页列出当前内核、参数和更新入口；更新向导沿用同一个工作区，回到原行。现有「文件与其他工具」要拆开评估，本地代理地址、环境变量归本地代理，数据与日志目录归维护，链接导入归通用，运行配置归配置或内核管理并保留一处实际入口。

## 什么时候用哪种界面

| 形式 | 适用 | Mlash 实例 |
|---|---|---|
| 行内控件 | 值少、可立即理解和回读 | 外观、字号、开关 |
| 锚定菜单 | 短选项或对象的少量操作，打开后仍能辨认触发处 | 路由模式、配置卡更多操作 |
| 二级工作区 | 有多个字段、草稿、长结果，或需要反复对照 | 配置编辑、备份、TUN、内核 |
| 页签 | 同一对象或任务族内的同级内容，切换后仍在原上下文 | 备份四项、数据四项、配置内容 |
| 弹窗 | 单次选择、确认、短而独立的编辑 | 选文件、覆盖确认、快捷键编辑候选 |

默认让设置留在左侧导航和右侧内容的同一壳层。若验证显示整页设置频繁遮断原任务，可单独比较独立偏好窗口，但窗口内部仍沿用同一份目录，不维护两份入口。移动参考的分组、可见状态和就近操作沿用到桌面，主窗口继续使用侧栏。

## 落地顺序与验收

本轮先落实设置归属。链接导入放在「启动与托盘」所在的通用分组，复制代理地址与环境变量放在「本地代理」，当前运行配置和内核目录放在「内核管理」。数据和日志目录共用「文件目录」，Geo 管理沿用维护区的直达入口。备份搜索直接打开对应页签。提交和取消在窄窗固定可见，表单正文单独滚动。首页、配置、数据沿用上表中的一级分区，本轮统一导航外观和原操作路径。

| 操作路径 | 保存、切页和返回 |
|---|---|
| 首页无配置 → 导入 → 配置卡 → 使用 → 首页开启代理 | 导入成功才出现配置卡；浏览卡片和查看候选只读，用「使用」或「应用更新」发起写入。取消导入回到原入口。 |
| 设置 → 本地代理 → 修改 → 保存或返回 | 搜索可直达字段。显式保存后回读，失败留在任务；切一级页保留草稿，返回目录前有未保存输入时确认。 |
| 设置 → 备份与恢复 → 创建或恢复 | 文件选择返回同一页签。恢复先校验预览，再选恢复范围；取消保留原数据。页签切换保留草稿，返回设置目录后仍可重新进入任务。 |

1. 定层级与归属。每项能力有一个实际入口，搜索和状态提示可将用户带到该入口。先确认「文件与工具」各项的归属和「更新」从哪里进入。
2. 画三条操作路径。首次导入到连接、改设置到返回、备份到恢复预览。对照它们从哪里进入、在哪保存、取消后回哪里。
3. 逐分区调整。设置先做目录和备份，配置统一对象标题和页签，数据复查列表与详情的返回位置。
4. 使用原生窗口复核。检查 840 DIP、120% 字号、浅深色、键盘和鼠标；从搜索直达、返回原处、草稿跨页保留；检查页签无溢出、窄窗仍可提交或取消。
