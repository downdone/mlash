# Mlash 视觉识别系统

Mlash 是一款桌面代理与网络诊断工具。界面应该让用户快速看清所在节点、当前网络状态，以及下一步能做什么。炭黑路径标志建立品牌识别，清亮蓝标出主操作和当前项，中性色背景为内容留出层次。

## 标志与组合

新图形是一条折成 **M** 的路由轨迹，右端的圆点是连接端点。标准组合由实心品牌色图标和 Mlash 字标组成。字标以 Noto Sans SC 700 转曲，正式写法为 **Mlash**。发布物料可使用独立图标与大字标；单色场景使用轨迹图形，深色底使用反白组合。

- 应用图标采用 64 × 64 单位网格和 16 单位圆角。图标建议应用尺寸 24 DIP 起，任务栏可用 16 DIP，验收时逐级检查端点与主线是否能分辨。
- 标志四周外留至少图标宽度的四分之一。标准组合已固定字距和间隔，整体等比缩放。较窄的触点优先只用图标。
- 原生品牌触点和托盘规则按下表实施。
- 辅助图形取自标志的折线和末端圆点。浅色封面使用 `#EAF5FF` 冰蓝底、`#83BFFF` 轨迹与标准组合。深色封面使用 `#132A43` 海军蓝底、`#398FF0` 轨迹与反白组合。产品工作区使用留白与分隔线组织内容。

## 色彩

品牌色由**炭黑 `#202020` 和清亮蓝**组成。参考 Daymark 的克制分工，标志与字标以中性色建立识别，清亮蓝用于操作。应用图标采用炭黑底、白色轨迹和灰色细边，深浅主题共用同一标志，字标按主题切换炭黑或白色。发布封面浅色用冰蓝底和深色字，深色用低明度海军蓝和亮字。参考 Apple 的颜色角色与明暗外观方法，界面状态使用独立颜色及文字或位置提示。 [Apple 色彩指南](https://developer.apple.com/design/human-interface-guidelines/color) · [Apple 深色模式](https://developer.apple.com/design/human-interface-guidelines/dark-mode)

应用配色采用 Daymark 的浅深色语义值。增强对比的交互边框使用参考色板的 outline，分隔和禁用角色各自保留。实际色值见[原生界面 token](../../src/ui/design/ShadowrocketStyle.h)。软件图标、发布封面和网站服务图标保留各自的资产色。 [实施设计](u40-visual-interaction-design.md#daymark-配色导航与测速卡)

同一表面上字体最低对比目标 4.5:1。主操作底、开关轨道及键盘焦点和邻接表面按至少 3:1 验收。浅色开关使用白色滑块，深色开关使用深色滑块。

## 字体与排版

应用内中英文统一用内置 Noto Sans SC，回退到平台系统字体。YAML、原始日志和结构化技术文本区使用系统等宽字体。界面正文、状态和数字使用同一基线；延迟、时间、流量按数值栏右对齐。

| 字阶 | 100% 字号／字重 | 应用 |
|---|---|---|
| 辅助 | 9 pt／400 | 来源、时间、协议和计数 |
| 正文 | 10.5 pt／400 | 表单、菜单、页签和节点；选中项和主按钮 600 |
| 区块 | 11.5 pt／600 | 配置卡名、表单分组和小标题 |
| 页面 | 13 pt／600 | 页面、任务工作区和对话框标题 |
| 数据 | 15 pt／600 | 关键数值，单位沿用正文 |
| 品牌 | 16 pt／700 | 桌面侧栏，宣传封面按比例放大 |

缩放以 100% 为基准，120% 按实际字体指标扩大行高；重要错误说明用正文字级。长对象名可以省略，并在工具提示或详情中提供全名。内容间距使用 4、8、12、16、24、32 DIP；卡片圆角 12 DIP，按钮圆角 8 DIP；胶囊用于开关。

## 交互状态与颜色角色

| 状态 | 规则 | 落点 |
|---|---|---|
| 默认 | 内容文字用正文色，说明用次字色，普通控件用中性底或透明底。 | 导航、节点、表单、菜单、可点击卡片 |
| 悬停 | 使用共享浅填充 Hover，保持边界与布局稳定；已选中项悬停沿用选中底。 | 左栏、工具、配置卡、节点、表格、页签、下拉项 |
| 按下 | 使用较深 Pressed；主按钮按下使用同系深／亮蓝，字色与按下底至少 4.5:1。 | 常用按钮和主动作 |
| 选中 | 一级导航使用主题蓝及同系浅底；页签与编辑列表用中性底、正文色和单一状态标记，下拉当前值用勾标。 | 导航、页签、列表、下拉、编辑器 |
| 键盘焦点 | 独立蓝色描边。满色主按钮沿用对比充分的前景色画内边界。鼠标选中保留选中填充。焦点与当前项可以同时出现。 | 左栏、设置、页签、表单、列表、卡片、胶囊 |
| 当前生效 | 用状态文本、勾标或左侧短线表达。键盘选择、鼠标悬停和当前运行版本可以同时读取。 | 节点和配置卡 |
| 禁用 / 加载 / 错误 | 禁用用弱化前景；加载保留控件区域与可读状态；失败用红及可行动的文案；成功／警告用绿／橙。 | 所有任务与数据页 |

标准 Widgets 从 UiTheme 使用应用字体，数据表和自绘委托与之共享字阶。原始 YAML 与日志例外。9 pt 用在次级数字和说明，正文 10.5 pt 用在主名称和操作，11.5 pt 用在卡片标题和分组，13 pt 用在主页面和任务抬头，15 pt 用在关键指标，16 pt 仅用于品牌字标。90／100／110／120% 从里到外使用同一比例，字标使用固定 700 字重。简化图标 16／20 DIP，左栏导航 18 DIP，开关轨道 46×26 DIP。品牌图标的留白及视觉尺寸独立于文本字体。

验收由主窗口、关于、应用图标、托盘、配置卡、数据页、设置、菜单、输入和键盘路径组成。浅／深及增强对比下检查各语义色；在 840／1440 DIP 和 100／120% 字号核对中文、英文字标、长节点名及右对齐的时间。抽查鼠标点击和键盘切换后选中与焦点，验证全部托盘资产复用炭黑母版。保存、取消、候选、空态、错误和重新打开继续沿用各页面的原业务语义。

## 页面应用规则

侧栏首页、配置、数据采用单列图文行，设置固定在侧栏底部。路由选中与键盘焦点独立。验收核对浅深主题、100% 与 120% 字号，以及折叠、展开和点击设置后的当前页面。

| 场景 | 视觉规则 |
|---|---|
| 首页 | 当前节点、开关、路由、整组测速各有稳定位置。状态应可读，订阅更新靠近节点工具栏。 |
| 配置 | 单卡占一列，多卡等宽双列。列表上方常驻快速导入行，高级新增在独立窗口；当前与候选使用不同的状态词。 |
| 数据 | 流量和延迟用数据字阶。连接、日志用连续行；等待、成功、失败和未测试有可读文字。 |
| 设置与控件 | 标签及当前值对齐，一行承载一个主要动作。表单、菜单、按钮和提示采用共享字阶；键盘焦点独立描边。 |
| 发布与文档 | 左上组合标志，中性近白底和一个主要任务画面。版本、平台、构建类型放进辅助信息行。浅底使用标准组合，海军蓝封面使用反白组合。 |

样板展示标志、应用图标、字阶、色板、交互状态、四个主页面和发布封面。Qt Widgets 的验证结果以[验证报告](../verification-report.md)为准。样板使用示例数据。

## 卡片、页签和设置层级

### 独立配置卡

U38 将卡内分为标题、来源与更新时间、状态与操作三行。内边距横向 16 DIP、纵向 14 DIP，状态和操作使用独立的底行。选中及悬停通过边框区分，卡底使用语义面色。查看为次要动作，应用更新和使用采用主题色，待应用和错误色留给状态。验收覆盖原生浅深样片、840 DIP 双列与 120% 长标题，核对选中边框、内边距、按钮间距及返回操作。

配置列表继续负责双列、选中、滚动和排序；每个格子使用独立 Qt Widget。标题行含类型图标、刷新和更多，元数据行左对齐来源与时间，底行左侧是当前状态与用量，右侧是查看、应用或使用。布局压缩时名称和来源先省略，操作与时间保持独立。用真实按钮提供悬停、键盘焦点、禁用和提示；卡身仍打开配置，修饰键仍用于多选。操作依据稳定配置 ID，保存和应用仍由 Controller 发起。验收覆盖双列、长名称、窄窗口 120% 字号、鼠标与键盘按钮、刷新和候选入口、返回滚动及排序后的对象关联。

设置目录按 iOS 的分组与行尾值组织，搜索作为右侧紧凑工具，保留 Ctrl+F 与结果直达。外观、字号和标题栏的选择菜单统一锚定关联行的右端，打开后核对右边缘并处理屏幕边界。

- 配置卡复用网站测试卡的容器、圆角方形图标底、名称与来源上下排列、右上工具和底部状态／动作。配置保留等宽双列；卡片状态用短文案，待应用和失败用对应语义色。取消蓝色边条和卡内横线。
- 数据、配置详情、备份及节点切换统一使用中性页签轨道，当前项用卡片色及加重正文区分。列表选中用中性填充和短标记，键盘焦点沿用蓝色描边。主操作沿用主题蓝。
- 子页用左向箭头和一个稳定对象标题。配置内容用配置名，备份用“备份与恢复”；具体任务由页签命名。设置的搜索留在目录。备份表单在抬头下方紧凑排列，面板最大宽 640 DIP，字段和帮助可滚动。
- 验收覆盖路由菜单右侧锚定、两列配置卡与独立动作、页签和布局在浅深色／窄窗口下正常、设置仅一处导航选中、工具子页无登录启动警告、备份输入与返回路径可用。
