## 原则复核与实施前设计

首页主要任务是查看实际代理并选择节点；配置浏览不能隐式应用。顶栏只保留居中标题与少量工具，运行状态统一由首页和固定状态栏承载，避免重复胶囊。侧栏保留品牌及四分区，取消装饰性产品副标。

紧凑尺寸以 DIP 定义：侧栏 188，顶栏 52，内容边距 16，侧栏项 40，节点行 52，配置行 60，设置行 48，详情宽 350。字体不随密度缩小；行高至少容纳当前字体的两行指标，支持文字缩放。默认窗口 1000×700，保留已保存尺寸和原生 Windows 窗口按钮。

本切片：统一外壳，简化控制区，节点真实国旗与内缩分隔线，修复当前勾与延迟重叠，将定位当前提升到标题行，订阅下拉仅浏览；选择非运行订阅后显式“使用此配置”。数据与设置沿用已实现命令及路由，后续继续按最终稿收敛编辑层级。

验收：构建通过；相关 UI 交互、路由和布局测试；截图复核。空态、窄窗及主题不依赖实际代理写入。不得将自动测试称为真实系统代理或正式发行验收。
