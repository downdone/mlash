# U15：界面精细度根因与施工设计

状态：事前设计已实施，定向自动复核与原生样片通过；人工读屏和正式发行资格未验。延续 U14 的内容优先、单一动作、渐进展开和真实状态原则；无业务或持久化协议变更。

## 根因与取舍

1. 设置目录 `ActionRow` 在圆角路径上叠加方角矩形，`QPainterPath` 默认奇偶填充令重叠区域消失；首行底部、普通行上下各约 10 DIP 的悬停背景因此缺口，150% DPI 下约为 15 像素。QSS 又对同一行绘制 hover，形成两条绘制路径。改为单一自绘、并集填充；首尾角只在组边界圆，内部行全高覆盖。鼠标 hover 不冒充键盘焦点。
2. 首页工具栏前端导入与后端加号都进入添加配置流程。只保留右端加号，明确“添加配置”；配置页的文件与 URL 入口仍按来源分流。顶栏保留等宽左右槽，标题不偏移。
3. 配置详情同时有七个任务页签和内容目录行；页签切换进入 `TaskWorkspace`，返回“概览”却重新构造详情滚动页，`selectProfile` 还主动 `scrollTo`，所以位置跳跃。详情只保留目录行，任务工作区保留同级页签；返回已有详情实例，列表滚动不被无数据变化的返回动作改写。不同配置才新建详情；离开再回来有明确的配置列表入口。
4. 外部程序管理代理时，“需明确允许接管”是操作保护结果，不是永久故障。首页控制区已经显示外部管理并提供显式接管确认。状态栏仅在该观测态且错误确为接管确认语句时不显示持续告警/泛化“处理”；真实恢复失败、只读保护和其他错误继续保留原告警。设置中的本地代理任务仍可查看配置。
5. `NodeRowView::resizeEvent` 把圆角转为整数 `QRegion` 并给 viewport 设置二值蒙版，圆弧边缘没有半透明像素，150% DPI 下出现阶梯。移除这一层硬蒙版；原生首轮截图显示白色节点区首尾成为直角，因此在 viewport 绘制完成后以抗锯齿圆角外域覆盖背景色，视觉轮廓仍为 10 DIP 圆角，行内容不被二值裁切。截图文字存在彩色子像素，说明字体抗锯齿正在运行；150% DPI 与截图缩放仍可能放大边缘，不盲目换字体或全局关闭子像素。

## 验收

- 第一行、普通行、末行在 100%/150% DPI 悬停时背景覆盖至分隔线，没有横向白缝；圆角仅出现在组边界；键盘焦点仍有独立可见环。
- 首页/配置顶栏仅一个添加入口，标题水平居中，URL/文件导入仍可到达。
- 配置详情进入规则或 DNS 后切回概览，详情对象与滚动值保持；返回配置列表沿用进入详情前的位置；任务草稿和失败状态不因导航被丢弃。
- 外部代理确认提示不持续占用状态栏；其他 `lastError` 与只读告警仍显示。没有系统代理写入测试。
- 原生窗口截图在实际 DPI 下复核行形状与列表边界；运行 UI 定向回归及可用构建，结果写入验证报告。人工读屏/正式发行仍按原门禁。

## 实施后对照

保留左右等宽标题槽，删除左侧重复导入图标；配置详情删去重复任务页签，任务工作区返回复用既有详情。设置行只由控件自绘 hover/分隔/焦点，路径改并集填充。节点列表取消整数蒙版，在 viewport 绘制完成后以抗锯齿外域覆盖圆角背景。外部接管确认提示仅从持续状态栏过滤，其他错误及只读告警保持。

原生样片在实际 150% DPI、1040×720 DIP 窗口下为 1560×1080 像素；节点区圆角边缘可见背景/表面之间的过渡像素，首尾不再为直角。设置行悬停全高像素断言及配置返回/外部状态语义断言通过。完整自动化与环境限制以验证报告为准。
