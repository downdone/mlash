# U40 深层页面与末级控件设计

五个一级入口及其字号、配色与间距沿用[视觉规范](u40-visual-interaction-design.md)。本设计规定深入对象后如何展示版本、原因、草稿、结果和返回路径，补足 144 条[末级任务](u40-leaf-design.md)的组件归属。下面的样板场景使用合成数据，实际指令和前置条件以 Controller 及[功能契约](../development/feature-contracts.md)为准。

七场景样板用于验证操作状态。实施以原生对象工作区、列表密度和操作槽为基线，具体处置见[当前 Widgets 实现复审](u40-visual-interaction-design.md#当前-widgets-实现复审)。

## VI 在深层页面的用法

- 炭黑 M 标志只出现在应用外壳和关于页。进入配置、连接或归档后，正文标题显示该对象的真实名字，把视觉重心交给正在处理的对象。
- 对象标题、状态、版本、来源时间占同一固定内容轴。标签用 12/18 DIP，正文用 14/22 DIP，任务标题用 24/32 DIP。长名称自然折行，版本 ID、单位和下拉值保持完整可读。域名、YAML 和哈希在正文按需使用等宽字。
- 运行中的对象用对勾与「当前运行」标识。待应用用文字及橙色标记。失效用橙色提示和「重新读取」。具体失败用红色文字并贴在对应字段或表行，可修正时紧接下一步。临时多选用浅蓝行底和复选框，选择状态与运行状态可同时出现。
- 状态区分使用四套已验色对。技术表以细分隔线和数字对齐保持密度。编辑器把分组作为一个连续表面，仅版本对比需要两块并列内容。危险动作在确认中使用红色文字，主色蓝留给操作与焦点。
- 默认图标使用 20 DIP 功能图形配 32 DIP 命中区。选中、成功、警告、失败和未知分别以勾、圆点、三角、感叹号、问号辅助文字。设置目录保留可读状态和进入箭头，表行末尾留给动作，长表单的强调集中在当前字段和主要提交按钮。

## 深层界面构件

| 构件 | 默认结构和复用规则 |
|---|---|
| 对象工作区 | 顶部返回、对象名、当前版本；中部任务栏目和内容；末尾留错误、主要动作与取消。840 DIP 时逐级下钻，宽窗可并排任务目录和内容。栏目切换复用对象和同一草稿 |
| 密集表与快照 | 标题、已应用过滤及采样时间置于表外，行主题与动作分栏。快照固定对象 ID 和时间，宽窗侧开，窄窗替换正文；读写动作分别检查观察与最新状态 |
| 可编辑分组 | 标签固定，字段和帮助按语义分组。即时偏好回读后显示新值；运行相关参数在显式提交后回读。行内非法值不抢走其他草稿，错误反馈恢复焦点 |
| 结构编辑与文本 | 同一草稿有行编辑和文本两个视图。切换先校验并根据可表示范围呈现；有错误时留在可修正视图。屏蔽、前置和追加明确其归属与顺序 |
| 选项与上下文动作 | 行尾显示现值，短选择用锚定选单。集合操作显示数量和作用范围，单行详情与选用分开。托盘跳转继承目标路由与对象身份 |
| 两状态对照 | 左右或上下展示现状和目标，显示对象、来源版本与生成时间。比较 ID 失效时保留证据并替换主动作为「重新比较」 |
| 阶段任务 | 按「准备 → 预览或校验 → 确认 → 结果」展示。每阶段仅有一个主动作，返回保留已验证的输入。先履行真实前置条件，再允许提交 |
| 保护与回位 | 短确认只说明对象和后果，默认焦点到取消。关闭、Esc、返回或切页统一检查适用的草稿。恢复到原控件、行或筛选，失效后回到提示或下一可操作行 |

## 七个深层场景

| 场景 | 进入、内容和出口 | 必须单独走查的失败分支 |
|---|---|---|
| 批量更新 | 配置列表选择对象后出现数量与更新动作。结果表固定每份配置的阶段，取消显示「停止后续更新」 | 当前项安全完成，其余项可追溯为未开始；一项失败的运行版本不被替换 |
| 版本对照 | 固定显示当前运行、待应用和差异。应用确认写明目标与可能中断。回滚使用上次良好版本入口 | 候选在比较或确认中变化时，旧比较与确认均失效；失败时确认原运行版本和后续操作 |
| 规则编辑 | 来源规则只读，覆盖项按前置、追加与屏蔽组织。结构与文本共享草稿 | 即使文本校验失败，原草稿仍保留；精确字段错误、返回阻止意外丢弃 |
| DNS 覆盖 | 先显示继承或覆盖来源，按需露出覆盖字段；恢复继承单独表达实际后果 | 保存非法内容时保留原状态，系统未回读成功前不显示已保存；错误位于实际字段旁 |
| 连接快照 | 保持表中筛选、活动范围与选中 ID。详情显示时间、实际策略与规则 | 连接消失后旧快照仍可读，断开动作失效；回到过滤后的列表并帮助重新定位 |
| 选择性恢复 | 校验归档后逐项选取，预览前后保留对象；存在阻塞时显示原因与处理入口 | 预览可读与实际恢复分开。恢复前要求内核已停且 Mlash 系统代理已释放，归档替换后强制重新校验 |
| TUN 权限和清理 | 先显示安装、会话与实际接管状态，再显式改偏好或安装，MTU 等字段仅在高级区 | 权限取消与失败各自反馈；安装完成只表示服务可用；异常清理失败保留恢复入口 |

## 通过条件

七个样板均可用鼠标和键盘操作，包含明确返回路径。窄宽和大字由堆叠代替压缩，主要按钮和错误可达，深色与增强对比沿用 VI 门槛。逐组检查范围覆盖 144 条叶子，运行提交和系统权限必须再按原生 [DoD](u40-ios-daymark-polish.md#实施与完成标准-dod)验证。合成结果只验证可理解性、动作范围、状态转移和信息呈现。
