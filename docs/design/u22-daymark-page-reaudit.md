# U22：按 Daymark 方法重审全页

状态：事前设计。以下是当前源码路径与测试夹具画面的审计，不把设计或截图视为已实现。

## 软件哲学与取舍

Mlash 的最短安全路径是：导入配置 → 看清候选与运行版本 → 显式启用 → 选择节点 → 观察接管和连接 → 需要时诊断/恢复。默认屏幕只呈现当前对象、真实状态和下一步；策略组、规则、DNS、TUN、日志等深度能力按对象和上下文展开。**简约而不简单**：删重复入口、同义标题、长期说明和装饰，不删草稿保护、失败原因、快照来源、回滚、键盘操作和危险动作确认。

Daymark 源码的可迁移规则是 `Main.qml` 的安全导航与同一编辑会话、`NavRow.qml` 的鼠标/键盘对象操作、`ListViewportState.qml` 的稳定对象 ID 与相对滚动位置、`style/Menu.qml` 的展示前分组/测量/锚定/限高、`SettingsGroup/Row.qml` 的单套分组行语法。Mlash 只吸收这些操作原则；不复制 Daymark 的任务领域模型，也不以 QML 替换 Widgets。数据观察、运行配置和代理接管各有不同写入边界，不能为视觉一致而混成同一个开关。

每个可见对象回答五件事：现在是什么、主动作是什么、动作是否写入、失败后保留什么、回来时在哪里。页面默认状态只放频繁动作；次级菜单按当前对象生成。单值立即提交且回读，多字段显式保存；只读信息不伪装成按钮。空态只能有一个明确主动作。搜索/筛选不改变对象或路由。切换页签不销毁草稿，离开数据观察页要标注快照有效期。

## 先整理功能，再安排页面

当前 `ViewIds` 为四个侧栏分区、五个内部视图（规则是配置域任务）和数据四页签。按用户目标而非类名整理如下；“默认可见”只指其所属页，非全局常驻。

| 功能族 | 具体能力 | 阅读/写入及频率 | 唯一主要归属 |
|---|---|---|---|
| 运行与接管 | 内核实际状态、系统代理/TUN 归属、开关、规则/全局/直连模式、当前成员 | 频繁观察；开关/模式是经 Controller 回读的写入 | 首页控制区；TUN 参数在设置 |
| 节点与策略组 | 浏览组、成员选择、单卡/整组延迟、搜索/筛选、收藏、详情、行/卡视图 | 频繁浏览与选择；测速只读，选成员写入 | 首页节点区；托盘只留有限快选 |
| 配置生命周期 | 地址/文件/节点链接导入、更新候选、比较、应用、恢复、重命名、删除、分享、来源策略 | 中低频；候选与运行版要分开 | 配置列表→同一配置详情→同一对象工作区 |
| 配置内容 | 优先规则/内核规则、DNS、节点/策略组、拨号链、规则源/节点源 | 低频、复杂且有草稿 | 配置详情下的编辑任务；规则保留兼容内部路由 |
| 流量观察 | 上传/下载速率、累计、活动连接数、出口/服务诊断 | 频繁只读采样；诊断按需请求 | 数据→流量 |
| 连接观察 | 活动/已结束、搜索、列、详情、复制/关闭、命中规则与策略组定位 | 只读为主，关闭连接是写入 | 数据→连接；详情保留来源列表书签 |
| 网站测试 | 测试节点、全部/单目标响应、目标管理、按节点暂存结果 | 中频按需请求；目标定义显式保存 | 数据→测试 |
| 日志与导出 | 级别、搜索、暂停、复制、清空视图、脱敏导出、日志目录 | 按需观察；清空仅本地视图 | 数据→日志 |
| 偏好与平台 | 外观/字号/标题栏、启动/托盘/快捷键、端口/TUN/排除、核心/Geo/应用更新、备份恢复 | 低频；即时偏好与需重启设置分离 | 设置目录→所属任务；危险恢复需确认 |
| 全局安全 | 状态栏、冲突提示、进度/取消、草稿守卫、快照失效、恢复日志 | 跨页且必须可见 | 固定外壳负责承载，命令/事实由 Controller 拥有 |

### 功能大纲与交叉入口

```text
首页 · 当前运行
  接管开关 / 路由模式 / 当前节点（名称只读）
  当前浏览策略组 → 节点行或卡片 → 选择、单测、详情
  整组延迟 / 搜索筛选 / 仅在需要时打开运行信息
配置 · 来源与内容
  导入来源 → 远程或本地配置列表 → 同一配置详情
  详情 → 候选与运行版本、规则、DNS、节点与组、拨号链、Provider
  来源更新、应用、恢复、分享和删除属于该配置的维护动作
数据 · 观察与诊断
  流量：速率、累计、连接数、出口诊断
  连接：活动与结束、筛选与列、连接详情和断开
  测试：测试节点、目标卡片、单项重测、目标编辑
  日志：级别、搜索、暂停、复制、清视图、脱敏导出
设置 · 偏好与维护
  常用：外观、字号、标题栏
  通用：登录启动、关闭窗口释放界面、启动与托盘、快捷键
  连接与网络：本地代理、TUN、代理排除；配置 DNS 只提供跳转
  维护与数据：内核管理、应用更新、备份、Geo、诊断、文件工具
  关于：应用版本与许可信息
固定外壳 · 跨页
  一级导航、任务进度与取消、冲突和恢复提示、托盘有限快选
```

归属规则：每项功能只有一处主工作区。首页空态导入、托盘快选、设置搜索和连接详情中的规则/组定位是**指向所属工作区的捷径**；不能各自维护第二份选择、编辑或提交状态。页面标题表示任务或对象，不能用“+”“搜索”等动作假装新页面。导航结构先于尺寸和配色确定。

决策顺序固定为：①用户任务与对象；②当前事实、主动作和写入后果；③信息先后与上下文返回；④空/忙/错/取消态；⑤键盘和浮层；⑥字阶、几何、色彩和线条。视觉改动若不能指出前五项中的理由，留在视觉阶段处理，不先改页面结构。

### 重新组织导航与层级

1. **一级导航只按工作目标**：首页用于“运行和选节点”，配置用于“来源和编辑”，数据用于“观察与诊断”，设置用于“偏好与维护”。不把规则、测速或 TUN 单独升为一级；它们仍可由搜索、托盘和快捷键直达所属上下文。侧栏显示当前分区，内部任务标题/返回负责精确位置。
2. **二级只按同一对象的视角**：数据的流量/连接/测试/日志四页签是观察种类，放在内容左起点而非悬在页面中央；配置的详情/规则/DNS/节点是同一配置的工作区；设置目录是唯一默认态，任务按主题进入。二级切换保留本页筛选/滚动，不能假装新建对象。
3. **不再用“动作”充当导航**：“导入…”是配置页的创建动作，首页空态可直接调用同一创建工作区；“规则源”属于当前配置，不是全局页；“出口诊断”从流量或测速的当前上下文打开。顶栏只放当页确需的全局动作，内容附近放对象动作。
4. **一条返回链**：一级分区保留自己的浏览上下文；对象工作区返回对象详情，详情返回原列表；数据详情返回原页签的筛选/列表位置；设置任务返回目录锚点。Esc 先关闭临时浮层，再退出当前任务；写入中的返回由守卫决定。

### 页面骨架：先信息与动线，后造型

| 页面 | 页面职能/视觉焦点 | 默认布局顺序 | 主动线及次级能力 |
|---|---|---|---|
| 首页 | 判断现在是否接管流量、当前在用谁、能否切换 | 控制摘要 → 当前策略组与节点工具 → 列表/卡片 → 按需反馈 | 开关/选成员；模式、整组测速和筛选就近；名称只读。无配置时节点区换成单一导入入口。 |
| 配置列表 | 找到并理解一个来源，决定是否更新/使用 | 唯一导入入口 → 远程/本地分组列表 → 当前状态 | 点行进入详情；批量更新只在存在可更新的外部来源时出现；行菜单锁定配置 ID。无配置时不显示空的远程/本地容器。 |
| 配置详情 | 区分来源、候选、运行版本及其内容 | 返回/名称状态 → 当前版本动作 → 配置内容分组 → 来源维护 | 使用/比较候选；规则、DNS、节点、链与源按同一对象进入；保存/失败返回原对象。 |
| 规则任务 | 编辑当前配置的优先规则并核对实际规则 | 来源与返回 → 编辑/实际视角 → 构造器/列表 → 固定保存结果 | 添加、调整、保存；复杂规则/规则源按需展开。无配置时不显示不可用的大编辑器。 |
| 数据·流量 | 快速读速率和活动连接，并按需诊断 | 关键指标 → 明细/诊断 → 观察时间 | 只读刷新；诊断从本页进入，回原滚动。 |
| 数据·连接 | 找连接并判断来源/命中/状态 | 活动/结束与搜索 → 表格 → 就近详情 | 选连接→详情/复制/关闭；列选择在本表附近；切页回来不重开旧快照。 |
| 数据·测试 | 选测试节点、启动测试、读目标结果 | 节点与运行命令 → 进度与目标管理 → 结果卡 | 全测/单卡重测；目标编辑从结果区进入；切节点显示对应暂存结果。 |
| 数据·日志 | 在记录中查找、暂停、导出 | 一条工具栏 → 日志正文 | 搜索/级别/暂停；复制/清视图在菜单，导出在同工具栏；有日志时不盖空态。 |
| 设置目录 | 找到一项并理解当前值 | 常驻搜索 → 外观/通用/连接与网络/维护与数据/关于分组 | 单值就近选，复杂项进入同主题任务；返回恢复目录锚点。 |
| 设置任务 | 改一组相关参数并知道何时生效 | 返回/主题 → 分组字段 → 说明与提交 | 即时项回读；网络/核心字段显式保存；失败保留输入，取消恢复观察值。 |

设置代码复核的具体断点：目录「本地代理」目前打开的任务混入日志等级、IPv6 和统一延迟；目录「内核管理」直接进入内核更新工具，而内核文件等字段只可经搜索进入隐藏的 `engine` 表单。`autoStart_` 和 `lightweight_` 曾先被放进完整表单，再被 `setTrailingControl` 转移到目录，留下不再归属编辑任务的行。这不是字号问题，是功能归属与控件所有权问题。设计为「本地代理」仅管理端口/节点延迟地址，「内核管理」进入内核选项任务（文件、日志等级、IPv6、统一延迟、更新及运行配置预览），更新工具再从该任务就近进入；目录直接管理登录启动与释放界面。搜索按同一归属定位，不能把字段带去另一任务。验收需覆盖目录→网络/内核任务→返回→搜索定位，并检查单一控件所有权与草稿守卫。

### 视觉与控件在上述结构后确定

Daymark 的“简约”是信息预算：同页一主动作、同一对象一个当前值、一条连续操作带；不是把所有按钮缩小。文字层级以正文/标题/次要说明/数据值四级为限，图标表示功能族而非装饰，每行有完整鼠标命中和键盘可达路径。组块只为真实分组使用圆角卡，列表/表格优先连续细分隔线；页面空白服务于阅读，不让状态或下一步漂浮在视线之外。宽窗可并列，窄窗只折行/收次级操作，不横向滚动或缩放整页。菜单在显示前测量和锚定，关闭后焦点回原控件；主题和 DPI 改变不生成另一套页面结构。

实施顺序据此为：功能归属/路由及空态 → 每页主要布局和工具位置 → 对象工作区及返回链 → 共享行/菜单/字体/间距精修 → 完整操作链与多尺寸截图。每片先说明其主动作与状态转换，失败用例先于外观断言；只对已实测路径标记完成。

## 逐页审计与改动契约

| 页面 | 布局/信息/呈现的当前问题 | 操作与切换断点 | 本轮目标及可观察验收 |
|---|---|---|---|
| 首页·无配置 | 控制卡、标题 `+`、独立导入按钮和空态说明同时存在；状态句在 `updateHome` 中先拼装又覆盖，导致信息竞争 | 用户不知道先做哪个动作；标题导入与空态导入重复 | 空态在节点区只有一处主导入动作，顶部 `+` 在无配置时退让；控制卡三行等高且不复述技术状态，名称区只读。失败仍有就地反馈。 |
| 首页·有配置 | 控制卡、节点工具和节点表是三个层级；浏览组/运行成员/单测容易混淆 | 列表、卡片、组切换、延迟点击、详情与返回须对同一成员 ID | 节点姓名只负责选择或进入子组，延迟只测该成员，信息只开详情；换视图与换页恢复浏览组、筛选、选中和列表位置。整组测速不阻止切成员。 |
| 配置·列表/空态 | 顶部导入行与页底空态句同时存在；远程/本地分组为空时已隐藏，其内的空态动作不会显示 | 导入来源与远程/本地对象关系不清；右键/双击可能改选中 | 只有顶部导入菜单承担新建；空分组继续隐藏，行的单击、键盘、菜单固定同一配置 ID。 |
| 配置·详情与编辑 | 详情概览与多项编辑任务使用不同容器；规则/DNS/节点的深度不一致 | 返回应是编辑→同一配置详情→列表；草稿或候选不能因切页丢失 | 详情保持配置身份、原滚动与未保存草稿；编辑任务用统一工作区标题/返回/保存边界；失败留在原任务。 |
| 规则 | 单独页面叠加订阅选择、配置跳转、规则页签与编辑表格，工具层级最多；无配置时仍展示完整空规则编辑器 | 从配置或连接进入时来源与返回必须明确；只读内核规则与用户草稿不能混同 | 无配置时只呈现一条导入路径，隐藏不可用的编辑器；有配置时以来源配置为对象，编辑和只读视图区分；跳转到配置时只回来源对象，失败不清草稿。 |
| 数据·流量 | 三块指标、诊断组、折叠明细位置有重复表面 | 采样只在流量可见时运行，展开/切页不应重置上下文 | 首屏仅保留速率/活动数及明细入口，诊断从就近行进入；返回流量后折叠态和观察时间保持。 |
| 数据·连接 | 表格工具多且筛选、列、关闭、详情混排；内核未就绪时汇总行的「前往首页启动」与表格空态按钮重复 | 连接刷新重建会丢失滚动/选中；深链不应重开失效快照；无配置时空态按钮写「启动内核」却实际导航配置 | 列表保留筛选/列与相对位置；动作锁定连接 ID；返回只恢复筛选和列表位置，不自动打开旧详情。空态只留表格内一个主动作：无配置进入配置，有配置而内核停止才就地启动。 |
| 数据·测速 | 页签下另有顶端诊断/编辑行、控制卡、解释、进度行，优先级分散 | 网站结果按测试节点暂存，编辑目标和单卡重测回原处；无配置时写「请先启动内核」并跳首页，增加无意义中转 | 节点选择和开始测试为主动作；编辑目标收在目标列表附近；方法解释按需；单卡反馈原位，切回节点复现其旧结果而非误标当前结果。无配置时直达配置，有活动配置而内核停止时就地启动。 |
| 数据·日志 | 空的标题行、顶栏导出、局部工具栏和日志区构成多个错位层级 | 暂停、清空、导出和切页复入要保持筛选与快照语义 | 工具只保留一条就近工具栏；导出只有一处，清空仅清可见视图；空态根据实际可见日志行决定，不能覆盖已有应用日志。 |
| 设置·目录 | 目录与“完整设置表单”历史上并存；搜索曾切换组件系统 | 搜索不能换页或重排草稿；单值菜单需就近、Esc 零写入 | 目录是唯一默认态，搜索框常驻；搜索结果定位目录行或所属任务；目录/任务都保留原滚动与焦点；单值选项以观察值为准。 |
| 设置·任务 | 不同任务的保存、取消、返回规则不一；长表单容易形成隐藏脏草稿 | 跨分区、跨任务、搜索跳转需先守卫 | 多字段显式应用或放弃；失败保留输入与焦点，返回原目录锚点。危险恢复才确认。 |
| 全局与托盘 | 侧栏、数据页签、工作区、浮层和托盘是四层路由 | 菜单打开后切页、窗口隐藏、DPI/窄窗变化，不能留下孤儿浮层或错焦点 | 导航先校验再切换；菜单从触发控件锚定，展示前计算、Esc 关闭不提交；托盘只承载少数高频动作。 |

## 逐页验收方法

每页按同一顺序核对：默认内容、空/加载/失败、主动作、菜单打开和 Esc、编辑取消/提交失败、跨页返回、重进、键盘路径、840×560 与 1440×900、浅/深色。先用含真实模型对象的隔离夹具捕获所有页面和任务态，再执行对象 ID/路由/滚动断言；包内截图必须对应同一个构建。系统代理/TUN 不在默认 UI 测试中写入。当前优先实施可从源码确定的跨页重复入口和空态断点；其余项目以实际测试结果记录，不把审计表冒充全页完成。

连接页有数据时，表格上方的摘要只展示有观测依据的速率与累计量；“断开全部”仅在当前活动连接非空时出现。四项数值均未知且无活动连接时，摘要行整行收起，空态成为视觉焦点。这样在初次读取或内核未就绪时不显示一排“—”和禁用的危险按钮；连接出现后摘要恢复，含义及采样来源由工具提示解释。验收在空、活动连接、已结束页签和暂停快照之间切换，确认按钮不因筛选结果为空而错误消失。

连接列浮层的尺寸验收须在它打开后进行。外观测试曾在首页扫描所有 `QScrollArea`，包括尚未展示、仍用初始几何的 `ConnectionColumnsPopup` 内部滚动区，将其 7 DIP 的布局中间值误报为首页横向溢出。页面检查只测当前可见区域；浮层单独打开，验证测量后的内容、锚点、屏幕边界、横向滚动和 Esc 还焦。若打开后的长列名仍撑破内容，再调整浮层宽度或行内省略，不能靠关掉横向滚动条掩盖裁切。

### 首页控制区单行化修订

用户对三行控制区的验收基准是“一行做一个事情”。三行依次是连接与当前节点、路由模式、当前策略组测速，采用同一行高、图标和水平对齐方式。当前节点名称只读；其下不再附加内核启停、接管方式等技术状态。测速行不再显示「尚未测试」或组进度，成员列表原位显示结果与进度。真实失败仍走全局状态栏和就近操作反馈，详细诊断由数据/设置入口承担，不能靠移除文字掩盖错误。

连接开关表达用户意图，不以 `state.ready` 为启用条件；存在有效活动配置、未退出、未只读且没有其他写操作时可开启。Controller 的 `setProxyEnabled` 负责在必要时准备并启动内核、回读接管状态和回滚。无配置或无活动配置时引导到配置，外部代理接管仍显式确认。验收覆盖无配置、活动配置但内核未就绪、已接管、TUN 观测及测试运行；三行在状态转换前后等高，不显示技术次行。

### 配置任务页签与返回语义

配置工作区已有独立的「返回」控件；把「概览」作为页签却执行返回，是动作伪装成视图，违反导航层级。配置详情的任务行已经是完整导航，进入任务后再显示六个同级页签，会与 DNS 等任务自己的视角页签叠加。配置工作区因此隐藏外层任务页签，以「配置名 / 当前任务」标识位置，只由详情任务行进入、返回控件回详情；任务内部确有多种视角时仍可使用自己的页签。设置和备份等真正需要在工作区直接切换的同级任务保留页签。同一配置重新进入时保留已挂载编辑器和草稿，但声明任务列表要与当前配置状态同步：未打开的过期页签可移除，仍挂载的编辑器留到用户明确完成/放弃；同名任务更新标题和动作。验收覆盖重复进入保留草稿、候选任务消失后不留下空页签，以及返回回到来源配置。

### DNS 工作区信息收敛

DNS 页的默认任务是确认当前配置是否沿用来源 DNS，以及是否需要自定义。默认态只展示一个选择和一条观察结果；未启用自定义时不展示不可编辑的空字段。开启自定义后才出现常用字段和高级 YAML 的编辑视角、撤销自定义操作及保存边界。来源 DNS、已保存配置预览、解析测试是按需查看的辅助视角，放入当前页就近菜单，不同时占据主导航。切换这些视角必须保留编辑草稿；保存失败回到原视角并保留输入。加载、成功和错误只在一个反馈位置出现。验收覆盖默认/开启、辅助视角切换、草稿保留和返回守卫，并检查 840×560 的可见操作区域。

### 配置目录与就近编辑

配置列表按远程订阅/本地文件分组，单击对象进入同一配置的详情目录；目录按「使用」「配置内容」「来源与维护」组织，不把每个任务复制成新的导航层。参照 Daymark 的任务编辑器，多字段任务从详情行就近展开为附着于主内容区的检查器：宽窗保留目录可见，窄窗检查器覆盖内容区；对象名称与任务名在检查器标题中持续可见。返回只收起检查器，恢复详情滚动和焦点，草稿留在原任务；切换对象及危险写入仍走既有守卫。单值选择优先行尾菜单；操作结果在状态栏或就近反馈，不新开页面。此规则先用于配置 DNS，随后覆盖规则、节点与组、来源维护等同一对象任务。验收从列表→详情→编辑→返回→原位置，并在窄/宽窗与草稿状态下检查。

实现中第一张截图显示 720 DIP 检查器挤压配置目录，故宽窗阈值改为内容区至少 800 DIP 时占不超过一半、最大 440 DIP；其余宽度用内容区内覆盖层。DNS 未自定义时只露出选择、当前来源和「查看…」，加载结束后反馈就近、编辑表单不占位，检查器按 240 DIP 内容态收起；打开字段或辅助视角再扩展到可用高度。配置工作区的关闭按钮与上下文标题位于同一行。后续审计须以实际截图再检查字体、密度和键盘路径，不能把“有检查器”视为全页完成。
