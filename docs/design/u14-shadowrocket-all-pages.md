# U14：Shadowrocket 原则驱动的全页精修设计

状态：设计完成、原生实施及自动验证完成，人工/系统验收待办。基线为 1.19.0；[可切换原型](u14-all-pages.html)只展示结构与状态，不执行网络、文件或系统写入。本文是本轮 UI 施工的事前设计；实际实现、测试与发行资格由项目状态和验证报告单独记录。U11–U13 已接受的安全和任务边界继续有效；表现结构修订见 [ADR 0054](../adr/0054-shadowrocket-all-pages-refinement.md)。

## 1. 先审视：完整任务与问题

使用路径是“确认目前是否接管 → 选择配置和节点 → 必要时维护配置 → 观察问题 → 修改设置”。高频动作在首页，低频编辑进入其所属对象。节点、规则、候选版本、连接和设置不应为了凑齐页面而平均分配视觉权重。

1. **清晰度**：1.19 原生冒烟图为 1560×1080 像素的窗口抓图，缺少实际显示器 DPI 与 1:1 人工观测，不能仅凭缩放后的预览认定是哪类抗锯齿失效。代码中存在应用字体与 QSS 双重指定、固定 2 倍绘制图标、位图旗帜缩放等待逐项验证的路径。先定位文字、矢量线条、位图和截图缩放各自的责任，再修源头。
2. **字号与密度**：UiTheme 正文 11pt、局部指标 20pt；U13 节点行已压至 38 DIP，但卡片格子仍约 54 DIP，网站卡最小 108 DIP，设置行额外上下 padding 可扩高。字号等级与组件几何没有按同一基线协同。
3. **结构**：一些页面同时出现顶栏、任务页签、工具带、容器标题、空态说明和页脚反馈。用户必须跨多层寻找主任务。空态与禁用控件可能重复解释同一原因。
4. **语义**：浏览组、运行配置、当前成员、下载候选和连接快照不能混成一个“当前”；加载、失败、外部接管和待应用也不能只靠颜色或未测数字暗示。

U14 不只改首页样式。它重审四个一级分区、配置对象任务、数据四视图、设置目录与所有高级任务、托盘、弹层、空/失败/忙碌状态。功能边界和写入权限不因 UI 精简而消失。

## 2. Shadowrocket 的设计哲学在 Mlash 中的转译

| 原则 | 可观察的界面行为 | Mlash 的必要调整 |
|---|---|---|
| 先内容，后容器 | 主体是连续行与内缩分隔；只有不同任务域才有容器边界 | 大量节点默认行视图；卡片是可选视图；配置和设置不用每行一张卡 |
| 一个画面回答一个问题 | 首页回答“正在用什么、是否接管、如何换”；配置回答“来源和版本”；数据回答“发生了什么”；设置回答“偏好如何生效” | 旧的规则入口收回固定配置对象；不在首页复制诊断仪表盘 |
| 渐进展开 | 常用动作就近，参数在同一对象的下一层；返回保持对象和滚动 | DNS、规则、节点定义、来源策略、备份是页内任务，避免中间“管理…”页和弹窗堆叠 |
| 直接、可预测 | 点击行进入详情或执行明确的行主动作；独立小目标拥有独立后果 | 节点名称选用、延迟重测、信息详情互不触发；配置更新不自动应用 |
| 安静而诚实 | 正常状态少文字；异常持续且指出处理动作 | 运行版、候选、待应用、代理归属、TUN 与内核状态分别标明；错误就地保留 |
| 平台真实感 | 使用系统字体/窗口装饰和键盘习惯，统一色彩与分隔层级 | Windows 不伪造 macOS 红黄绿窗口按钮；以 Qt Widgets 实现，无需因风格迁移 QML |

Clash Verge 的就近定位、明确测速设置、连接检查器和维护状态继续作为桌面效率补充；不引入首页大仪表盘、每组工具矩阵或展开到整屏的托盘节点子菜单。

## 3. 全局骨架与视觉系统

```text
┌───────────┬─────────────────────────────────────────────┐
│ 首页      │ 入口/返回       对象或页面标题        主动作 │ 固定顶栏
│ 配置      ├─────────────────────────────────────────────┤
│ 数据      │ 页面工具：只包含当前任务必要的选择/搜索/动作 │
│ 设置      │ 内容：连续分组行 / 表格 / 有界结果卡         │ 唯一主滚动区
│           │                                             │
│ 小象·版本 ├─────────────────────────────────────────────┤
│           │ 最近操作                 持续告警 · 详情    │ 固定状态栏
└───────────┴─────────────────────────────────────────────┘
```

- 侧栏四项不变，宽约 188–200 DIP；当前项一处蓝色选择。品牌只在底部签名。顶栏 44–48 DIP，标题居中，页面动作按需出现。正文内边距 12–16 DIP；普通页面只滚动正文，状态栏不参与滚动。
- 颜色保留语义角色：Canvas、Navigation、Surface、Separator、Ink、Secondary、Accent、Selection、Success/Warning/Error。浅色以白色分组置于低对比灰底；深色以近黑画布与深灰分组区分。蓝色只标记可操作、实际选中和主动作，不把大片卡片染蓝。
- 用户要求内容再稍小：Windows 中文内容正文从 **10pt** 样片起评估（原 11pt），导航/一级标题维持 11/13pt 等独立等级；副文约 8.5–9pt，数值用等宽数字特性。macOS 正文另以 10.5pt 起评估；并不把 10pt 一刀切给高对比或放大偏好。所有最终尺寸由真实字体度量决定，文字 90–120% 仍可增长。不得通过强制低 DPI、关闭抗锯齿或整体缩放截图制造“细腻”。
- 用户追加统一免费商用字体：优先内置 **Noto Sans SC 可变字重**（Google Fonts，SIL OFL 1.1），中文和西文共用同一字面与字重体系，缺字回退到平台字体。资源随可执行文件加载，不依赖用户安装；包内保留字体许可文本。Qt 应用字体只设置一处，不由全局 QSS 重置 family。验收要看原生渲染解析出的字形族、简繁中文/西文、深浅主题和紧凑行的裁切。
- 单行目录/设置 34–38 DIP；双行节点按正文+副文指标约 36–42 DIP；可选节点卡 42–44 DIP、间隙 4 DIP；网站测试卡约 84–92 DIP、间隙 6–8 DIP。**这些是待原生样片验证的目标，不是现已达到的结果**。独立图标目标至少 28 DIP，重要操作约 32 DIP；视觉图形可更小。
- 统一分组容器 8–10 DIP 圆角，内部行用内缩 1px 分隔；工具条、行、卡、编辑器不能同时套四层描边。当前、hover、浏览选择、键盘焦点、pending 必须可分辨。
- 对照必须使用原始尺寸截图及实际 DPI；先检查字体解析和 QSS 覆盖，再检查 DPR/资源、像素对齐及重采样。高对比和系统文字放大是独立验收，不只从明暗主题推断。

## 4. 一级页面与完整子任务

### 4.1 首页：连接与节点

首屏为三条连续控制行：**当前节点/接管总开关**、**路由模式**、**连通性检查**。第一行主文为实际节点或“未连接”，副文只在异常、外部管理或未接管时出现；开关语义是代理接管，不等于核心启停。第二行显示实际模式，不把路由切换藏进更多。第三行重测只影响观测。

控制组下面是紧凑工具排：当前浏览组选择、搜索、定位当前、测试本组、排序/视图。默认显示连续节点行；组头保留来源、浏览组、实际成员与数量，但同一信息不重复。普通节点一行显示旗帜/名称/协议、副文仅在需要辨认时出现、右侧延迟和详情。当前节点勾、浏览高亮、鼠标 hover 和测速中各自独立。子组进入其成员；自动组可查看当前选路但无手动切换动作。卡片视图仍可切换，用同一模型与命中语义。

无配置时，控制区仍能解释“未连接”，主体仅一处空态“导入配置”；有配置未启用、内核未就绪、外部代理和恢复失败各有一条可执行的下一步。不在正文底部再放重复说明。短列表结束即留白，不伸展行距填满窗口。

### 4.2 配置：来源、版本与编辑

首页为“导入配置”单行入口，随后按**远程订阅 / 本地文件**分组连续列行。每行第一层只显示名称、来源类别/最近更新、运行勾和候选提示；有效的用量/到期才出现短副文。URL 更新与文件重新导入分别命名，行尾信息进入固定对象详情；右键与键盘菜单补低频动作，不取代显性更新入口。

详情顶部显示配置身份、来源与**运行版本 / 候选版本**两种独立状态。主动作随状态变化为“使用配置”或“应用候选”；更新只生成候选，不改变运行版。同一对象内的紧凑导航分为**概览、规则、DNS、节点与组、链路、来源与维护**。前置/订阅原规则/追加/实际内核规则分别标明可编辑性；DNS、节点、链路保留“沿用/覆盖/清除”语义。来源维护呈现上次成功、失败、更新计划、Provider 和候选比较。高级文本作为同一草稿的可选模式，不能创建第二套互相覆盖的编辑会话。

编辑任务占正文而非模态叠层；对象身份与返回位置固定。同级切换保留草稿；切换对象、取消修改、删除和应用候选遵守原确认/校验/回滚。错误就地指向字段、规则行或版本；运行配置在失败前后不被候选替代。

### 4.3 数据：四种观察任务

数据页顶端只有一组 **流量 / 连接 / 测试 / 日志** 页签，不再在正文重复“数据”和当前页标题。

| 任务 | 第一屏 | 进阶动作与状态 |
|---|---|---|
| 流量 | 上传、下载、活动连接三个小指标；一条真实时间轴 | 来源/时间范围、累计统计和内核工作集按需展开；无数据不画零流量假曲线 |
| 连接 | 活动/已结束直接切换、搜索；四列默认表格：目标、命中规则、代理链、状态 | 点击行打开右侧/窄窗后续详情，按“目标→规则→路径→流量”阅读；复制、查看组、预填规则、断开就近；冻结快照标时间 |
| 测试 | 当前测试叶子选择、开始/取消、结果摘要；紧凑网站卡片 | 服务图标、目标、结果+文字状态、独立重测；详情在本卡内展开；出口诊断进入同页任务；结果归属与时间明确 |
| 日志 | 级别、搜索、暂停/跟随、导出；连续文本行 | 历史阅读时出现“回到最新”；脱敏错误可复制；清空视图不删除文件 |

离开观察任务停止对应采样，重新进入时说明新鲜度；空/失败/暂停/过期不能沿用旧的绿点或速率。大数据页可以用剩余高度，但工具排不随空表一起伸展。

### 4.4 设置：偏好目录与完整任务

设置默认是单列分组目录，分为**外观、启动与托盘、连接与网络、内核与维护、数据与备份、关于**。每行左侧小图标与名称，右侧实际值/开关/箭头。即时偏好就地改变并回读；网络/内核类进入完整任务后显式保存。搜索仅定位或导航，不创建并列的第二套设置表单。

| 任务 | 页面内呈现 | 提交边界 |
|---|---|---|
| 外观与文字 | 系统/浅/深；文字比例；即时预览 | 即时提交，失败回到观测值 |
| 启动与托盘 | 登录启动、静默、启动内核、恢复接管、轻量模式、点击动作 | 每项明确当前值；轻量模式描述关闭 GUI 后重建 |
| 本地代理与网络 | 端口、日志级别、IPv6、统一延迟、测试地址；系统代理排除 | 需要内核重启的改动同一草稿，保存后校验并安全重启 |
| TUN | 服务状态、安装/卸载、启用、权限与冲突 | 现有授权及必要确认不变，区分服务/内核/系统观测 |
| 内核管理 | 当前版本/路径、历史、选择、预检、应用 | 预检候选副本，实际回读成功才显示已应用 |
| 数据与备份 | 创建、恢复、自动计划、WebDAV 同级任务 | 先预览，危险后果确认，失败保留原数据 |
| 其他工具 | 快捷键、GeoData、诊断与目录 | 常用入口就近，目录/原始路径只在详情 |

设置目录短时结束即留白，不拉伸目录行。页内编辑保持返回入口与主提交动作在稳定位置；有草稿时标明未保存。窄窗允许纵向滚动，不用两列挤压字段。

## 5. 托盘、弹层与状态

托盘是**快速控制面**：实际运行状态、总开关/接管方式、模式、最近或常用策略组、当前配置、打开对应主窗、退出。大量节点不展开成横跨屏幕的三级菜单；组内提供当前成员和少量最近项，完整搜索回到主窗。展开具体组的按需测速保留既有有界/可取消规则，不以 hover 选择成员。托盘样式遵从当前系统菜单约束，不用另一个视觉体系伪装应用弹窗。

弹层首帧即为稳定圆角；外部点击/Esc 关闭，键盘上下与 Enter 可用，长列表可搜索。鼠标点击后不保留键盘焦点环。系统状态栏只显示最近操作与持续告警；表单字段错误仍留在字段附近。消息出现不改变正文尺寸。

## 6. 技术与合同边界

保持 C++20 + Qt Widgets、UiTheme/WidgetStyle 共用 token；先做字体、图标、GroupedList、NodeRow、WebsiteCard 四个原生样片。当前没有 Widgets 无法实现的已证实能力，故不将迁移 QML 作为 UI 精修前提。UI 仍只发 AppController 命令；来源、候选、运行、上次良好与 OS 实际代理状态按现有契约区分。图标/字体/页面布局变化不新增网络、持久化字段、后台服务或系统代理测试。

实施分片：**A 渲染链与 token → B 外壳/连续行 → C 首页与配置 → D 数据四任务 → E 设置与高级任务 → F 托盘和状态 → G 原生对照/回归**。每片先留下当前/目标截图和交互决策，再修改代码；完成后逐页对照本文及原型，冲突先修订设计。自动展开测速只取当前及最多 15 个候选；显式“重测本组延迟”仍可测整组（最多 500 个）。托盘当前组与常用组优先，最多列 8 组；每组节点快速列表最多 16 项，其余进主窗口。

## 7. 可观察验收

1. 真实 Windows 原生 100/125/150/200% DPI 抓图按 1:1 审查文字、线图标、位图旗帜和边框；分别记录缺陷原因与修复。用户字号 90/100/110/120% 独立验证，无截字/重叠。未执行前不得声称锯齿已修复。
2. 1040×720 默认窗、840×560 窄窗和 1440×900 宽窗，浅/深色与系统高对比逐页检查。含不少于 30 节点、多个配置和长名称的隔离夹具；衡量首屏可见完整行数，而非只测空数据。
3. 首页单击选择、延迟重测、详情、浏览组、候选应用、连接预填规则、设置草稿各走一条完整链；验证取消、失败、回读及轻量释放重建。无系统代理写入的默认测试边界不变。
4. 所有一级页和页内任务检查空、加载、成功、失败、待应用、外部接管、键盘焦点及返回位置。无重复主动作或两处相同状态句；状态消息不引起内容跳动。
5. 设计原型仅检验信息架构和交互意图；原生实现与实际测试另记证据，不能以原型或截图自动判定产品已完成。
