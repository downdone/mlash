# U26：品牌蓝主按钮与绿色胶囊开关

2026-11-19。用户澄清：截图中的「开始测试」属于主操作按钮，应使用专门设计的主题色；「胶囊」指代理和设置中的开关轨道，关闭为灰色，启用为绿色。最初把主按钮染绿并做成胶囊是误解，本设计取代该方案。

## 角色与配色

主题色采用与 Mlash 蓝色品牌图标呼应的深海蓝。浅色主按钮和品牌色为 `#1769C2`，按下为 `#0E5AA6`，淡蓝选中面保持克制；深色主按钮 `#2B73BE`，品牌文本使用更亮的蓝以保证暗底可读。白字与明暗主按钮的对比度分别约 5.47:1 和 4.89:1。按钮恢复原有的紧凑圆角矩形，普通、危险、禁用及高对比主按钮按原有语义处理。

胶囊开关仅把**已启用**轨道设为绿色：浅色 `#34C759`，深色 `#30D158`；关闭仍为灰色，禁用仍为灰色。高对比主题使用独立的深/亮绿。旋钮保持白色，轮廓和尺寸、键盘焦点保持不变。开关颜色不复用 `Primary`，防止按钮、勾选框和配置卡徽标一起变绿。

## 任务与验收

首页的代理开关及设置页的启动、恢复等开关共用同一控件；点击、失败回滚、禁用、焦点与 Controller 命令不变。主按钮覆盖首页空态、配置导入、网站测速及保存/应用，统一回到主题蓝。验收同时检查明暗主题中开/关/禁用开关、主按钮和普通按钮，核对 100%/120% 字号与窄窗无布局跳动。源码外观/组件回归与从独立预览包启动的截图应与设计一致；原生人工屏幕未验则如实记录。

## 实施后复核

新 `switchOn` 语义色只由 `ProxySwitch` 的启用轨道使用；`Primary` 恢复主按钮、勾选与配置徽标的蓝色角色。截图复核：网站测试“开始测试”为蓝色；设置页同屏启用开关绿色、关闭开关灰色，明暗主题一致。三个受影响隔离 UI 测试组通过；包内八路由冒烟与 35 文件完整性通过。实测范围、初版误解和独立预览包身份见[验证报告](../verification-report.md)。
