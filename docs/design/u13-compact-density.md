# U13：紧凑密度对齐

状态：已按事前设计实施并完成本机针对性回归与原生图像复核。接受用户对 U12 密度不足的反馈，尺寸决策见 [ADR 0053](../adr/0053-compact-density.md)。

## 先审视

U12 收敛了页面结构，但沿用 U11 的 52 起节点行、48 目录行、56 顶栏及 20/18 正文边距；两行文本的高度预算错误地使用两份正文指标，副文字与额外留白重复计算。首页控制卡 48/46/46，加上下边距、工具排和布局伸展后首个节点过晚。侧栏行 QSS 上下各 8 再加 margin，密度也未随原型调整。不能仅靠缩小截图或增加窗口模拟紧凑。

只读对照 Shadowrocket 原生首页及用户参考图，按截图比例归一化后控制/节点行距约 38 DIP，工具带与分组之间紧邻。具体参考值为图像估算，不冒称读取了其布局代码；私人节点与订阅内容不进入文档/测试。

## 实施前方案

| 项目 | 现有基线 | 新目标（100% 字号，DIP） |
|---|---:|---:|
| 顶栏 | 56 | 44 |
| 侧栏行 | 约 40 | 30–32，保留焦点/图标命中 |
| 正文水平/上边距 | 20/18 | 12/12 |
| 首页控制行 | 48/46/46 | 38 起，异常信息允许增高 |
| 节点/组头 | 52 起 | 38 起；正文+副文实际指标+6 |
| 单行目录/双行配置 | 48/60 起 | 38/40 起；副文允许增高 |
| 组间距/工具排间距 | 14–24/8–10 | 8–12/4–6 |
| macOS 正文/分组 | 12/13 pt | 11/12 pt，仍用系统字体 |

共享尺寸集中 UiTheme；正文与副文的真实字体指标共同决定双行高度并统一绘制，不把两行当作同字号。不修改用户已保存的字号偏好；100/120% 均验证，不以固定高度裁掉文字。图标图形可减至 18–20，独立命中区至少 28，主要工具图标保留 32。正文顶部布局不得把空余空间均摊进控制卡或组间空隙，短列表结束后留白。

配置/设置目录沿用共享 ActionRow，工作区减少外边距和页签 padding。复杂表单保留必要滚动与主提交动作；不删错误、来源、候选/运行身份或必要确认。空态/失败可以自然占用额外行，不硬压到正常态预算。

## 可观察验收

同一 1040×720、100% 深色夹具对比 U12：实际节点行约 38、控制卡不超过 124、组头顶部明显提前；使用足够多的示例节点验证可见完整行数，不能由六行短列表误判容量。窄窗 840×560、宽窗 1440×900、浅/深色、100/120% 检查文字无相互重叠、无横向溢出、选择/测速/信息命中分离、页签与返回可达。保存前后的业务命令边界不变，默认不写宿主系统代理。

## 实施后复核

已实施共享紧凑尺寸和双行文本布局，配置/设置目录、任务页签与正文边距同步收紧。短列表多余空间由尾部伸展项吸收，工具排不被撑开；当前标记与长名称的绘制区分别预留。

原生 30 节点夹具下，100% 字号设置、1040×720：节点 52→38 DIP，最终整组观测控制卡 146→108、组头 y=270→206，完整可见成员 6→10。首轮单用例控制卡观测为 112 DIP；以上记录具体执行值，不以单次几何推导其他平台。六节点短列表组头仍位于顶部预算内，剩余空白在列表之后。

四组针对性回归通过；追加点击命中用例及原生专项通过。覆盖三尺寸、100/120%、浅深色、独立选择/测速/详情、隐藏草稿与 Inspector 几何。未执行 Windows 原生/完整回归或正式发行资格验收。执行证据归 [验证报告](../verification-report.md) 所有。
