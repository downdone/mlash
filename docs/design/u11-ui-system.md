# U11：按最终原型落实的 UI 系统设计

状态：系统设计已记录，本轮完整原生实施已完成；决策见 [ADR 0051](../adr/0051-prototype-ui-task-hierarchy.md)，完成与验证证据单独记录。本文件把已确认原型转换为统一的原生实施规范，不是另一个视觉提案。

## 1. 输入、顺序与完成定义

唯一视觉与交互基准为 [U09 最终原型](u09-final.html)。旧预览、U08 原型和 U10 预览包均不能替代它。用户随后明确“先 UI 系统设计、布局设计、控件设计、风格设计，按系统方法论”；本轮先冻结系统规则，再修改产品。

实施顺序：任务/信息架构 → 布局骨架 → 组件契约 → 视觉 token → 状态/输入 → 页面装配 → 原型对照。不能从改几个圆角、压缩现有设置表单或换图标开始。

“稍微紧凑”仅允许本规范明确的尺寸差：不减少信息层级，不将详情页换成巨型抽屉，不把目录行展开成常驻表单，不缩小正文。原型里的合成值、评审工具栏和模拟失败开关不进入产品。

完成必须同时满足结构、外观和交互：自动测试通过只能证明对应行为；截图结构对照合格才能称视觉落实；尚缺的页面不能用首批完成代表整体完成。

## 2. 上轮偏差与根因

| 层次 | 原型要求 | U10 实际偏差 | 本轮约束 |
|---|---|---|---|
| 全局外壳 | 侧栏直接四项，品牌在底部签名；居中标题；按页出现导入/添加 | 顶部品牌块、主题/更多常驻，顶栏与正文融为一体 | 重做 AppShell，顶栏内容由页面声明，不再复用全局更多菜单 |
| 首页控制 | 三行同组、蓝色线性图标、主要一行文字、必要时一行状态 | 灰点、三行状态、长测试 URL、无首列图标 | 用统一 ActionRow 组合，不再手写三种布局 |
| 节点工具 | 左侧浏览组，右侧搜索与定位/测速/更多 | 订阅下拉、计数、独立排序、更多和文字定位占一排 | 严格照原型收敛到一条工具排；来源选择进入配置任务 |
| 节点列表 | 本组名/实际成员/数量/本组设置的组头；普通当前行加勾 | “手动选择”泛化组头、整行当前底色；勾与延迟顺序不符 | 真实组头；当前勾在延迟左侧；选中/hover/当前分开 |
| 配置 | 导入/更新两行，来源分组，详情进入后续页 | 多个导入按钮平铺；详情仍为侧抽屉 | 列表 → 配置详情 → 内容/维护任务，保持对象身份 |
| 设置 | 五组目录，只有简单偏好直接开关 | 三组长表单，输入框/路径/启动选项全部常驻 | 首页是目录；启动/本地代理/内核/备份分别进入编辑页 |
| 数据 | 居中四页签，任务内容与详情统一 | 旧工具条、重型面板与独立连接窗口继续拼接 | 共享任务页头、数据列表和 Inspector，不改变采样边界 |
| 视觉 | 原型的中性色层、细分隔线、克制蓝色、稳定字体 | 浅色边框卡、灰按钮、字体后备及尺寸各自保留 | 从语义 token 和组件统一修复，不按页面堆 QSS |

U10 的构建、回归与打包通过不代表上述偏差可接受。保留其浏览不应用、独立延迟命中等正确行为。

## 3. 信息架构：一级、二级、对象任务

| 一级 | 默认页内容 | 二级/对象任务 | 返回位置 |
|---|---|---|---|
| 首页 | 三行控制、浏览组、连续节点 | 组选择器；节点 Inspector；本组测试设置 | 原组、筛选和滚动位置 |
| 配置 | 导入/更新组；远程/本地配置行 | 配置详情；规则/DNS/节点/拨号链；来源与维护；候选比较 | 原配置行与滚动位置 |
| 数据 | 流量/连接/网站测试/日志四页签 | 连接 Inspector；列设置；按需诊断 | 原页签、过滤、选中连接 |
| 设置 | 外观偏好；通用；连接与网络；维护与数据；关于 | 启动与托盘；网络表单；内核管理；备份任务 | 原目录项 |

配置详情固定对象 `profileId`；候选比较还绑定版本；连接详情固定 `connectionId + profileId + activeVersion + generation`。页面标题不能由当前下拉显示值反向推断业务对象。所有返回/切页仍遵守既有草稿保护，不静默保存或丢弃。

## 4. 布局系统

### 4.1 AppShell

```text
Windows 原生标题栏
┌──────────────┬─────────────────────────────────────┐
│ 首页         │ 导入        页面标题          添加 │ ← Toolbar
│ 配置         ├─────────────────────────────────────┤
│ 数据         │                                     │
│ 设置         │ PageHost / Editor / Inspector       │
│              │                                     │
│ 小象 Mlash   ├─────────────────────────────────────┤
│ 版本签名     │ 最近操作          持续告警     详情 │ ← StatusStrip
└──────────────┴─────────────────────────────────────┘
```

- 侧栏从内容顶部开始，四项连续排列，不先占一块品牌展示区；小象和版本为底部低权重签名。
- Toolbar 与侧栏用导航层底色，正文用画布底色；标题必须在内容区真实中心，而非剩余空间中心。
- 首页标题为 Mlash，其他为配置/数据/设置；首页/配置提供左右导入与添加入口，数据/设置两端留空。不用主题按钮或全局更多占据这两个槽位。
- Toolbar、StatusStrip 高度固定，不属于正文滚动；正文只有一个主要纵向滚动容器。
- 正文不得用大 stretch 把列表压在半屏；数据列表可使用剩余高度，目录按内容向下排列。

### 4.2 尺寸表（DIP，100% 文字）

| 项目 | 原型 | 紧凑实现目标 | 规则 |
|---|---:|---:|---|
| 侧栏宽度 | 224 | 208 | 固定，不随字号变成极窄侧栏 |
| Toolbar | 64 | 56 | 两侧槽各 72，标题居中 |
| StatusStrip | 30 | 30 | 字体放大时按单行指标上调，消息不改高度 |
| 内容水平/上边距 | 24 / 22 | 20 / 18 | 全部分区同一边界 |
| 组间距 | 28 | 24 | 组标题在组外，距组顶 8 |
| 组圆角 | 10 | 10 | 首尾行由父容器裁切，不各自画四边框 |
| 单行目录 | 52 | 48 | 整行可点，禁止挤成 30 高表单 |
| 双行节点 | 56 | 52 起 | 实际高至少两行字体指标 + 12 |
| 节点组头 | 52 | 52 起 | 名称/实际成员/数量/设置，不可退化为泛化标签 |
| 行左右内距 | 16 | 16 | 文字起点统一在组左 + 52 |
| 图标 | 22；国旗 27 | 22；国旗 26 | 命中区至少 32，图形本身不等于命中区 |
| Inspector | 350 | 350 | 内宽含边距；窄窗使用后续页 |
| Editor 最大宽 | 760 | 760 | 详情表单居中，普通目录铺满正文 |

默认新窗口 1040×720，最小 840×560；不覆盖已有保存几何。不得以把窗口做得更大来掩盖布局溢出。

### 4.3 响应规则

以内容可用宽度判断，不直接照搬 CSS 浏览器宽度到 Windows DIP：内容 ≥ 860 可打开右侧 350 Inspector，主内容实际收窄并重新布局；小于 860 切为内容区后续页，侧栏/顶栏/状态栏保留。不能用覆盖层挡住未改变宽度的正文。

节点工具排窄时搜索换到第二行，组选择和三个图标保持一行；不将图标缩成极小目标。长名称截断，完整值在 Tooltip/详情可读。文字 120%/150% 增高双行项，禁止固定矩形裁切。

## 5. 控件系统：有限组件和契约

| 组件 | 内容结构 | 行为/状态 | 禁止变体 |
|---|---|---|---|
| SidebarItem | 蓝线图标 + 名称 | 当前项蓝底白字白图；hover 仅淡背景 | 品牌卡挤导航；图标和文字不同状态 |
| ToolbarSlot | 32 命中图标 + 中心标题 | 根据页面声明显隐 | 常驻灰底主题/更多；多层标题 |
| GroupedList | 同一 surface、10 圆角、内缩分隔 | 末行无分隔；整组裁切 | 一行一个边框卡；行间大间隙 |
| ActionRow | icon / title(+sub) / value / chevron | 整行点击；键盘 Enter/Space；disabled 保留原因 | 右边再放“管理/编辑”按钮；组合框箭头再叠 › |
| ToggleRow | icon / title / switch | 点击后依写入/回读表现 pending；开关有可读名称 | 说明与开关错位；同一行多个开关 |
| NodeGroupHeader | layers / group+actual member / count / settings | 设置独立命中，当前值为真实回读 | “手动选择”替代实际组名；组头点击切换业务状态 |
| NodeRow | flag / name+protocol / current check / delay / info | 名称选择、延迟测速、info 详情三目标；自动组只读 | 当前行整片蓝底；点测速顺便选节点 |
| GroupPicker | layers + 组名 + chevron | 弹带搜索、常用/最近与勾选的列表 | 经过就切组；把组切换塞深层更多 |
| SearchField | search icon + placeholder + clear | 有文本才出现清除；过滤不改业务 | 常驻“查找”按钮占满设置页头 |
| ChoicePopover | 列表、当前勾、可选副文 | 选择仅提交本项；Esc/外部点击关闭 | 原生方形动画叠圆角；盲循环选择 |
| Inspector | close/back + title + KV + 操作组 | 宽窗并列，窄窗后续页；对象失效只读 | 不可滚动的重叠抽屉；同对象重复窗口 |
| DetailPage | 返回 + title/sub + 分组目录 | 绑定对象、返回保留浏览上下文 | 把配置详情和节点详情无差别都做抽屉 |
| FormEditor | 返回 + 字段组 + 说明/错误 + 主次动作 | 草稿独立；校验/保存失败保留输入 | 首页常驻所有字段；即时偏好夹带网络草稿 |
| SegmentedTabs | 居中四项，淡底/当前 surface | 左右键切换；可见任务管理采样 | 老式下划线页签+外置重复标题 |
| StatusStrip | 最近操作 / 持续告警 / 详情 | 固定高度，失败可复制/处理 | 插一张消息卡改变正文高度 |

组件同源 token、图标绘制、焦点策略和可访问名称；同一种控件不能每页重新定义。先在真实主题和字体下验四个关键组件 AppShell/GroupedList/NodeRow/Inspector，再装配页面。

| Navigation | #202020 | #F5F5F7 | 侧栏/顶栏/状态栏 |
| Surface | #1C1C1E | #FFFFFF | 连续组/详情表面 |
| Separator | #343436 | #E3E3E8 | 内缩分隔，细线 |
| Text | #F5F5F7 | #1D1D1F | 主要内容 |
| Secondary | #A1A1AA | #63636B | 值/说明/元信息 |
| Accent | #4DA3FF | #0066CC | 图标/链接/信息按钮 |
| Primary | #075FBE | #0066CC | 选中导航与必要主动作 |
| Hover | #29292C | #ECEEF3 | 可交互悬停 |

| Warning | #EFB66A | #865000 | 需要注意 |
| Error | #FF8A96 | #B32636 | 错误/超时 |

高对比沿用独立语义方案，不能被这两套值覆盖。对比度必须实测；不用低透明度叠层冒充可读灰色。尊重已有外观偏好；评审对照在相同主题/字号进行，不能把深色原型与浅色实机并排后判断颜色一致。

### 6.2 字体与图标

- 正文目标 15 CSS px 对应 Windows 11pt；次要文字 9pt；标题 12pt，详情标题 16pt。层次主要靠权重/颜色，不把每个卡片标题加大加粗。
- Windows 中文使用明确的现代 UI 字体后备链；验证 Latin/中文最终解析字体。禁止 QSS 将多字体后备链降为单个 Segoe 字体，导致中文落入衬线后备。
- 保留平台默认字距，不模拟 macOS 的 SF 专有字形或伪造窗口按钮。数值对齐使用字体数字特性/等宽数字，不把所有正文改等宽字体。
- 图标采用同一线宽约 1.65、同一 24 逻辑画布。正常无灰底方块，只有真正服务标志/国旗保留其资源。未知地区用地球，名称推断不能冒充 IP 定位。
- 圆角、阴影只表达容器层级；普通组无阴影。只有弹层/并列 Inspector 需要轻微分层，不用大渐变与厚描边。

## 7. 页面装配清单（直接对照原型函数）

| 页面/基准函数 | 必须出现 | 必须移除或下沉 |
|---|---|---|
| `renderHome` | 三行控制：rocket+当前成员/接管状态+switch；route+全局路由+值；gauge+连通性+图标测试 | 长 URL、重复订阅/核心状态行、首页概览卡 |
| `drawNodes` | group picker、右侧搜索/定位/测速/更多；真实组头；连续 NodeRow | 来源下拉、独立计数标签、独立排序按钮、文字“定位当前成员” |
| `renderProfiles` | 导入/更新两行；远程/本地标题在组外；行显示来源/时间/候选和当前勾 | 添加/文件/剪贴板等同级四按钮；空列表大面板；常驻教学段落 |
| `configDetails` | 返回配置；对象标题；候选/使用；配置内容四任务；维护三任务 | 将全部对象操作塞到侧抽屉按钮条 |
| `renderSettings` | 外观/字号；通用四项；连接四项；维护四项；关于 | 常驻的启动细项/端口/日志/IPv6/完整路径/环境变量/多种备份按钮 |
| `networkEditor` | 返回设置；明确字段；保存并重启/取消；失败留稿 | 页面底部与编辑器同时出现两套应用按钮 |
| `renderData` | 居中流量/连接/网站测试/日志；各任务轻页头 | 当前任务名在全局顶栏和正文重复；多层大边框 |
| `connectionInfo` | KV 快照、看组、以目标新建规则、复制、关闭确认 | 关联已失效配置仍允许写入；独立杂乱的详情窗口 |

原型只是高级工具的任务入口，没有完整 DNS/TUN/备份编辑字段；复用现有可靠编辑器，但入口必须归属正确，不新增未实现菜单或删掉可用功能。

## 8. 输入、状态与安全语义

每个组件必须覆盖 normal/hover/pressed/keyboard-focus/disabled/pending/error；列表另有 empty/loading/stale。实际 current、用户 selection、鼠标 hover、定位 flash 分开渲染。鼠标点击不留蓝框，Tab 焦点必须清晰。

页面打开不写配置；选浏览组不激活订阅；下载不应用候选；单测不选节点；连接新建规则只预填；恢复与特权写入仍有必要确认。按钮忙碌时禁止重复写入，搜索/查看仍可用。离开观察页停止采样；轻量释放重建后恢复有限浏览状态，不保存敏感快照。

状态说明以可读结论为主；长 URL、路径、测试新鲜度、协议参数进入详情。故障原因、未保存、待应用、接管后果不可为了简约隐藏。

## 9. 实施架构与替换方法

继续 Widgets；复用 Controller/模型/命令，只替换表现树。先按组件边界提取 `AppShell`、`GroupedList`、`ActionRow`、`NodeRow`、`InspectorHost`、`DetailPage`、`SettingsDirectory`；名字是职责约束，不要求为每个名字建立空类。

旧编辑控件可以整体移入 DetailPage，但不能隐藏在目录下仍撑开几何，也不能复制两套字段/状态。设置的即时偏好与需要重启的草稿分别走原命令。旧入口经路由适配进入同一个编辑会话；同一字段只有一份草稿。

统一样式禁止靠广域 `QPushButton` 的灰底/默认边框实现所有行；组件使用明确属性/类并有命中和尺寸契约。颜色/字号/尺寸只从 UiTheme 取。Windows 原生调用仍留平台层。

QML 仍按 [选型评审](u09-technology-review.md) 决策：只有关键组件实证不能达到设计或维护成本明显失控时再采用，不把框架更换代替系统设计。

## 10. 原型一致性验收与执行门禁

| 门禁 | 可观察证据 | 不合格时 |
|---|---|---|
| G1 结构 | 同尺寸原型/实机的侧栏、Toolbar、分组、返回层级逐项一致 | 不能进入逐控件美化，也不能打“整体完成”标记 |
| G2 组件 | 四关键组件深/浅、鼠标/键盘、空/加载/失败样片 | 修共享组件，不给每页加例外补丁 |
| G3 页面 | 四一级页 + 配置详情 + 网络编辑 + 节点/连接详情对照图 | 缺屏记缺屏，不用其他页面代替 |
| G4 行为 | 浏览不应用、单测不选中、pending 回读、草稿取消/失败、陈旧连接只读 | 修命令适配/上下文，不能只改测试期望 |
| G5 弹性 | 1040×720/840×560，100%/120%/150%，长中英文与 500 节点 | 修布局/字体，不靠扩大默认窗口过关 |
