# U40 Mlash 视觉与交互详细设计

本设计把「连接、配置、诊断、维护、设置」落实到可走查的桌面界面。用户在任何分区都能辨认当前对象、实际状态和下一步。Apple HIG 提供布局适配与内容层级的依据，Daymark 提供固定动作槽和操作回位的参考，Shadowrocket 提供同类网络工具的简约交互参考。当前发版仍用 U32 视觉规范。U40 的数值与组件为拟实施规格。[全界面方案](u40-ios-daymark-polish.md) · [现行视觉规范](u32-mlash-visual-identity.md) · [Apple 布局](https://developer.apple.com/design/human-interface-guidelines/layout) · [Apple 无障碍](https://developer.apple.com/design/human-interface-guidelines/accessibility)

## 从 Shadowrocket 提取的简约规则

| 参考画面中的做法 | Mlash 桌面设计与检查 |
|---|---|
| 首屏把开关、路由、测速放在连续三行，节点列表紧随其后 | 连接页默认采用一组紧凑的「流量接管 / 路由模式 / 测试当前组」。当前配置和节点以短说明出现，流量摘要放节点区下方或按需展开。840×560 DIP 默认字号核对三行控制和至少三行节点 |
| 节点名称是主信息，协议是第二行，分组可折叠，行尾独立查看详情 | 节点采用连续列表和稳定的延迟列。组选项集中于组头，手动选择与详情有独立命中区。当前节点有可读标记，名称内的地区只作推断。分别测试点详情零切换、选路失败和折叠后的焦点 |
| 选项用主标签、当前值或勾选表达，解释跟着选项或分组 | 路由模式在行尾打开三项选单，每项包含作用短句和当前勾选。设置每行只承载一种语义，整行进入、即时开关、草稿字段和只读状态用不同反馈。禁用原因靠近字段 |
| 下载配置用一个短输入，添加和编辑节点才展示长表单 | URL 采用一个持久标签输入和明确提交，将下载策略、命名、节点预览放在按需展开的区内。长表单采用属性行和共享草稿，协议选定后才展开相关字段。校验、候选和激活仍单独表达 |
| 单目的工具只显示完成当前任务所需的输入、结果和返回 | DNS 查询先显示域名、类型、查询及结果，只有显式进入时显示工具。运行规则与配置规则分别标对象。高频诊断保留桌面数据表，低频工具归组并可从搜索直达 |

图形、品牌、色值和 Windows 导航使用 Mlash 的体系。参考图中的订阅地址、真实节点与移动端专用功能不进入样板或项目资料。走查从 144 条末级任务出发核对深层可达性，首屏只承载高频状态和动作。

## VI

Mlash 保留炭黑底、白色 M 路径和端点。侧栏使用 26 DIP 标志及 16 DIP 字标，间隔 8 DIP。关于与版本页使用 44 DIP 标志和 24 DIP 字标。任务栏、资源管理器和窗口使用原 ICO 母版，侧栏保持统一前景。品牌组留白最少为标志宽度的四分之一。产品页面只使用路径标志表明应用身份，连接对象、节点和诊断结果有独立功能图标。[M 路径母版](u32-assets/mlash-app-icon.svg) · [标准组合](u32-assets/mlash-lockup.svg)

应用图标与托盘徽标检查 16、20、24、32、48 px。在最小两档可针对栅格调整端点和徽标的间距。托盘底图参与辨认；实际接管用对勾，外部管理用双环，未知用问号，处理中用省略点，故障用感叹号。托盘提示写全代理归属和内核阶段。原生验收分别在浅、深和增强对比的任务栏中观察实际渲染，并检查 EXE 图标资源。

## 版式与组件

| 元素 | 默认规格与适配 |
|---|---|
| 字体 | 保留 Noto Sans SC 和已验证 Windows FreeType 管线。页面 24/32、对象 18/26、分组 16/24、正文 14/22、说明 12/18。斜杠后的数字为 100% 字号下的目标行高，Qt 以实际字形度量为下限。日志和 YAML 单独使用等宽字体。数值与单位保持同行，列表数值右对齐 |

| 控件 | 字段和普通按钮最小高 36 DIP，独立图标命中最小 32 DIP，触控动作达到 44 DIP 或有等效清晰入口。一级导航行最小 40 DIP，普通对象行 48 DIP，可带两行信息。技术数据表 32 DIP 起。圆角按字段 8、选中面 8、内容组 12、独立浮层 14 DIP |

| 动作层级 | 每个任务或对话框最多一个填色主动作。普通命令用中性按钮或对象行尾。带危险后果的名称说明结果，对话框默认焦点为安全动作。单对象多项操作置于锚定菜单 |
| 行与列表 | 采用标题、次信息、稳定状态/动作列。配置集合默认连续列表；选中、正在运行、有候选分别编码。节点卡片视图保留为切换项。列表密度由行高和间距控制，文字大小独立保存 |
| 空态与反馈 | 空态在任务起始区就地显示原因和可执行动作。进行中预留固定动作槽。可修正错误贴字段或条目，阻断性系统错误同步到全局状态区。错误保留至条件变化或用户明确处理 |
| 动画与焦点 | 普通悬停/选中用短促状态过渡，子层展开最多 160 ms，系统减少动态时直接切换。打开工具后焦点到第一个任务控件。返回按对象 ID 恢复原触发项、筛选和滚动；失效时回列表安全位置 |

## 五个分区的界面

| 页面 | 首屏与主要动作 | 深层容器与状态 |
|---|---|---|
| **连接** F01–F06 | 顶部三行「流量接管 / 路由模式 / 测试当前组」。就绪时节点区紧接其下，配置与组信息贴在相应对象旁。840×560 DIP 默认字号须看到至少三行节点 | 节点行并列名称、协议、实际选路标志和延迟。信息按钮或键盘进入只读详情。组设置、筛选、模式分别锚定来源。无配置时主动作是导入，待用配置时是选择。外部归属或状态不明可就地处理 |
| **配置** F07–F16 | 标题与「导入配置」对齐。列表每个对象显示来源、更新时间和运行/候选两个状态。列表工具在集合范围内操作 | 选中对象后，宽窗以对象任务目录与详情并列，窄窗下钻。版本固定对比「当前使用」和「待应用」。规则、DNS、拨号链与来源编辑各有独立标题，字段错误和取消返回同一草稿。导入从三种来源中选择，地址遮挡，成功定位新对象 |
| **诊断** F17–F22 | 页内固定二级入口，表和日志占主要阅读面。连接默认显示活动范围、工具带和采样时点，暂停、筛选和连接详情保持独立语义 | 流量、连接、网站测试、出口与服务、运行规则、DNS 查询、日志均按其采样方式组织。连接详情固定快照对象和时间，返回恢复选择。区分零值、等待、筛选无结果、失败四类信息 |
| **维护** F23–F28 | 用简洁目录进入备份与恢复、内核、Geo 和应用版本，目录只显示可核对的最近结果 | 备份恢复按选择、预览、确认分步。内核和应用更新都区分当前、候选及校验失败；内核应用显式说明可能中断。Geo 区显示当前版本引用与默认快照来源 |
| **设置** F29–F33 | 目录列与属性分组，当前值贴着行尾，每行承载一个即时偏好或进入一个任务 | 外观与轻量关闭可即时回读。本地端口、DNS 接管或 TUN 路由等工作区显示更改后果、草稿和明确的提交动作。服务安装/修复/卸载各自独立，权限与失败信息就地显示 |

托盘及恢复入口 F34–F35 共用应用状态、动作名和目标路由。向右切页或关闭弹层后复查原位置，采样退订与轻量窗口销毁继续遵循原契约。

## 关键状态的逐屏规则

| 状态链 | 屏幕上的变化 | 输入、焦点及业务约束 |
|---|---|---|
| 首次安装 → 导入失败 → 重试 → 使用 → 接管 | 连接页提供导入。错误贴地址，重试保留原值。成功选中新配置，使用后仍显示「代理未开启」。开启只在回读后显示接管 | 光标先到输入，成功后若来源窗口还处于原任务则移到「使用」。使用和开启各是一次明确提交。后台结果不抢焦点 |
| 外部代理冲突 → 取消或确认 | 接管行显示外部管理，确认说明预期影响。失败时显示实际仍由谁管理及处理位置 | 取消回原开关，零写入。请求成功后等待独立回读再变更开关值 |
| 活动版本 + 候选 → 比较 → 应用或返回 | 「当前使用」与「有更新」并存。各列标版本，过期比较禁用应用并显示重新比较 | 比较只读。应用可能中断接管，提供显式确认。失败显示实际运行版本和下一步 |
| 草稿 → 无效字段 → 关闭 | 错误紧贴字段。保存保持可修正状态。存在有效草稿时离开给继续编辑或放弃；已提交窗口说明关闭效果 | Esc、Alt+F4 和关闭按钮共用草稿判断。继续编辑聚焦到原控件，放弃才清除 |
| 连接结果 → 详情 → 返回 | 详情标注对象与采样时间，返回保留范围、过滤和滚动 | 刷新后只按原对象 ID 重新定位，过期详情不可对替代行执行断开 |
| 选择备份 → 预览 → 部分恢复 | 预览显示校验结果、当前阻塞、待恢复条目。选择后才出现最终确认 | 预览与确认绑定所选归档。取消、密码错误与预览过期零恢复 |

## 设计走查与完成判据

样板走查先使用合成数据核对五个分区，再走失败、取消与返回路径。对照 [T01–T13](u40-ios-daymark-polish.md#测试方法) 核对选中、当前运行、进度和后果是否可辨。样板 320 CSS px 的换行只说明预览适配，实际 Widgets 门禁以 840 DIP、200% 应用字号和真实 Windows DPI 为准。

1. 五区分别确认任务标题、主要入口、深层路径和单一可写对象。逐项对照 144 条末级任务核路由归属。
2. 首轮比较浅色、深色和增强对比，对已列色对做 sRGB 数值检查。用原生截图复核抗锯齿、焦点、命中、滚动槽、窗口边界和托盘图标。
3. 用鼠标、纯键盘和讲述人完成首次连接、候选比较和失败重试。保留原生证据，验证焦点、草稿和对象身份。
4. 每个切片对照本规范与总 DoD，记录选用样板、实际尺寸、主题、任务结果及实际测试。尚未走查的原生、读屏和系统行为按未验记录。

## 当前 Widgets 实现复审

以 Windows U39 便携包和同一工作区的 Widgets 测试为基线。现有首页三行控制组、内嵌配置工作区、连接检查器和设置连续分组已形成统一的桌面界面。U40 五区用于归纳任务。是否调整一级入口，以 T13 的任务发现结果决定。深层浏览器样板用于推演状态，组件和视觉改动以原生基线样片为对照。

原型放大了标题和分组间距，重复增加行尾文字，同屏可用内容随之减少。它把配置对象下的版本、规则和 DNS 放进场景侧栏，打断了原生「配置卡 → 同一对象工作区 → 编辑」的关系。版本样板又将实际的增删改和选择失效提醒压成计数。应保留原生的紧凑工具带、独立点击区、对象页签和证据密度。Shadowrocket 的分组行及右侧当前值已在首页和设置落地。Daymark 的固定操作位置、就近详情和返回焦点适用于补足当前实现。

| 功能与优先级 | 当前实现的表现 | 精修要求与验收 |
|---|---|---|
| F01–F06 · 首次连接和常用控制 · 优先 | 空首页能把焦点送到快速导入。840×560 DIP 有配置样片可见六条完整节点；三行控制组下方已有策略组、连通性、当前位置与信息操作。内核就绪后，代理行标题可能以节点名替代接管状态文字，灰色开关旁可同时出现正在使用的节点名。 | 保留三行及节点密度。第 1 行常驻「代理」和实际接管状态，节点名为次级信息。已有配置未使用时，「选择配置」直达可使用的卡片。T01/T03/T04 注入内核已就绪但代理关、外部代理、未知、系统代理与 TUN 后逐一核对可见文字、开关、托盘事实和返回焦点。相同夹具下的可见节点数以现有样片为下限。 |

## 原生精修实施设计

1. 首页第一行保持原高度。左侧恒为「代理」，旁边用可省略的次级文字显示当前节点；右侧为实际接管说明和原开关。可用空间优先给接管状态。点击、忙碌和失败均由原 Controller 路径回读。无配置时聚焦带常驻「配置来源」标签的快速输入，有配置未使用时从「选择配置」聚焦一条可用卡片，用户继续显式使用。以原生 840×560 DIP、100% 和 120% 字号核对三行等高、状态与开关一致及节点可见量。
2. 批量更新在原集合工具带显示范围。零或单选沿用「更新全部」的集合入口和卡片单项更新，多选明确标出实际可更新的项数。有源文件的本地配置可同步，仅有快照的配置跳过；所选均为快照时禁用按钮并说明原因。工作区列出打开时的更新计划或同范围的上次结果。停止只影响后续队列；返回后重新按当前选择计算。测试覆盖混合来源、仅选快照及运行版未切换。
3. 候选比较保留差异表和具体证据，补充对象名、已使用、候选与上次良好版本。失效在比较头下说明并可重新比较。配置卡与键盘的应用动作进入同一比较流程。应用与回滚复用确认样式，说明目标和运行时影响，默认焦点在取消；确认后仍核对同一版本。失败留在来源工作区并显示当前版本，取消或目标变化不提交。用对象替换、确认取消、写入失败及返回复测。

## 独立盲评后精修

- 窄配置卡中的「查看变化」「应用更新…」以完整文字和内边距为布局下限。空间紧时状态与动作换行，卡片随之增加高度，现有按钮和 Tab 顺序继续可用。以 840 DIP 浅深、100% 和 120% 验收按钮内容区域、相邻控件间距与焦点。
- 来源读取失败把原因与「重新读取」放在节点和策略组工具带下方。读取当前对象失败时列表只表达未取得内容，不重复播报原因。保存失败、版本变动仍用原任务反馈，底栏独立事务的恢复入口明确其归属。测试重试可恢复、未写数据及编辑继续可用。
- 首页、连接、流量和网站测试共用无配置与未使用配置文案，主动作与说明成组。前者聚焦导入，后者聚焦可使用配置。配置集合的空态靠近快速导入。其余刷新、清除筛选及诊断查询保持各自语义。
- 差异页以增删改和失效选择为阅读重点，版本编号进入元信息。范围预览中的说明、列表与主操作相邻，长结果表独立滚动。保留既有版本校验、停止队列、危险动作确认及失败反馈。
- 宽窗节点行将当前勾选收回节点名附近，并以有限阅读宽度对齐数值和信息按钮，绘制与命中共用几何。详情表单保持原容器，字段在可读宽度内换行。设置搜索显示分组路径和进入提示，沿用已有路由与草稿保护。

## 配置卡片精修

当前卡片把标题、来源、状态和操作分散在四个不同的水平位置。紧凑窗口虽然保住了按钮文字，但固定增高后，当前配置与待应用配置的留白和动作仍不一致。

- 卡片使用上下两组。上组把名称、来源、时间组成一块，与类型图形和行尾工具对齐。来源在必要时省略，时间保留。两组以细分隔线相接。下组左侧为状态，右侧为动作；在文本与两个动作放不下时只重排底部。卡片高度按字阶和底部所需空间计算，同一行对齐。
- 运行归属与更新结果独立。运行版同时拥有待应用候选或遇到更新失败时，两种事实各有一行，以小型语义形状辅助文字。选中沿用独立外框，键盘焦点可辨。普通动作使用安静的文字样式，应用或使用采用强调色浅底。
- 保留配置卡原有操作和命令。以 840 DIP 浅深 100%／120%、以及宽窗复核视图。测试长名称、当前使用兼有更新、更新失败、查看与应用的独立命中以及完整按钮标签。复看网站测试和节点卡片的两行标识，沿用它们现有的数据呈现与布局。

## 配置卡片文字完整性

参考 Shadowrocket 截图 1、3、9 的名称和来源层级，以及 Daymark 对常用与次要动作的处理。用户确认采用紧凑卡片，副标题并排显示来源和最近成功更新时间。远程来源显示 URL 的协议、域名和显式端口，完整地址在来源编辑中查看。卡面保留必要状态和一个文字动作。标题使用正文字号和中等字重。名称和副标题按实测宽度换行，无空格的长文本也能完整排版。较长内容触发单列，各卡片按自身内容定高。

- 时间取本地时区，有来源但未成功时显示「尚未更新」，仅有本地快照时在有记录的情况下显示时间。订阅用量留在来源维护。默认闲置状态由「使用」表达，当前使用、更新失败和待应用各按实际状态展示。去掉卡内分隔线，缩短上下留白，以字重与间距区分名称、来源和状态。
- 候选只露出「查看更新…」，浏览即进比较工作区。键盘快捷键继续可达。工作区仍明确显示目标版本，并在应用前单独确认。刷新图标固定在更多菜单左侧，存在可刷新来源时走原单项更新。没有来源时置灰并给出原因。
- 以 840 DIP、100%／120% 浅深色和宽窗检查名称、公开 URL、时间和按钮完整入框。用含中英文长名称、无断点长域名、带路径及查询参数的来源、当前使用兼有候选和失败的夹具检查。逐项验证普通卡无闲置标签、刷新位置与来源能力一致、候选只有一个文字动作，以及进入比较、来源详情和返回时的定位。

## Daymark 配色导航与测速卡

- 全局浅色和深色使用 Daymark DesignTokens 的背景、侧栏、正文、次级文字、强调、选中、分隔、悬停、按下和状态色。正文画布按 Daymark 主窗用 surface，分组和卡片用 grouped，侧栏用 sidebar。高对比轮廓使用 Daymark 的 outline，继续按本项目既有对比度要求检查。品牌、服务标识和系统标题栏使用各自原有资产。
- 侧栏采用 Daymark 的品牌与折叠开关同排、双列导航卡、底部固定工具。Mlash 的首页、配置、数据使用各自标题、图标和已有路由，设置保留固定入口。收起为 44 DIP 窄栏，展开恢复入口焦点，工具与任务工作区继续从原路由返回。当前页面底色由路由决定，键盘焦点单独显示边框。
- 配置卡沿用网站测速卡的表面、图标底块、标题与副标题并排结构、内边距和静态动作。公开 URL 与时间在次级行显示，必要时全量换行，刷新紧邻更多。下方一行呈现状态和操作，需要同时表达运行与更新两种事实时状态可增高。刷新走单项检查，候选由比较和显式确认应用。
- 用 840／1440 DIP、100%／120% 浅深色复核卡面、窗口、导航与可读性，高对比使用原测试门禁。验证鼠标和键盘切页、设置工具中的选中与焦点、折叠往返、导入、刷新和候选、长名称与 URL、网站测速卡详情。按原生截图和便携包冒烟分别收证。

## 侧栏竖排

首页、配置、数据自上而下组成单列。每项为 38 DIP 高的整行入口，图标和文字横向对齐。保留 Daymark 色板、当前页面浅色底、独立键盘焦点、顶部折叠和底部设置。方向键上下移动焦点，点击或回车切页。展开恢复当前入口。

## 配置页参考稿精修

参考稿把导入集中在一处，卡片边界和右上操作一眼可辨。现有配置页采用同一思路。配置来源、文件选择、导入和高级新增共用一条浅强调色导入栏。输入使用独立表面，导入反馈紧邻栏下。导入栏增加 20 DIP 纵向内边距，列表上方间距沿用原值。常驻来源标签配简短输入提示，窄窗能读全。保留 URL 保护及拖入现有入口。

配置卡沿用网站测速卡的图文布局，并采纳参考稿的蓝色类型图标底、卡片细轮廓和右上角小方形工具按钮。状态在名称和来源下方对齐，以紧凑圆角底和语义色区分当前、待应用及失败。普通卡由「使用」表达可用动作。公开 URL、更新时间和必要状态完整换行。配置顺序沿用现有菜单。更新仍生成独立候选，从比较页确认应用。

以 840 DIP、120% 字号浅深主题和常规窗宽检查导入可见、长内容无截断、刷新和更多的点击范围与键盘焦点。使用原导入、失败、取消、候选与返回测试检查交互。
