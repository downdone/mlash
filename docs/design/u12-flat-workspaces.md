# U12：页面内工作区与层级收敛

状态：已按事前设计实施；本机针对性自动回归与 Cocoa 图像复核结果见验证报告，Windows 原生与正式发行资格待验。用户要求按 Shadowrocket/最终原型对照结果完整实现，并减少弹窗、尽可能减少设计层级。后续原型冲突按 ADR 0052 处理。

## 原则与范围

保留四个一级分区，常用查看/选择就地完成。复杂编辑在原分区正文内完成，入口一次到达完整任务，不先进入只有“管理…”按钮的中间页面。配置对象采用同级任务切换，不叠加目录、抽屉和编辑窗口。减少表现层级不改变 Controller、候选/运行/回退、恢复日志或权限边界。macOS 平台仍明确 Unsupported。

## 组件、任务与布局

- 正文宿主始终占据顶栏与状态栏之间的伸展空间。Inspector 在正文内部并列或替换，不隐藏唯一伸展项；关闭恢复列表、滚动和焦点。
- TaskWorkspace 复用现有编辑器与 Controller 命令，编辑器以子控件承载，不创建独立工具窗口。同一工具/对象复用一份会话；同级任务切换保留草稿。返回所属页面不等于取消写事务；关闭/轻量释放检查覆盖隐藏的工作区草稿与进行中提交。
- 内核管理从设置目录直接打开完整任务，路径、版本记录、预检/应用同页；备份以创建/恢复/自动计划/WebDAV 同级切换，不保留“目录→管理”的中间页。
- 配置列表到对象工作区；概览、规则、DNS、节点/组、拨号链、来源与更新、来源数据、候选在同一对象上下文中可达。来源信息与维护合并，技术名称以“节点源/规则源”表达。
- 组选择为就地搜索/选择面板；本组参数在首页内展开，绑定配置与组身份；浏览其他组隐藏旧草稿，返回原组恢复，明确编辑新组才确认放弃旧稿，定位被筛选隐藏的当前成员不再用普通确认框，保留原筛选并提供恢复动作。
- 导入在配置任务区域内，订阅/文件/节点链接同级，下载参数直接展开；系统文件选择器保留。其他维护、诊断及只读详情采用同一个正文任务容器，不叠加独立窗口。
- 简单偏好保留行尾选择/开关；删除、恢复、放弃草稿、外部代理接管、特权安装等必要确认保留。普通校验错误和详细信息在任务内显示，失败留稿。
- 网站测试详情直接在对应结果卡片内展开，保持结果快照，离页销毁；避免为了只读详情中断整个测试页面。外部链接/剪贴板预填作为初始值，未编辑即可取消，用户实际修改后的输入才按草稿保护。
- 日志默认仅保留搜索、级别、暂停与更多；阅读历史时就近出现“回到最新”，不要求为常用阅读动作打开菜单。
- 保持主题、字号、图标与 ActionRow/GroupedList；首页控制行加内缩分隔，搜索宽度有限，列表表面随内容。工具任务优先内容与主提交动作，低频选项同页展开。

## 分片与可观察验收

1. 配置实际行不出现 UUID，无空态按钮覆盖；空列表动作仍可用。Inspector 在 840/1040/1440 宽度下顶栏 y=0、状态栏贴底，关闭/重开不遗留边距。
2. 工作区不出现新的可见独立 QDialog；复用/切页/关闭、失败、取消、草稿与 pending 均有回归。覆盖 840×560、1040×720、宽窗及 100%/120% 文字。
3. 设置/配置任务一次可达，不创建重复会话，不错用其他配置身份；对象删除与版本变化遵循原只读/拒绝语义。
4. 组/参数、导入、诊断入口就地或正文内；普通通知不弹框，保留输入和实际读回。
5. 构建、针对性回归及 Cocoa 原生截图复核；默认不写宿主系统代理。无法在 macOS 运行的 Windows 系统/真实核心用例明确列为未验。

## 实施后复核

首页已采用三行控制、右侧图标工具排、默认折叠搜索和按内容结束的单份来源/组列表。配置副标题改读真实描述，非空列表不再显示空态导入按钮。正文稳定宿主修正窄窗 Inspector 顶栏/状态栏错位。

内核直接进入完整任务，备份四个同级任务复用会话；配置按固定对象切换内容，来源与维护合并。主窗口内高级编辑及子编辑嵌入正文，帮助就地展开，网站结果详情在卡片内展开。已有必要确认保留。失败留稿、隐藏草稿、父子任务关闭、切组旧稿、预填取消与 pending 边界均纳入专项回归。返回目录不主动丢弃输入，后台完成不抢回页面。

可验证范围包括 840×560、1040×720、1440×900，浅/深色和 100/120% 文字；原生自动截图使用隔离示例状态，不能证明真实系统代理或核心就绪。构建/截图/执行证据由[验证报告](../verification-report.md)维护，不以测试通过替代系统发行资格。

## 首页追加修订（实施前）

用户进一步指出首页与 macOS Shadowrocket 差距大、难以理解，因此首页以其三行控制加连续节点列表作为直接结构约束，替代 U11 的独立浏览组/大搜索框工具排。工具排右对齐纯图标，搜索默认收起，点击搜索或快捷键才展开；组头只出现一份，名称优先当前配置，副行给出更新时间与实际浏览组，左侧折叠箭头。选节点、延迟重测、详情仍独立命中，不改变控制语义；不将某组的节点假称整个订阅全部节点。正常首行只显示当前节点和开关，接管冲突/失败仍可见，详细内核状态收进提示与状态栏。三行控制使用统一高度、内缩分隔；短列表按实际内容结束，不铺满空白卡片。验收包括默认无大搜索栏/重复组标题、真实来源组可读、三行密度、空/失败和三尺寸截图。
