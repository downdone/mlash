# U40 Mlash 功能清单与入口映射

按用户可完成的任务清点 1.22.0 Windows 工作区。组合在同一行的操作共享对象和归属。右列是 U40 提议的主要入口，用于核查能力迁移。当前实现和约束参照[交互契约](../ui-interactions.md)、[功能模块契约](../development/feature-contracts.md)、[需求映射](../requirements-traceability.md)及 [Controller 命令入口](../../src/app/AppController.h)。交付判据见[重新设计方案](u40-ios-daymark-polish.md)。

| 编号 | 现有用户任务 | U40 主要入口 |
|---|---|---|
| F01 | 查看当前配置、内核健康、代理归属与 TUN 实际状态，开启/关闭代理，处理外部代理冲突 | 连接 → 接管状态 |
| F02 | 查看/切换规则、全局、直连路由模式，了解每种方式的含义 | 连接 → 路由模式 |
| F03 | 浏览和切换策略组、子组及手动成员，查看自动选择与恢复自动，恢复已记忆的选择 | 连接 → 节点与策略组 |
| F04 | 搜索节点，按地区、协议、状态、延迟、收藏筛选，切换表格/卡片和排序，定位当前成员，查看详情、最近与收藏 | 连接 → 节点与策略组 |
| F05 | 测单个节点、所选成员和当前组，看进度、取消；管理组测试地址、常用组和当前叶子节点探测 | 连接 → 节点与策略组 |
| F06 | 管理切换后按组清理受影响连接的偏好，查看选路与清理结果 | 连接 → 策略组设置 |
| F07 | 导入订阅 URL、本地 YAML 与节点链接，预览及去重，处理拖放、剪贴板和外部协议确认，按需命名、设下载方式、UA 与超时 | 配置 → 导入配置 |
| F08 | 浏览、使用、重命名、排序、多选、删除配置；显式展示可分享来源与私人二维码 | 配置 → 配置列表与对象操作 |
| F09 | 更新订阅、同步/更换本地源文件，管理自动更新/监测、用量/到期、下载策略，执行批量更新、取消队列并查看逐项结果 | 配置 → 来源与更新 |
| F10 | 识别活动、待应用与上次良好版本，看候选差异，应用候选、安全重新加载及回滚 | 配置 → 版本 |
| F11 | 添加、编辑、覆盖、移除节点和策略组，管理成员和引用，向现有配置加入节点链接 | 配置 → 节点与策略组 |
| F12 | 查看来源规则，编辑前置、追加、屏蔽规则及规则集声明，切换表单与高级文本，查看改动影响 | 配置 → 规则 |
| F13 | 查看和编辑配置 DNS，继承、清除或覆盖来源，使用表单与高级 YAML | 配置 → DNS |
| F14 | 查看、设置或清除节点拨号上游，检查引用和循环 | 配置 → 拨号链 |
| F15 | 查看节点源、规则源与版本快照，单项、同类或全部刷新，调整继承的下载策略和自动更新计划 | 配置 → 规则源与节点源 |
| F16 | 查看兼容性检查、受控覆盖与拒绝能力，预览脱敏运行配置 | 配置 → 兼容性与运行视图 |
| F17 | 查看上传/下载速率、累计量、连接数、图表及采样状态 | 诊断 → 流量。连接页显示只读摘要 |
| F18 | 查活动及已结束连接，暂停/恢复、搜索/筛选/正则、排序、定制列，查看快照、复制或定位策略组，断开单条/全部 | 诊断 → 连接 |
| F19 | 按指定节点重测网站、编辑测试目标、比较同会话结果、看详情、停止或清空测试 | 诊断 → 网站测试 |
| F20 | 检查出口 IP、地区、ASN 与服务响应，选传输路径、取消、查看结果依据 | 诊断 → 出口与服务 |
| F21 | 按可见性查内核当前实际规则和测试 DNS 查询；从连接或诊断定位所属配置 | 诊断 → 运行规则 / DNS 查询 |
| F22 | 读应用/内核日志、筛选、暂停、复制、换行、跟随最新、清空视图、打开目录及导出脱敏诊断 | 诊断 → 日志 |
| F23 | 创建加密备份，预览并选择性恢复，选择范围，处理恢复前内核/代理要求 | 维护 → 备份与恢复 |
| F24 | 配置自动本地备份、变更前保护和保留策略，立即备份、检查目录、预览选中档案，停用并清除存储密码 | 维护 → 备份与恢复 → 自动备份 |
| F25 | 配置 WebDAV 凭据、传输路径与局域网策略，按需或定时备份、查看远端版本、取消或下载归档到本机、停用并清除凭据 | 维护 → 备份与恢复 → WebDAV |
| F26 | 核对运行内核、启停、查看路径/日志等级/IPv6/统一延迟，检查、下载或导入内核、预检、应用、切换历史和清理副本 | 维护 → 内核 |
| F27 | 检查、导入和更新 Geo 文件及其来源，区分默认数据与运行版本使用的数据 | 维护 → Geo 数据 |
| F28 | 查看应用版本、运行环境、数据位置，检查、下载、取消更新并打开已校验候选包 | 维护 → 应用与版本 |
| F29 | 改本地代理端口、手动测试地址和系统代理排除，复制代理地址和环境变量 | 设置 → 本地网络 |
| F30 | 配置系统代理/TUN 接管方式、栈与路由选项，查看网卡及服务状态、安装/修复/卸载服务和重试清理 | 设置 → 接管方式 |
| F31 | 管理登录启动与冲突、启动页/隐藏/内核/恢复代理、关闭释放、托盘手势和外部协议关联 | 设置 → 启动与桌面 / 链接导入 |
| F32 | 录制、修改、清除快捷键，查看注册失败或冲突 | 设置 → 快捷键 |
| F33 | 调整明暗、增强对比、字阶和系统/应用内标题栏 | 设置 → 外观 |
| F34 | 托盘显示状态、开关代理和接管方式、切模式、快速换组/节点/配置、组停留测速、更新当前配置、显示主窗/连接/设置及安全退出 | 托盘快捷入口，复用 F01–F10、F18、F29–F33 的命令或路由 |
| F35 | 从失败或只读保护恢复，查看告警、详情和处理入口，区分隐藏、关闭与退出，轻量重建后找回浏览位置 | 全局状态与当前对象。日志和诊断导出归 F22 |

运行规则与源规则各有对象。规则模式与节点连通各有状态。下载候选和应用版本各有命令。WebDAV 下载与恢复分别由原操作确认。托盘、搜索、快捷键和状态提示可直达各自的主入口，统一对象身份、命令权限和写入确认。

实施前按逐条映射核对现有按钮、菜单、快捷键、启动页及旧路由入口。每个功能组至少记录一个可走通的入口。低频入口以菜单、搜索或明确的对象链接到达。若原有能力缺少新入口，为该条补足后再迁移原页面。
