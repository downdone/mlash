# U20：菜单与就近操作体系

状态：设计审视完成，P0 的菜单弹出、连接搜索与节点筛选已实施；其余项待实施。当前行为以[交互契约](../ui-interactions.md)为准，实际验证见[验证报告](../verification-report.md)。

## 原则与容器选择

目标是减少完成一次任务所跨越的界面层，而不是统计 `QDialog` 类名或追求零弹窗。Shadowrocket 的低层级、内容优先是产品方向；Daymark 的菜单测量、动态分组、锚点定位、状态绘制和就近编辑是组件方法。Mlash 仍使用 Qt Widgets，业务写入仍经 AppController。

Apple 的 [Menus](https://developer.apple.com/design/human-interface-guidelines/menus)、[Popovers](https://developer.apple.com/design/human-interface-guidelines/popovers)、[Context menus](https://developer.apple.com/design/human-interface-guidelines/context-menus)、[Sheets](https://developer.apple.com/design/human-interface-guidelines/sheets) 和 [File management](https://developer.apple.com/design/human-interface-guidelines/file-management) 给出的取舍是：菜单供短命令，浮层供少量临时信息或选择，右键菜单只呈现当前对象相关命令，文件选择继续使用系统面板；有阻断后果时才使用模态确认。macOS 并不存在“几乎不使用弹窗”的硬规则；输入复杂度、持续时间和后果决定容器。

| 内容与任务 | 容器 | 关闭与状态规则 |
|---|---|---|
| 立即执行的 2～8 个短命令 | 锚定命令菜单 | 选择、点外部或 Esc 关闭；不嵌表单。 |
| 单值、短列表或轻量筛选 | 就近选择浮层 | 触发控件附近打开；有边界、可搜索、可键盘操作；关闭后归还焦点。 |
| 一个对象的多个字段、候选预览或长时任务 | 所属页面的 TaskWorkspace / Inspector | 状态与错误留在任务内，切页保留草稿和进行中结果。 |
| 当前行的只读详情 | 当前行展开或侧边详情 | 返回原行与滚动位置，不打断列表。 |
| 删除、覆盖、放弃草稿、接管外部系统代理或提权 | 短确认框 / 平台适当的 sheet | 说明对象与实际后果；默认不执行危险动作。 |
| 选择真实文件或保存位置 | 系统文件面板 | 保持平台路径、权限与可访问性惯例。 |

## Daymark 源码吸收点与 Mlash 根因

Daymark 的 `style/Menu.qml` 在出现前按可见项测量宽高，将菜单限高约 480 DIP，以触发点定位并限制在屏幕内；动态命令不会留下首尾或重复分隔线。`style/MenuItem.qml` 把勾选、文本、快捷键和子菜单箭头分列，菜单自己拥有唯一高亮，危险命令显式着色。`style/ComboBox.qml` 使用同一行规则且关闭时不孵化列表。`CatalogEditPopup.qml` 和 `DateField.qml` 在触发点附近展开、保留草稿、处理 Esc/点外部，并在结束时恢复焦点。这些是可移植的行为与几何规则，不依赖 QML 本身。

Mlash 已有语义色、`WidgetStyle` 的圆角菜单绘制和紧凑 `QComboBox`，U19 也已有独立的 `GroupPickerPopup`。但 `WidgetStyle::PopupSurface` 对通用菜单与组合框在 `Show` 事件里调整大小和位置；这一时序无法像 U19 组选择器一样保证显示前定几何。全局样式只统一了外观，页面仍自行决定组织、嵌表单和嵌套深度。菜单最大高度 720 DIP、行高下界 26 DIP，也与 Daymark 的约 28～32 DIP 行、480 DIP 限高不同。数值应按 Mlash 字体指标和窄屏样片定稿，不机械复制。

## Daymark 的体验逻辑：从用户任务而非控件出发

前述对照只覆盖了组件实现，**不足以称为吸收 Daymark 的 UI/UX 设计**。它的界面首先围绕“找到对象→理解状态→就近操作→得到结果→回到原位置”组织，然后才选择菜单、行内编辑或详情。Mlash 的对象是订阅、策略组、节点、连接和设置，不能照搬任务管理语义，但应逐条核对这个闭环。

| Daymark 源码中的决策 | Mlash 应吸收的原则与落点 | 可观察验收 |
|---|---|---|
| `TaskRow.qml` 单击打开行内速编、双击完整编辑；菜单承担次级动作；`NavRow.qml` 的操作在悬停或键盘焦点时出现。 | **主动作贴近对象，次级动作渐进呈现。** 配置行的使用/更新/编辑有明确主次；节点名称仍按现有组选择契约执行，延迟独立测速，不能把“单击速编”机械移植为误写代理状态。隐藏的动作必须仍可用键盘及上下文菜单发现。 | 从配置行完成日常使用/更新无需穿越多层菜单；节点名称、延迟、详情各有独立命中区；鼠标与键盘获得相同能力。 |
| `TaskRowSummary.qml` 仅在有内容时显示注释和元数据，无辅助文字时让标题垂直居中；文本溢出才显示完整提示，并有行几何自检。 | **信息按存在性和任务重要度排布。** 节点行优先名称、当前/测试结果；协议、来源和其他元数据只在有用时出现。配置、连接、设置行不为缺失字段保留空位，不用常驻图标/说明争夺主视觉。 | 空值与长名称、已测/未测、当前/非当前混排时，行高、基线和动作列稳定；截断信息有可访问的完整名称。 |
| `NavSection.qml` 折叠后仍指示所选对象位于其中；`Main.qml` 保留对象 ID、来源行、锚点，并在来源不可见时处理回退。 | **位置和上下文连续。** Mlash 从配置详情、组选择或数据详情返回时保持来源对象、列表滚动和筛选；当前运行版、正在浏览的组及选中节点必须分别标示。面板失去锚点时关闭或改为稳定工作区。 | 切页/返回不跳到列表顶部或另一个组；折叠/筛选不把当前对象伪装成丢失；订阅更新后若对象代次变化，旧详情不能继续操作。 |
| `Main.qml` 的 `navigateSafely()` 在忙碌、脏草稿和保存失败时延后跳转或停在原任务；`CatalogEditPopup.qml` 的失败保留输入、完成归还焦点。 | **状态与结果归属于任务。** 导入、重命名、规则草稿、设置编辑在原工作区显示校验、进行中、失败与完成；关闭浮层不暗中取消后台事务。仅未保存草稿或实际破坏性后果触发确认。 | 导入失败保留来源/名称；切页时草稿不丢；成功后在相应订阅行看到结果；异步结果不会落到已切换对象的页面上。 |
| `style/Menu.qml` 开启前过滤和测量、限制屏幕边界；`DateField.qml` 选可用方向并恢复焦点。 | **临时界面围绕触发对象。** 单值选择、筛选与搜索在触发点附近，首帧位置/圆角已正确；复杂表单留在页面。浮层随窗口隐藏、路由改变或对象失效而退出。 | 在上下左右屏幕边缘、DPR/字号变化和键盘打开时不遮挡关键控件、不跳位；Esc 后焦点返回触发点。 |
| `NavRow.qml` 支持右键、macOS 修饰单击和 Shift+F10；`TaskRow.qml` 为列表行提供键盘主动作、详情及上下文动作。 | **可发现性不依赖悬停。** 常用命令有文字或明确的可访问名称；工具栏图标、菜单和行操作在键盘焦点时同样可见。 | Tab/方向键、Enter/Space、Shift+F10、Escape 可完成对应流程；无鼠标悬停时仍知道可用操作。 |

### 按 Mlash 用户任务重排，而非按 Daymark 页面翻版

1. **导入订阅：** 配置页“添加”就近选择 URL、文件或节点链接；在配置工作区输入与校验，展示候选后明确“使用”。`ImportDialog` 当前已嵌入 `TaskWorkspace`，故工作重点是去掉表单式重复外壳、把状态归给候选对象；文件路径仍由系统面板选取。下载/解析不得自动覆盖当前运行版。
2. **找组、选节点、测速：** 首页始终展示“当前运行成员”和“浏览组”的区别；组选择、搜索、排序、整组测试围绕节点列表；单节点延迟是直接重测动作。切组后搜索和滚动按组保存或显式重置，避免看似随机跳位。选择写入必须走 AppController，并回读观察状态。
3. **管理配置：** 行上提供最常用的“使用/更新”，详情承载来源、版本、规则、DNS 和危险维护；行内改名只处理一个字段。候选、当前、最近可用版本的标识不能合并为一个“已更新”。
4. **检查连接与日志：** 列表项就近展开详情/断开/复制；复杂列配置贴近表头，日志导出贴近日志工具栏。筛选保留在列表上下文中；结果反馈写在该对象或固定状态栏，不推动列表高度。
5. **设置与托盘：** 简单开关在设置行直接操作并显示观察值；多字段配置进同页工作区。托盘只完成高频快捷动作，明确当前状态，完整配置与长节点列表交还主窗口。

这份对照是**设计准则和待验任务**，不是现状已实现声明。它也不要求 Mlash 迁入 QML：Daymark 的视觉与交互规律可由 Widgets 的布局、代理绘制、浮层和状态模型实现；Mlash 的系统代理/TUN 安全边界、候选/活动版本及 Windows 托盘规则优先于相似外观。

| 托盘：OS 菜单含模式、最多 8 组 × 每组 16 节点、订阅和页面入口 | 层级与数量偏多；系统托盘不能强求应用内浮层完全同形。 | 保留状态、窗口、总开关、模式、当前/常用组和退出；组内限当前/收藏/少量前列，更多进首页；测速显式触发。 |

当前多数 `TaskDialog` 由 `TaskWorkspace` 当子控件承载，不能把类数等同于屏幕弹窗数。文件选择器也是系统任务的一部分，应保留。连接“断开全部”保留确认；单个明确选中的连接可直接执行，并在原处报告回读结果。

## 共同组件与实施顺序

1. **命令菜单基础。** 统一可见项过滤、首尾/双分隔线归并、按内容测量和锚点定位；在 `popup()` 前完成尺寸与屏幕裁切，避免首帧 `Show` 后跳位。单选使用 `QActionGroup`，只绘制一个高亮；危险命令放最后。菜单不承载输入控件。
2. **选择浮层基础。** 复用 U19 组选择器的显示前定几何、圆角和筛选；补充焦点归还、父窗移动/隐藏和触发点销毁处理。短表单、列选择和筛选用此组件，不塞回 `QMenu`。
3. **P0 操作链。** 首页路由和连接右键非阻塞；连接搜索开关回到搜索框旁，节点筛选和连接列设置从 `QWidgetAction` 迁出；配置导入在既有工作区内重排。每片保留旧对象名或同步更新操作测试，不因外观重构改变命令语义。
4. **P1 信息组织。** 精简配置右键和节点“更多”、就地重命名、移除重复/死入口；托盘按任务频率限项，仍使用系统菜单。
5. **P2 余下工具。** 审核设置、日志、备份、核心/Geo、诊断任务。复杂任务保留工作区，危险操作保留确认；只对确有多余层级的入口改就近浮层。

所有 UI 只调用既有 AppController 命令；菜单/浮层保存对象 ID 和打开时快照，执行前回查当前身份与允许状态。关闭浮层不取消后台事务；关闭输入任务遵守草稿与提交保护。跨页、隐藏窗口或锚点销毁时关闭浮层；主窗口轻量重建后不能使用旧控件指针。

## 第一片实施后复核

首页路由菜单和连接右键菜单现在使用堆上短命菜单，非阻塞打开、关闭后延迟销毁；共同通过 `WidgetStyle::popupMenu()` 在显示前确定限高、屏幕内位置与透明圆角。路由项互斥勾选来自当前观察模式。连接右键捕获打开时连接 ID，触发动作时再到当前过滤模型查找，原连接消失时不把复制/详情/断开转给别的行。连接搜索的三个开关移到搜索框旁，列菜单不再包裹这一小表单。

样片复核：路由菜单首帧圆角透明，30 项菜单在 480 DIP 内滚动；连接搜索三开关与列入口同处一条工具带，未挤压表头。节点的地区、协议、状态、延迟、收藏筛选现为锚定工具按钮的独立浮层；关闭后保留条件，Esc、换页及主窗移动/隐藏关闭，焦点返回触发点。首帧样片无方角。配置右键审计另发现“重新加载”与“回滚”动作名误绑且重载误用回滚参数，已修正。单字段重命名改在配置详情行内完成：右键直达该行，取消不写入，未保存返回须确认，保存失败留在原处。

## 下一片：连接列选择（实施前设计）

对象是当前连接表，不是全应用配置菜单。点击表头附近的“列与视图”按钮，在按钮旁展开最高 480 DIP 的可滚动选择浮层；每列一行复选框，名称列始终启用且不可隐藏。多项选择留在浮层中连续完成，不因每次勾选反复关闭；“恢复默认列”和“恢复默认顺序”位于列表后的操作区。表头宽度与顺序继续由现有 `ConnectionOptions` 单一写入路径维护，浮层只发出用户选择，不直接写 Controller。打开时从表头实际可见性同步，父窗移动/隐藏、离开数据页、Esc 或外部点击关闭，重新打开仍反映表格现状。边界、首帧圆角、缩放下的可达性与持久化回归是验收点。

## 配置导入与托盘快选（实施前设计）

配置右键按对象任务压缩为单层短菜单：对象状态、设为当前、更新（远程）、重命名、来源与更新、分享（远程）、更换文件（本地）、删除。规则、DNS、节点、链、兼容性及目录仍在对象详情/设置等既有入口，不让短菜单替代页面工作区。现有程序化动作对象保留以兼容自动化与状态同步，但从可见右键中移除。每次展示根据选中配置的来源决定适用项，删除始终置尾。

配置页的“导入…”是选择来源的入口，不应预设为 URL。点击后在触发行旁显示三个短命令：订阅地址、本地 YAML、节点分享链接；选定后进入现有页面内导入工作区，保留来源页签以便纠正选错来源。页内工作区已有“导入配置”标题，嵌入表单隐藏重复的“添加订阅”标题，保留显式取消作为草稿退出动作。空列表的“添加订阅”“导入文件”仍直接进入对应来源。剪贴板、拖放和协议链接沿现有预填路径，不因入口改动而直接下载。浮层打开前确定尺寸和位置；取消不创建配置，提交失败留在工作区。

托盘只承载快速操作。策略组依次选最近、常用及少量其余组，最多五组；每组先放当前节点，再放收藏节点，再补少量前列节点，最多六项。订阅先放当前，再补至最多五个；“打开订阅页”始终可达完整列表。超出时提供“在主窗口查看全部”入口。测速继续由显式命令触发，原有“展开时测延迟”偏好保留，避免打开菜单立即造成网络工作。完整组与节点始终可在主窗口找到。验收检查菜单高度、有当前勾选、超额入口及现有 Controller 命令路径。

## 本轮实施后复核

连接列浮层在 `build/u20-final-screenshots/connection-columns.png` 的离屏样片中呈现固定宽度、圆角和可滚动 15 列；连续勾选不收起，回读表格列状态。配置页“导入…”现在先显示三来源短菜单，再复用既有页内导入任务；空列表与剪贴板/拖放的直达路径未改变。配置右键保留短菜单，低频编辑经详情工作区进入；兼容用动作对象保留但不再露出冗余菜单项。设置的代理环境变量、Geo、预览和内核目录行直接持有动作，不经不可见菜单刷新；日志更多菜单现为日志目录与自动换行两项，导出和清空仍在原工具带。托盘快选上限为五组/每组六节点、五个订阅；完整选择仍在主窗口，原测速入口与 Controller 事件未改。

Windows 构建及配置导入、连接列、设置行内动作、托盘订阅上限的隔离回归通过。组/节点上限断言加入原有真实内核回归，受限环境未能跑到该断言；原生鼠标、读屏、高对比、缩放、系统托盘实际展开及发行资格仍待验证，不能将离屏截图视为完整手工验收。

## 可观察验收

- 视觉：明/暗/高对比、840×560 与常用宽窗、100/125/150% DPR、100/120% 文字下检查首帧圆角、边界、列对齐与无闪烁；记录显示前和 0/16/60/160 ms 几何。
- 交互：鼠标、键盘、Shift+F10、Esc、点外部、长名称/多语言、屏幕边缘、父窗移动或隐藏后均无残留浮层；关闭后焦点回触发点。
- 内容：无空/双分隔线、无关禁用项与重复命令；危险项指明对象并靠后。高频路径不穿越多级菜单；只有标签明确且可预测的低频分类允许一层子菜单，长选择转工作区或选择浮层。
- 任务：导入三来源及剪贴板/拖放/协议预填未确认前不下载，失败留稿；浏览不写入，确认后才调用 Controller。删除、外部接管、覆盖和放弃草稿继续确认。
- 工程：定向 Widgets 和操作链测试、原生样片、文档/隐私检查通过；真实系统代理/TUN 写入仍仅在受控环境验收。本设计本身不等于这些项目已通过。
