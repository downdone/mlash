Mlash · Windows x64 便携版

开始使用
1. 解压完整文件夹后运行 Mlash.exe，请勿只复制 EXE。
2. 在“订阅”添加 YAML 地址、配置文件或节点分享链接，校验后明确点击使用。
3. 在首页按需开启系统代理；使用 TUN 前，在设置中明确安装权限服务。

关闭与退出
关闭窗口后程序进入托盘；轻量模式会释放界面，内核继续运行。
完全退出请使用托盘的“退出 Mlash”。升级前先退出旧版，再解压到新文件夹。

数据与备份
便携指免安装；用户数据仍保存在 %LOCALAPPDATA%\Mlash，不写入解压目录。
可从设置打开数据目录并导出加密备份。删除或替换程序文件不会删除用户配置。

文件说明
cores 内为随包固定内核 @CORE_VERSION@；运行库和插件文件夹请一并保留。
MlashTunService.exe 仅用于明确安装的 Windows TUN 服务，普通启动无需管理员权限。
package-manifest.json 提供文件完整性与版本记录；cores/manifest.json 记录内核来源。
本包不包含订阅、密码、日志或个人设置。Geo 数据按配置按需获取，不预装大型数据集。
