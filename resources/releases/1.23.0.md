Mlash 1.23.0 · Windows x64 预发布

- 主窗口采用 Daymark 风格的浅深配色和竖排侧栏，设置固定在侧栏底部。同步细化应用图标、托盘状态和键盘焦点。
- 配置页收紧导入栏，可粘贴订阅 URL、拖入或选择 YAML 文件。「高级」打开独立导入窗口。配置卡集中显示来源、时间和状态，右上角提供刷新与更多操作。
- 更新候选可从配置卡进入比较，再确认应用。首页细化首次连接引导，设置搜索直达具体任务，网站测速与连接详情适配窄窗。

升级前退出旧版，解压完整便携 ZIP 后运行 `Mlash.exe`。同名 `.sha256` 文件可校验下载，来源 JSON 记录应用与固定内核的源码提交。

本版按 Windows x64 预发布分发。真实系统代理与 TUN、干净系统部署和长期稳定性仍待正式发行验收。
