Mlash 1.20.0 · Windows x64 预发布

- 整组节点延迟测试以最多 12 个并发异步请求完成，保留进度、单节点重测与取消。
- 主窗口可在设置里选择系统标题栏或融入页眉的应用内标题栏；应用内栏支持最小化、最大化、拖动和窗口边缘缩放。
- 新增应用在线版本检查与便携包下载；检查固定 GitHub 发布源、版本、文件名、大小和 SHA-256，校验成功后保存到独立更新目录。当前运行版本不自动替换，退出后由用户打开候选包完成便携升级。
- 纳入模块化架构和 Shadowrocket 视觉系统精修；字体、字阶、控件边距及线条在同一设计规格中管理。
- 随包内核保持 v1.19.32-halfclose.1。

解压完整 portable.zip 后运行 Mlash.exe。升级前从托盘退出旧版并备份；应用内下载的更新包只作为已校验候选，不执行后台自替换。ZIP SHA-256 见同名 .sha256 文件，源码与固定内核来源见 source.json。

本版为预发布。实际运行的 Windows 测试与未执行的系统/长期测试分别记录在验证报告；不将预发布标记为正式发行资格。
