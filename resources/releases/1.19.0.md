Mlash 1.19.0 · Windows x64 预发布

- 高级编辑移入当前分区正文，减少独立弹窗和中间页；返回和同级切换保留草稿，未完成提交及隐藏草稿继续受保护。
- 内核管理直达完整任务；备份创建、恢复、自动计划、WebDAV 同级切换。
- 配置的规则、DNS、节点、拨号链和来源在固定对象内组织，来源信息与维护合并。
- 首页采用更紧凑的三行控制与连续节点列表，搜索默认收起；顶栏、侧栏、目录、页签及正文留白同步收紧，文字放大时按实际指标扩展。
- 帮助与网站测试详情就地展开，日志阅读历史时直接提供“回到最新”。
- 修复配置副标题、空态覆盖、窄窗 Inspector 错位，以及切组参数草稿归属。
- 随包内核保持 v1.19.32-halfclose.1。

解压完整 portable.zip 后运行 Mlash.exe；用户数据仍在 %LOCALAPPDATA%\Mlash，升级前从托盘退出旧版并备份。ZIP SHA256 见同名 .sha256 文件，源码与固定内核来源见 source.json。

验证平台：本次在 macOS 开发并通过本机构建与针对性回归。Windows 发布链执行编译、包内冒烟和附件完整性检查，完整 Windows 回归不作为本次发布门槛；未执行的场景不作通过声明。

本版为预发布：自动构建/隔离回归不替代受控 Windows 10/11、系统代理/TUN/登录恢复、长期稳定性与资源预算验收。第三方完整对应源码及分发声明审查仍未完成，release_qualified=false；未进行代码签名，不标记为最新稳定版。其他平台适配仍保持明确 Unsupported。
